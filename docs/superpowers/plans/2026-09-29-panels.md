# 面板识别 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 团子（大脑模式）实时知道画面上开着哪些面板，操作前不被挡，能读出面板文字、按安全规则按按钮；`run` 默认进大脑模式。

**Architecture:** `vision/panels.py` 只看（特征卡快看 + OCR 细读 + 通用兜底），`assets/panels/` 放特征卡数据，`game/panels.py` 只动手（关面板、按按钮），
`brain/body.py` 接事件 / 状态 / 遮挡护栏 / 三个面板工具，工具经 `brain/tools.py` + `mcp_server.py` 给大脑，网页和手动控制跟着加。

**Tech Stack:** Python 3.11+、numpy、OpenCV、tomllib、RapidOCR（`OcrEngine` 协议）、pytest（合成画面 + 假设备 + 假 OCR）

**Spec:** `docs/superpowers/specs/2026-09-29-panels-design.md`（实现前先读完；本计划只写 spec 没定死的决定）

## Global Constraints

- 用中文写注释、日志、给大脑 / 用户看的文字；代码风格照周围代码（dataclass、`log = logging.getLogger(__name__)`、坐标 0~1 归一化按 1920×1080 标定）。
- 测试命令：`python -m pytest -q`（云端没有模拟器；**不往真机发输入**）。每个任务结束时全量测试必须全绿（基线 707 passed, 6 skipped）。
- 五张卡全部 `verified = false`；**未核对的卡缺模板图 → 该特征不命中 + 加载时一行 WARNING**；已核对的卡缺图 → `CardError`。
- 按钮安全规则优先级：`never`（全局 `panels.never` + 卡片 `never`）> `retreat` > 卡片 `allow` > `other`；词表匹配用"包含"（词在按钮文字里）；`never` 主人放行也不按。

## Review Focus

1. **截图不是 1920×1080**（测试画面 1280×720、MuMu 也可能改分辨率）：模板按 `frame 高 / 1080` 缩放后照样认得出 → Task 3 `test_template_matches_on_1280x720_and_1920x1080`。
2. **OCR 抛异常 / 返回空**（后台线程里）：身体不能崩，已认出的面板状态不变 → Task 5 `test_ocr_error_keeps_state`。
3. **大脑给的按钮编号越界、文字对不上、同名按钮有两个** → 越界 / 对不上时报错并列出现有按钮，同名取第一个 → Task 8 `test_panel_press_bad_button_lists_choices`。
4. **特征卡里拼错键名**（`treshold`）或关法写错（`kye:18`）：静默忽略会让卡永远认不出 → 加载时报错带卡片名和键名 → Task 2 `test_card_unknown_key_raises`、`test_card_bad_close_way_raises`。
5. **整屏黑（切场景）**：和"干净画面"差异巨大，不能因此去 OCR、也不能把黑屏当成面板 → Task 5 `test_black_frame_does_not_scan`。

  ```python
  def check_feature(frame: np.ndarray, feature: Feature, builtins: dict[str, Callable[[np.ndarray], bool]]) -> tuple[bool, float]
      # (命中没有, 分数)：template = 最高匹配分；dark = V 中位数；builtin = 1.0 / 0.0；text 恒 (False, 0.0)
      # template 缩放：k = frame 高 / 1080，scales = [k * s for s in (0.9, 1.0, 1.1)]；template 为 None → (False, 0.0)
      # dark：HSV 的 V 通道，中位数 ≤ max_value 且标准差 ≤ max_std
  @dataclass(frozen=True) class CardCheck: card: Card; hits: tuple[tuple[Feature, bool, float], ...]; open: bool
  class PanelWatcher:
      def __init__(self, cfg: PanelsConfig, cards: list[Card], ocr: OcrEngine,
                   builtins: dict[str, Callable[[np.ndarray], bool]], clock: Callable[[], float] = time.monotonic,
                   background: bool = True) -> None   # 卡片里的 builtin 名不在 builtins 里 → ValueError
      state: PanelState                                # 最近一次 observe 的结果
      readings: dict[str, PanelReading]                # 各面板最近的细读（Task 4/5 填）
      def observe(self, frame: np.ndarray, now: float) -> PanelState
      def explain(self, frame: np.ndarray) -> list[CardCheck]   # 单帧、不去抖（panels scan 命令用）
      def present(self, frame: np.ndarray, panel: Panel) -> bool # 单帧判断这个面板还在不在（PanelOps 用；unknown 见 Task 5）
      def mark_closed(self, name: str) -> None         # 立刻从 state 去掉并排一个 close 变化（PanelOps 关掉后调）
      def expect(self, name: str | None) -> AbstractContextManager   # None = 什么都不做；可嵌套（计数）
      expected: set[str]
      def blocking(self, action: str) -> list[Panel]   # state 里 name 不在 expected、action 不在 allows 的，按 layer 从大到小
      def pop_changes(self) -> list[PanelChange]
      def close(self) -> None                          # 停后台线程（Task 5）
  ```

  expected 里的面板开 / 关不排变化；`expect` 退出时它仍开着 → 排一个 open 变化。
  `Panel.box = roi_rect(card.region, w, h)`，`allows = card.allows`。

  - `panel_press(button)`：
    1. `now - self._read_at > cfg.panels.read_ttl` → `ToolError(f"先 panel_read（{read_ttl:.0f} 秒内）再按：面板可能变了")`

       `ToolError("没有这个按钮；现在的按钮：[1] 取消、[2] 加入")`

       `ToolError(f"「{text}」要卡洛放行才能按：卡洛在聊天里发「#允许 {text}」后 {permit_window:.0f} 秒内可以按一次")`
