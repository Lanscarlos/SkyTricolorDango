# 按 Q 喊一声 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 好友走远标签淡掉时不再误报"走开 / 陌生人"；团子能按 Q 喊一声把附近好友的名字亮出来（大脑工具 + 身体自动兜底），顺带用呼唤光圈认出团子自己。

**Architecture:** 感知层加三样被动能力（轨迹续命、呼喊窗口收标签、贴边标签不算在身边）；新的纯计算模块 `vision/halo.py` 认光圈；身体 `Body.call_out` 同步按 Q + 连拍 1 秒、开窗口，`_watch_call` 自动兜底；大脑工具 `call` 在 MCP 线程等窗口结束；文字拼装放新模块 `brain/calling.py`。

**Tech Stack:** Python 3.11+、numpy、opencv；测试 `python -m pytest -q`（合成画面 + 假设备）。

**Spec:** `docs/superpowers/specs/2026-10-01-q-call-design.md`

## Global Constraints

- `[call]` 默认：`enabled = true`、`auto = true`、`min_gap = 20.0`、`auto_quota = 3`、`auto_window = 600.0`、`auto_after_leave = 30.0`、`window = 6.0`、`burst = 1.0`、`halo = false`、`halo_rise = 25.0`、`halo_center = 0.35`
- `[perception]` 新增：`sticky_names = true`、`edge_band = 0.06`
- Q 的 Linux 键码 `LINUX_KEY_Q = 16`，放 `device/base.py`；短按 `device.hw_key`，**不长按**
- `[call] enabled = false` 或感知层没开时：没有 `call` 工具，`TOOL_NAMES` / `ACTIONS` 以外的工具列表、提示词、status 逐字照旧，身体不自动喊
- `sticky_names = false`、`edge_band = 0` 时感知层逐字照旧
- `halo` 默认关；光圈认不准就放弃，**不为确认再按一次 Q**
- dry-run 不按键（自动喊照样判断、记日志"会喊"）
- 新背景事件 `call` 不单独叫醒大脑
- 中文注释 / 文案，风格同周边代码

## 偏离 spec 的地方（实现时照这里）

- **贴边标签仍更新 `labels`**（spec §1.3 说不刷新 labels）：技能 track 靠 `env.labels` 里贴边的名字继续往画面外转（2026-09-30 真机验收过的行为，`Body.target_x`），停掉会让盯人一出画面就跟丢。只是不刷新 `last_seen`（= 不算在身边）、不挂圆圈 / 请求、不进 hardcases 的 `seen`。
- **`call` 工具不进 `DESCRIPTIONS` / `TOOL_NAMES`**：照 `introspect` 的做法单独一个 `CALL_DESCRIPTION`，`ToolBox(call=True)` 时 MCP 在 `look_around` 之后注册。这样关掉时工具列表逐字照旧（spec §3.1 "放在 look_around 后面"指注册顺序）。`"call"` 进 `ACTIONS`（不注册时用不到）。
- `HaloWatch.result(width)` 只收画面宽，中线 = 宽 / 2（spec 签名里的 `center_x` 多余）。
- 光圈判定的边界情况：恰好一个人过门槛但有人在 `halo_rise/2 ~ halo_rise` 之间、或过门槛的那个人不在画面中间 → `"others"`。
- `Seen` / `CallSeen` 放 `vision/people.py`（纯数据，身体导入它不拉 YOLO）。
- "没在环视"不单独判断：环视、call_out 都在身体线程同步执行，不会重叠。

## Review Focus

- 好友标签淡掉、但 YOLO 把他的人物框弄丢一两帧又接上（新轨迹没名字）：新轨迹不带名字，续命断了，5 秒后照样"走开"——这是 spec 接受的，但别因为新轨迹而判陌生人之前多冒一次 stranger（Task 3 测：断开 < track_buffer 时同一条轨迹接着续命）。
- 呼喊窗口里感知层暂停（黑屏 / 转镜头）：窗口跟着往后挪，结果晚到；大脑工具最多等 `window + 4` 秒，等不到要回"没等到结果"而不是挂住（Task 4、Task 7 测）。
- 连拍时时钟不走（测试 / 沙盒钟）：连拍循环必须有张数上限，不能死循环（Task 5 测）。
- 喊之前输入框开着：字母 Q 会被打进输入框；`clear_view` 关掉身体开的框之后还要 `ime_shown()` 再查一次（Task 5 测）。
- 自动喊：好友走开后又回来了 / 同一次走开已经喊过 / 额度满：不喊（Task 6 测）。

**Files:**
- Create: `src/skydango/brain/calling.py`
- Modify: `src/skydango/brain/body.py`
- Test: `tests/test_brain_call_body.py`（新）

**Interfaces:**
- Consumes: `HaloWatch`（Task 2）、`env.called` / `call_result` / `last_tracks` / `self_box`（Task 4）、`LINUX_KEY_Q`
- Produces（`brain/calling.py`）：
  - `@dataclass CallResult(at: float, reason: str, refused: str = "", dry: bool = False, halo: str = "off", self_box: Rect | None = None, seen: CallSeen | None = None)`
  - `seen_text(seen: CallSeen) -> str`："认出 小明（右边·远）、懒洋洋大王（左边·近）；小红在画面外（左边）；还有 1 个没挂名字的人"；没好友 → "没看到谁的名字"；`unnamed == 0` 不写最后一句；画面上但没远近的写"小明（右边）"
  - `halo_text(halo: str) -> str`：`"self"` → "光圈：认出了你自己（中间）"，`"others"` → "光圈：别人也在喊，没认出你自己"，`"none"` → "光圈：没看到"，`"off"` / `"skipped"` → ""
  - `tool_text(r: CallResult) -> str`："喊了一声：{seen_text}。{halo_text}。"（seen 为 None → "喊了一声：没等到结果（感知层暂停了？）"）
  - `event_text(seen: CallSeen) -> str`："你下意识喊了一声：{seen_text}。"
  - `wait_result(body, r: CallResult, poll: float = 0.25, sleep=time.sleep) -> CallResult`：每 `poll` 秒 `body.call(lambda: body.env.call_result(r.at))`，最多 `window + 4` 秒（按 `body.clock`，同时按次数上限防时钟不走）
- Produces（`Body`）：
  - `call_out(reason: str, *, live: bool = False) -> CallResult`（reason：`"brain"` / `"auto"` / `"manual"`）
  - `last_call: CallResult | None`；`self._call_times: deque[float]`（自动喊的时间）
  - status 一行 `"上次喊：{N 秒前|N 分钟前}（认出小明；你自己在中间）"`（`last_call` 有、且 `seen` 有了才写；没认出 → "没看到谁的名字"）

**`call_out` 顺序**（不能喊 → `CallResult(refused=原因)`，不抛）：
1. `[call] enabled` 关 → "没开"；`env` 没有 `called` → "没开感知层"；`blackout` → "画面黑着（在切场景），现在喊不了"
2. `now - last_at < min_gap`：`reason == "brain"` 且 `_owner(now)` 放行（之后结果文字带 `OWNER_NOTE`，`CallResult.reason` 记 `"brain-owner"`）；否则 "N 秒前刚喊过，等一会儿再喊"
