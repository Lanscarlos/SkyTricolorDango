# 管理面板（console）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `python -m skydango console` 起一个本机网页面板：填密钥、改常用配置、检测 MuMu、启动 / 停止团子子进程，运行时看实时识别、大脑时间线和团子状态。

**Architecture:** 面板是父进程（标准库 `ThreadingHTTPServer`），把 `python -m skydango run --view …` 作为子进程起停；子进程的 viewer 开在 `127.0.0.1:<child_port>`，面板把 `/live/*` 转发过去，实时页用 iframe 嵌子进程自己的 viewer 页面。
面板设置写 `console.toml`（叠加在 `config.toml` 之后）、密钥写 `secrets.toml`（按环境变量名，注入子进程环境变量），`config.toml` 只读。

**Tech Stack:** Python 3.11+ 标准库（`http.server`、`urllib.request`、`subprocess`、`tomllib`、`threading`），原生 HTML/CSS/JS（无构建）、pytest。

**Spec:** `docs/superpowers/specs/2026-09-29-console-design.md`

## Global Constraints

- 不加任何依赖：只用标准库；前端原生 JS，无构建步骤。
- 面板只监听 `127.0.0.1`，不提供改成局域网的选项；子进程由面板启动时 viewer 强制 `127.0.0.1`。
- 默认端口：面板 `19390`，子进程 viewer `19391`（`[console] port` / `child_port`）；`view` 的 19399 不动。
- `config.toml` 面板**只读不写**；面板只写 `console.toml`、`secrets.toml`（与 `config.toml` 同目录，都进 `.gitignore`）。
- 加载顺序：默认值 → `config.toml` → `console.toml`；`secrets.toml` 的 `[env]` **覆盖**已有环境变量；终端直接跑命令也适用。
- 浏览器永远拿不到完整密钥；日志里不打密钥的值。
- 所有 `/api/*`、`/live/*`（含 GET）校验 Host 是本机地址 + 面板端口；所有 POST 还要 `X-Skydango: 1`、`Content-Type: application/json`、请求体 ≤ 64 KB。
- `[console]` 默认值：`port = 19390`、`child_port = 19391`、`stop_timeout = 60.0`、`log_lines = 500`、`brain = true`、`live = false`、`emotes = true`、`duration = 0.0`。
- 子进程看门狗每 2 秒查一次父进程；启动 60 秒还没响应仍是「启动中」；转发超时 5 秒。
- 子进程命令行总是显式带 `--live` 或 `--dry-run`；普通 Agent 加 `--no-brain`（`run` 默认就是大脑）。
- 界面文案、日志、注释用中文，风格照现有代码（简短、说清为什么）。
- 测试：`python -m pytest -q`，不需要模拟器；基线 921 passed / 6 skipped。
- 代码名一律 `console`（`panel` / `panels` 已经是聊天记录面板和面板识别）。

## Review Focus

1. **子进程输出非 UTF-8 / 超长行**（Windows GBK 残留、进度条）→ 日志线程不能崩，按 `errors="replace"` 解码、单行截到 2000 字。测试在 Task 6。
2. **`console.toml` 被手改坏了（语法错 / 未知键）** → 设置页显示「console.toml 读不出来：…」，保存被拒绝、不覆盖原文件；启动预检也报这个错。测试在 Task 3。
3. **连点两次停止 / 还在「启动中」就点停止** → 停止幂等；启动中子进程还没开端口，`/shutdown` 发不过去就每 0.5 秒重试到 `stop_timeout`，再强杀。测试在 Task 6。
4. **子进程在两次请求之间退出** → 转发遇到连接被拒 / 超时返回 503 `{"ok": false, "text": "团子没在运行"}`，不是 500。测试在 Task 9。
5. **页面传来的启动选项不合法**（`duration` 为负、不是数字、`brain` 不是布尔）→ 400 + 哪一项不对，不起子进程。测试在 Task 9。

  - `class SettingsStore(config_path: Path, environ: Mapping[str, str] = os.environ)`
    - `view() -> dict`：`{"fields": [{key,label,help,kind,group,choices,value,source,warning}], "error": str | None}`；
      `source` ∈ `default / config / console`，密钥 ∈ `secrets / env / none`；密钥 `value` 是 `mask(...)`；
      `owner` 的 `value` 取 `reply.owner_name`，两处不一致时 `warning = "config.toml 里两处主人昵称不一样：普通模式「A」、大脑「B」，保存会统一"`

      `owner` 同时写 `reply.owner_name` 和 `brain.owner_name`；`secret.llm` 存到 `[env][cfg.llm.api_key_env]`，`secret.claude` 存到 `[env][cfg.brain.token_env]`
    - `secret(which: str) -> str`：`"llm"` / `"claude"` 的当前值（secrets.toml → environ → `_user_env`），没有返回 `""`
    - `effective() -> Config`：`load_config(config.toml, console.toml)`

    - `status() -> dict`：`{"state", "pid", "uptime", "exit_code", "run_dir", "forced", "slow_start", "options"}`（`slow_start` = 启动中超过 `start_notice` 秒；`options` 是 `asdict`）

    - `close() -> None`：`stop()` 并阻塞等到不是 `STOPPING`（面板退出用）
  - 状态转换：监控线程每 0.5 秒看一次；`STARTING` 时 `probe` 通了 → `RUNNING`；进程退出 → 退出码 0 为 `EXITED`、否则 `CRASHED`（`STOPPING` 期间退出一律 `EXITED`，强杀的记 `forced`）
  - 从输出行匹配 `本次运行的日志和截图: (.+)$` 记下 `run_dir`
