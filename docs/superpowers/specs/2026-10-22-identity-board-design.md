# 身份板：外观为主、名字标签证实（设计）

日期：2026-10-22。依据：10-22 晚 live（`runs/20261022-204242-live-brain`，32 分钟、三个好友 + 路人）的日志、图鉴和离线实验（`tmp/vision-1022/`）。
改造感知层里"这个框是谁"的判定（好友 / 团子 / 陌生人），接在认人底库（spec `2026-10-03-identity-gallery-design.md`）之上。
这是两期里的第一期：**流程改造**，用现成的 DINOv2；第二期再训认人头（见 §9）。

## 0. 目标和不做的事

用户的方向（10-03 就定过，这次重申）：**YOLO 只负责把人框出来，认人交给外观（DINOv2），名字标签用来证实**。
现状和这个方向相反：身份靠"这一帧标签离谁最近"和 YOLO 的 `self` 类现判，外观只给"这一帧没挂标签"的人兜底，排在最后、几乎轮不到。

成功的样子（在拥挤录像上量，§7）：
- 好友挤在一起、标签在几个框之间跳时，好友不被判成陌生人（目标：好友的框被判陌生人 ≤ 2%）
- 团子在人堆里也认得出（目标：团子的框认出 ≥ 90%，别人的框被判团子 ≤ 1%），YOLO 不出 `self` 框时也一样
- 拿不准的人按 Q 喊一声确认，不硬判
- 好友 / 团子底库不被认错的样本污染

不做：
- 训认人头（第二期，§9）
- 在场确认喊得太勤（10-22 晚 32 分钟喊了 50 声；另一个问题）
- 拿不准时转镜头去看、走过去看
- 黑影（没点火的人）的认人：没有外观可比，照旧等 `stranger_after` 判陌生人
- 改 YOLO、追踪器、第二层外形头

## 1. 依据（10-22 晚）

- **好友被判成陌生人**：32 分钟编号编到"陌生人AC"（约 29 个），图鉴判成陌生人的 86 条轨迹里能认出饶总、懒洋洋大王（花田里白斗篷粉条纹那一串，好友抽样图里挂着他的标签）和团子自己。
  机制（`perception.py` 862~869）：轨迹 6 挂着"饶总"，下一帧饶总的标签被 `_assign_tags`（每帧纯几何、贪心）分给了旁边的框 → 名字和 `tagged` 一起被摘 →
  它出现早过了 `stranger_after`、好样本也够（是挂着名字时攒的）→ **同一帧判成陌生人A**；外观只在算了新样本的帧跑（每 3 帧），这一帧没轮到。名字被这样摘了 77 次。
- **团子认不出**：171 张难例里 151 张 YOLO 一个 `self` 框都没出，出了的分数多在 0.25~0.5；团子靠"30 秒内记住的位置"（`DANGO_MEMORY`）撑，过期后变回普通人：被判陌生人、还会抢身边好友的标签（被抢的好友又成了陌生人）。
  "self 框和团子连不上"94 次、"轨迹不在团子框上了"68 次；启动转圈只登记到 4 张。
- **底库被污染**：底库只从"这一帧挂着名字"的框学，标签一跳，别人的样子就学进了好友名下（`tmp/vision-1022/friends-sheet.jpg`）。
- **外观本身的能力**（`tmp/vision-1022/loo.py`，362 张挂标签的好友裁图 + 10 张团子，留一最近邻、同一身份取最像一张、排除 10 秒内的帧）：
  DINOv2 73%、颜色 64%；只拿最近 3 分钟当底库 69% / 68%。错得最多的是懒洋洋大王和玛卡巴卡（都是深红长斗篷）；同一个人暗处 / 金光 / 夜里花田几乎是三个样子。
  这组标签里混着上面说的污染，真实能力会高一点，但单帧不够当主判据——所以要按轨迹攒多个样本、带滞回，拿不准就喊。
- **好样本不是瓶颈**：难例帧里 236 个人物框，被别人压住的 33 个、太小的 2 个，其余都能当好样本。

## 2. 结构

```
YOLO 框 + 追踪器（不变）
   │ 每帧：人物轨迹、名字标签、self 框、画面平移
   ▼
perception.py ──喂证据──► vision/identity.py：IdentityBoard（纯计算，不碰画面、不调模型）
   │  · 标签候选（哪个标签可能挂在哪条轨迹上、误差）       每条轨迹一份 Evidence
   │  · 这一帧新算的外观样本对各身份底库的分数              每帧 decide() → Verdict
   │  · 团子线索（self 分数、离团子位置多远、跟不跟背景走）
   │  · 呼喊窗口的结果
   ◄──── 标签分配 + Verdict + 这一帧哪些样本可以学进底库
   ▼
原来的下游照旧：people()、在场、陌生人事件和编号、图鉴、点亮、喊一声、管理面板画面……
```

### 2.1 `vision/identity.py`（新，纯计算）

- `Evidence`（每条轨迹）：标签票（最近挂过哪个名字、连续几帧、第一次稳定的时刻）、外观分（最近 `window` 个样本对每个好友 / 团子底库的最高分）、团子分（平滑后的）、
  接回线索（perception 的 `_relink` 给的名字）、呼喊结果、出现时刻、是不是黑影、面板后面时刻。
- `Verdict`：`kind` ∈ `friend_tag`（标签证实）/ `friend_look`（看着像）/ `dango` / `unsure`（拿不准）/ `stranger` / `pending`（刚出现、证据还不够），
  `name`（好友名，`unsure` 时是最像的那个）、`score`、`since`。
- `IdentityBoard`：
  - `assign_tags(candidates, now) -> {轨迹 id: 标签 id}`：带记性的标签分配（§3.1）
  - `observe(track_id, ...)`：喂这一帧的外观分、团子线索、接回名字
  - `decide(now, track_ids) -> {轨迹 id: Verdict}`：每帧一次，含"团子只有一个""一个名字只给一条轨迹"
  - `learnable(track_id) -> (kind, who) | None`：这一帧这条轨迹的样本能不能学、学进谁（§5）
  - `called(at)` / `call_result(at, shown)`：呼喊窗口开始 / 结束（`shown` = 窗口里亮出名字的轨迹）
  - `forget(now)`：删掉断了的轨迹的证据
- 不持有底库，只拿分数；底库（`AppearanceBook` / `Gallery`）留在原处，学不学由 `learnable` 说了算。

### 2.2 `perception.py`（改）

- `[identity] enabled` 时：每帧把证据喂给 `IdentityBoard`，用它的结果写 `data["name"]`、`data["maybe"]`（好友像）、`data["unsure"]`、`data["dango"]`、`data["stranger"]`、`data["tagged"]`，
  **字段名和含义保持原样**，下游（`people()`、`nearby()`、`unsure()`、身体读 `data["dango"]`、陌生人编号 `_appearance_stranger`、图鉴、点亮、管理面板画面）不改。
- 判身份的老代码（`maybe` / `unsure` / `dango_look` / `_one_dango` / `_mark_dango` 打标记那部分 / 862~919 那段判定）在 `enabled = false` 时**逐字照旧**；`enabled = true` 时不走。
  老代码等新流程真机稳定后再删（另起一次改动）。
- 外观样本照旧在 `_appearance_features` 里算（DINOv2 和第二层共用会话），算完交给 `AppearanceBook` 打分、再交给身份板。
- `_relink`（按位置接回）保留，结果作为证据交给身份板，不再直接写 `maybe`。

### 2.3 配置 `[identity]`（`IdentityConfig`，数字是估的，§7 用录像定）

| 字段 | 默认 | 含义 |
|---|---|---|
| `enabled` | `false` | 关着逐字是旧流程 |
| `tag_hold` | 0.5 | 标签换到另一条轨迹要连续这么多秒才算数 |
| `tag_stick` | 0.5 | 上一帧挂着这个标签的轨迹，分配误差乘这个系数（越小越黏） |
| `window` | 5 | 外观分取最近几个样本的中位数 |
| `min_samples` | 3 | 判"像"/"明显不像"至少几个样本 |
| `friend_feature` | `"dino"` | 好友外观分用哪个特征：`dino` / `color` / `both`（两个平均），§7 定 |
| `match` / `margin` / `unsure` | 沿用 `[appearance]` | 像 / 领先第二名 / 拿不准下限；新流程下用身份板自己的中位分比较 |
| `drop` | 0.03 | 从"像"掉下来要低于 `match - drop` |
| `stranger_low` | 沿用 `unsure` | 对每个好友和团子都低于它才算"明显不像" |
| `dango_w_pos` / `dango_w_look` / `dango_w_self` / `dango_w_pivot` | 0.4 / 0.4 / 0.2 / 0.2 | 团子分四项权重 |
| `dango_min` | 0.5 | 团子分过它才可能是团子 |
| `dango_switch` | 1.0 | 第二名连续比第一名高这么多秒才换团子 |
| `dango_learn` | 0.75 | 团子分过它、没被压住，才学进团子底库 |
| `unsure_wait` | 沿用 `[appearance] unsure_wait` | 拿不准多久后喊 |

`[identity]` 要配合 `[perception]` 和 `[appearance]`（要 DINOv2）；`[appearance] enabled = false` 或 DINOv2 没加载时自动当成关，启动日志一行说明。管理面板设置页加 `identity.enabled`。

## 3. 好友怎么判

### 3.1 标签分配要有记性

- perception 照旧用 `_tag_err` 算每个（轨迹，标签）对的误差，交给 `assign_tags`。
- 上一帧这个标签（按名字认，读不出名字的按标签轨迹 id）挂在哪条轨迹上，那一对的误差乘 `tag_stick`；其余照贪心分配（误差小的先拿，一个标签一条轨迹）。
- **名字的归属要稳定才换**：同一个名字连续 `tag_hold` 秒都分给另一条轨迹，原来那条才失去它。在这之前原来那条保留名字（照旧算这个好友、不判陌生人），但不算"稳定"、不学底库；新那条还不挂这个名字。
- 失去名字的轨迹进 `unsure`（`name` = 失去的那个名字），**不进陌生人**；它之后的外观分说了算。
- 团子轨迹不参加分配（同现在）；身份板判成团子的轨迹不挂名字。

### 3.2 外观分

- 每个新样本对每个好友底库取"最像一张"（`Gallery.best`），存进这条轨迹最近 `window` 个；**中位数**当这条轨迹对他的分数。
- 样本不到 `min_samples` 时外观不下结论（`pending`，等它攒够；最多等 `stranger_after + STRANGER_GRACE`，之后按 §4 处理）。

### 3.3 判定（每帧，带滞回）

1. 标签稳定挂在这条轨迹上 → `friend_tag`（最可信）
2. 没有稳定标签、中位分 ≥ `match`、领先第二名 ≥ `margin` → `friend_look`；一个名字同一时刻只给一条轨迹（分高的拿；已经被 `friend_tag` 占着的名字不给）
3. 已经是 `friend_look` 的，中位分低于 `match - drop` 才掉下来
4. 接回（`_relink` 给了名字）且外观不反对（对他的中位分没低于 `unsure`，或样本还不够）→ `friend_look`，30 秒没被标签证实就摘（同现在的 `RELINK_MAX_KEEPS`）
5. 中位分在 `[unsure, match)`、或刚失去名字 → `unsure`
6. §4 的陌生人条件 → `stranger`；都不是 → `pending`
- 稳定标签一出现就盖掉外观结论；标签和外观对不上（`friend_look` 是小明、标签证实是小红）记一条难例 `identity_conflict`。

## 4. 拿不准、陌生人

- `unsure`：不判陌生人、不编号、不进图鉴陌生人；持续 `unsure_wait` 秒后交给"按 Q 喊一声"确认（复用现在的 `env.unsure(now)` → `Body._watch_call` 那条路）。
  喊完窗口里他身上亮出标签 → 那个好友（这一帧学进底库）；亮在别人身上 / 没亮 → `stranger`。
- **额度共用**现在的自动喊（`[call] min_gap` 20 秒、`auto_window` 1 分钟 `auto_quota` 3 声），在场确认那一声的结果也算数：一声确认画面里所有 `unsure` 的人。
  额度没了就接着等，不新加额度；`[call] auto` 关着 / dry-run 时等满 `unsure_wait + call.window` 判陌生人（同现在）。
- `stranger`（任一条）：
  1. 从没稳定挂过名字、最近 `min_samples` 个以上样本对**每个**好友和团子都低于 `stranger_low`
  2. `unsure` 喊过一声没亮出名字
  3. 黑影：照旧等 `stranger_after`，挂过名字的轨迹不算
  4. 一直攒不到好样本（太远、一直被挡）：照旧等满 `stranger_after + STRANGER_GRACE` 判（这一条不变，否则远处陌生人永远不判）——但**挂过名字的轨迹不走这条**，走 `unsure`
- 陌生人的编号、"又回来了"、`stranger_forget` 照旧（`_appearance_stranger`）。
- 面板挡着标签（`_under_panel`）的规则照旧：面板后面的人不判陌生人，面板关了从关的那一刻起算。

## 5. 团子

### 5.1 团子分

每帧对每条点过火的人物轨迹算四项（都在 0~1），加权求和后按轨迹平滑：

| 项 | 怎么算 |
|---|---|
| 位置 `pos` | 中心离"这个面板状态下团子该在的位置"多远，按团子框宽归一化（0 个框宽 = 1，≥ 1.5 个框宽 = 0）。位置按面板开 / 关分别记、跟着认定的团子框更新，**不过期**；走路、黑屏、转圈后只是暂时不信（这一项给 0.5），等认定的团子框重新更新 |
| 长相 `look` | DINOv2 对团子底库最像一张，减去对每个好友底库最像一张的最大值；> 0 才有分，映射到 0~1 |
| YOLO `self` | 这一帧有 `self` 框和这条轨迹是同一个身体（`same_body`）→ `self` 分数；没有 → **不加不减**（这一项不计入，权重按剩下的重新归一） |
| 不跟背景走 `pivot` | 画面平移超过门槛的帧里，这条轨迹配上的是不带平移的预测框（`Track.drift` 增量接近 0），而大多数人跟着背景走 → 1；跟着背景走 → 0；镜头没转 → 不计入 |

- 每帧团子分最高、过 `dango_min` 的那条是团子；现任团子被别人连续 `dango_switch` 秒反超才换；**稳定挂着名字标签的轨迹永远不是团子**（自己头上没有名字）。
- 被判成团子的轨迹写 `data["dango"]`（下游照旧），不挂名字、不判陌生人、不算"没挂名字的人"。
- 面板开关横移动画（`_panel_slide_until`）里不换团子、`pos` 不计入。

### 5.2 团子底库

- 启动转圈登记照旧（钉住）。
- **运行中补充**：团子分 ≥ `dango_learn`、样本是好样本（没被压住）→ 学进团子底库（`Gallery` 的去重 / 上限照旧，不钉住）。
- `look` 一项在团子底库不到 3 张时不计入（只靠位置 / self / pivot）。

## 6. 底库只从干净的帧学（`learnable`）

| 身份 | 条件 |
|---|---|
| 好友 | 这条轨迹 `friend_tag`、标签已经稳定满 `tag_hold`、这一帧标签只挂在它身上、好样本 |
| 团子 | §5.2 |
| 陌生人编号 | 已经编号、这一帧仍是 `stranger`（同现在） |
| 其余 | `friend_look` / `unsure` / 接回 / `pending` 都不学 |

喊一声后亮出标签确认的那一帧照学（同现在）。

## 7. 评估：拥挤录像 + 半自动标准答案

**录像**（用户晚上录）：好友挤在团子身边 3~5 分钟，来回转镜头、开关面板，最好有一两个路人：`python -m skydango record --seconds 300`。

**`perception identity-truth <录像目录> [--model 模型]`**（新，`vision/identity_eval.py`）：
1. 跑一遍 YOLO + 追踪（同 `track-eval` 的回放方式）；离线能看"未来"：整条轨迹上任何时候**稳定**挂过的名字（≥ `tag_hold` 连续帧）就是这条轨迹的身份；团子按 `self` 高分 + 画面中间初判；其余写 `?`
2. 写 `tmp/identity-truth/<录像名>/truth-draft.toml`（每条轨迹一行 `t12 = "饶总"`，带注释：出现时间、帧数）和 `sheet.jpg`（每条轨迹一格：编号 + 几张裁图）
3. 用户对着拼图改草稿：好友名 / `团子` / `陌生人` / `不要`（YOLO 误框）；改完再跑一次 `--apply` 展开成**每帧每个框**的标准答案 `truth.jsonl`（帧文件名、框、身份），放回录像目录
- 按框（IoU ≥ 0.5）对答案，不依赖轨迹编号：以后改了追踪器照样能用

**`perception identity-eval <录像目录> [--model 模型] [--fps 6.5]`**（新）：同一段录像跑两遍（`[identity] enabled = false` / `true`，其余配置相同），出 `tmp/identity-eval/<时间>/report.md`：

| 指标 | 目标（先估，量完基线再定） |
|---|---|
| 好友的框被判成陌生人 | ≤ 2% |
| 团子的框认出是团子 | ≥ 90% |
| 别人的框被判成团子 | ≤ 1% |
| 好友的框认对是谁（`friend_tag` + `friend_look`）、认错成别的好友 | 记数，和基线比 |
| `unsure` 占比、要喊几声（离线按"喊了全都亮"和"喊了都不亮"各算一次） | 记数 |
| 发了几个陌生人编号 | 和答案里真实的路人数比 |

报告另给门槛建议：扫 `match` / `unsure` / `friend_feature` / `dango_*` 权重 / `tag_hold`，列出满足三条目标的组合。录像回放里外观特征（DINOv2）照算，第一遍算完缓存进 `tmp/identity-eval/_features/`，扫门槛时不重算。

## 8. 出错、兼容、上线

- 身份板出异常：记日志、这一帧沿用上一帧的结论；连续 10 帧出错自动关掉、退回旧流程（status 一行说明）
- `enabled = false`：逐字旧流程（老测试全过）
- 上线顺序：录像 → 标答案 → `identity-eval` 过线 → 本机 `console.toml` 打开 → 真机一晚：数陌生人编号、看图鉴里还有没有好友 / 团子、喊的次数
- 管理面板画面 / status 的"像小明?""可能是小明?""团子"照旧显示（数据从身份板来）；`perception.py` 的 DEBUG 日志多一行每条轨迹的 Verdict 变化（"轨迹 6：friend_tag 饶总 → unsure（标签换到轨迹 9，0.5 秒）"）

## 9. 第二期（不在这次）：认人头

在 DINOv2 上训一个小的认人头（同第二层外形头的路子），把"外观分"换成它的输出；训练数据用 `learnable` 筛出来的干净样本（这期上线后 `runs/<…>/appearance/` 攒的就是）。身份板的接口不变，只换打分。

## 10. 测试（`pytest`，合成证据 / 假检测器）

`IdentityBoard` 单测（合成证据序列）：
