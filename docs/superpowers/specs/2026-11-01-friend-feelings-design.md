# 对每个人的感觉（`[inner] feelings`）

## 0. 起因和目标

内心层有心情、别扭、心愿、老梗，但团子「对一个人怎么看」没有地方放：关系卡（`inner/ledger.py` 的 `Card`）只有次数和时长，
每次反思都从材料重新看起；心情睡一觉回到平常、别扭最长 2 小时。结果是昨天被放鸽子，今天见面完全没有余温；对认识一天的人和对卡洛也差不多。

目标：团子对每个好友有一份**会慢慢变的感觉**——一句印象 + 亲近度档位 + 走向，由下线那次的反思在旧的基础上改写，他来的时候和 status 里带给大脑。

成功的样子：
- 同一个好友上线几次后，印象文字有变化，而且说得出依据（这次或以前发生的具体事）；
- 放鸽子之后印象 / 走向记一笔、亲近度不掉，第二天他来时 arrive 带上，团子语气有余温；
- 认识没几天的人不会被写成「很铁」；不写依恋、吃醋。

不做的见 §7。

## 1. 数据

`Card` 加一个字段 `feeling`（旧卡没有 = 空 dict，`_from_dict` 照旧容忍缺字段）：

```json
"feeling": {
  "text": "嘴贫但靠谱，骗我背背的账还没算",
  "close": "熟了",
  "trend": "平稳",
  "since": "2026-11-01",
  "past": [{"text": "…", "close": "刚认识", "date": "2026-10-20"}]
}
```

- `text`：印象，≤ 40 字（`FEEL_MAX`）。
- `close`：亲近度三档 `刚认识` / `熟了` / `很铁`（`CLOSE_LEVELS`，有序）。
- `trend`：走向三档 `在变近` / `平稳` / `有点生疏`（写盘的只有这三种）。
- `since`：这一版写下的日期（world 的钟，沙盒用沙盒时间）。
- `past`：最近 `FEEL_PAST`（3）版旧的，新的挤掉最旧的；只有 `text` 或 `close` 变了才推一版，只改走向不推。

显示时现算、不写盘的一档：离他上次在身边 ≥ `feel_stale_days`（14）天 → 走向显示「好久没见了」。

只在 live 写盘（同 `people.json` 现有规矩）；dry-run 只在内存里改。

## 2. 谁来写：下线那次的最终反思

只有最终反思（`reflect.py` 里 `final=True` 那次）改感觉；在线每 20 分钟一次的反思不碰（当场的情绪仍由心情 / 别扭管）。

**材料**：现有的最终反思材料之外，多一节「你对他们的感觉」：这次上线**见过或聊过**的每个好友一行——现在的 `text` / `close` / `trend` / `since`，没有就写「还没有印象」；
附一起玩过几天（`len(card.days)`）。好友 friends.md 那一节和关系卡本来就在材料里。

**提示词**（`FEELINGS_SYSTEM`，接在最终反思的系统提示词后面）：
- JSON 多一项 `"feelings": [{"who": 好友名, "text": "…", "close": "…", "trend": "…"}]`；没变化的人不写；
- 在旧印象的基础上改，要有这次或以前的具体依据，不写空话（「人很好」）；
- 一次不愉快只改走向或在印象里记一笔，不降亲近度；亲近度要好几天的积累才往上走；
- 不写依恋、吃醋、「只有他」这类话；外貌身材家里成绩年龄不碰；
- 这次说过难过的人，好好记，不埋怨。

## 3. 代码守的规矩（`inner/feelings.py`，纯函数，照 `Persona.apply` 的路子）

`apply_feelings(cards, proposed, *, met, soft, today, friends) -> (changes, dropped)`：

1. **人**：只认好友名单里的（`similar` 模糊匹配，按最像的好友归）；不在 `met`（这次上线见过或聊过）里的丢——反思见不到他，不该改。
2. **档位**：`close` / `trend` 不在三档里的丢整条；亲近度一次最多变一档（越级的压到相邻那档）；
   `很铁` 要一起玩过 ≥ `feel_close_days`（7）天、`熟了` 要 ≥ `grudge_min_days`（3）天，不够压回能到的最高档。
3. **文字**：超过 `FEEL_MAX` 40 字整条不收（不截半句）；带 `persona.SENSITIVE` 敏感词、`DISTRESS` 难过类的话、`claims_human` 的丢；
   带依恋 / 吃醋词（`CLINGY`：离不开、只喜欢、只要他、吃醋、嫉妒、想独占……）的丢；空的、和旧的几乎一样（`similar ≥ 0.9`）且档位没变的当没变化。
4. **收着点**：这次上线里说过难过的人（`soft`：最终反思的材料里按 `DISTRESS` 现找，不依赖 `[inner] persona`）——`trend` 写了「有点生疏」改成「平稳」；印象里带埋怨词（`GRUMBLE`：烦、讨厌、放鸽子、又迟到、没良心……）的这一条不收，只收档位和走向。
5. 每条丢弃都记原因（`dropped`），和性格档案一样进流水账「没收下的」。

`changes` 写进卡：推 `past`（§1 的条件）、更新 `since`。

## 4. 大脑看到的

- **arrive 事件**：在「你惦记着」「你们的老梗」之前接「。你对他：<text>（<close>，最近<trend>）」；
  没有印象不写；他在收着点里（`Body._soft_until`，或 persona 关着时不判）只写「（<close>）」不带印象；走向按 §1 现算「好久没见了」。`return` 不带。
- **status**：「身边的好友」每人括号里在「一起玩过 N 天」后接档位（「熟了」）；走向是「有点生疏」/「好久没见了」才附上。
- **提示词**：「说话」一节加一句 `FEEL_RULE`：按你对这个人的感觉说话——熟的随意、刚认识的客气点、生疏了可以带点别扭或想他；别把感觉直接说出口（不说「我觉得我们变近了」）。
- **`introspect("关系")`**（introspect 本身只在 `[backstage]` 开着时注册；「关系」和别的话题一样常驻在话题列表里，`feelings` 关着时回「没开」）：列出每个好友的印象、档位、走向和最近一次改写，旧版本按时间。

## 5. 别的地方

- **内心页**（`console/inner_view.py` + `static/inner.js`）：关系卡显示印象、档位、走向、改写日期，旧版本折叠。
- **流水账**（`inner/log.py`）：最终反思那条多「对谁的感觉：旧 → 新」，没收下的照旧列原因。
- **沙盒**：跟着最终反思走，不用另做；`memory/` 重置会带上真记忆里的感觉。
- **配置**：`[inner] feelings = true`（要 `reflect` 开着，`reflect = false` 时等于关）、`feel_close_days = 7`、`feel_stale_days = 14`；管理面板设置页加 `inner.feelings`。
- **`feelings = false`**：反思系统提示词和材料、arrive、status、「说话」一节**逐字照旧**（和不传开关时的输出对照）；卡上已有的 `feeling` 留着不删。
- CLAUDE.md「内心层」加一小节。

## 6. 测试

单元测试（不调模型）：
- `apply_feelings`：不在名单 / 没见过的丢；档位越级压一档；天数不够压回；超长整条不收；敏感词、依恋词、难过词丢；收着点改走向、埋怨印象不收；几乎一样当没变；`past` 只在文字或亲近度变了才推、最多 3 版。
- 反思：JSON 里 `feelings` 解析（缺、不是列表、项缺字段都不炸）；材料「你对他们的感觉」一节只列这次见过的。
- arrive / status 的文字：有 / 没有印象、收着点、好久没见。
- `feelings = false` 逐字照旧（对基准文件）。

沙盒验收（真 DeepSeek，`sandbox-ctl`）：
1. 懒洋洋大王来、聊几句具体的事、下线：卡上出现有依据的印象（说得出是哪件事），档位合理。
2. 跑「放鸽子」（换成懒洋洋大王）：印象或走向记一笔、亲近度不掉；「睡一晚」上线后他来，arrive 带上这句，团子语气里有余温。
3. 一个只一起玩过 1 天的好友聊得很好、下线：反思即使给了「很铁」也被压成「刚认识」/「熟了」以内，流水账里写明原因。
4. 内心页沙盒那一栏看得到印象和旧版本。

## 7. 不做的

- 不加新的模型调用：只用下线那次已有的反思。
- 不给陌生人建感觉（陌生人编号每次上线不复用）。
- 不用数值好感度、不做「好感度变化」提示——档位够用，数字会诱导模型刷分。
- 不让感觉影响主动开口额度、反射概率（先只影响说话；要的话以后接 `effects.py`）。
- 不把感觉写进系统提示词常驻（只在他在的时候占地方）。
