# 聊天的节奏和分寸：攒几句再回、不句句都贱（`[pacing]`）

2026-10-07 晚，用户自己和团子单聊 15 分钟（`runs/20261007-220825-live-brain`）后提出：和 Neuro-sama 比，团子

1. **句句都接**：卡洛说一句它回一句（43 句回了 36 句，几乎都是话音刚落 3~5 秒就回）；Neuro 会看气氛，不是每句都接
2. **句句都贱**：「你才废物，我是可爱」「那是你发的，甩锅给我」「便宜你个头，我这是限量款」……没有一句好好说话；Neuro 是适当犯贱

提示词里早就写着「一轮一般只说一句或者不说」「几句里来一下就够，别句句都贱」，模型照样无视。原因在结构上：

- **节奏是代码定的**：每句聊天进事件队列，`brain/loop.py` 的 `due()` 等 `chat.debounce`（0.8 秒）就叫醒大脑；被叫醒、标着「跟你说：照常接」，几乎一定会回
- **贱不贱全凭模型自觉**：没有东西记着它最近贱了几句；DeepSeek 温度 1.0（10-06 `cheeky` 时提上来的），还会模仿 `history.jsonl` 里自己的旧回复，越贱越贱
- **只做动作不说话**（`emote`）这条路是通的，但提示词没把它当成正经的回法

## 用户定的方向（brainstorming 时选的）

- 不接话的样子：**攒几句再回一句**、**只做动作不说话**、**回得慢一点**（「有时干脆不理」不要）
- 犯贱的分寸：**以正常为底色**，对方先损、心情好、气氛对的时候更容易贱；**连着贱了几句就收一收**
- 方案：身体管节奏（确定的），代码把大脑最近的习惯摆到它眼前当建议，说什么、贱不贱还是大脑看上下文定（不是代码掷骰子替它决定）

## 目标 / 非目标

- 目标：单聊时团子的回复句数降到对方句数的一半左右；贱的句子是少数；连发几句的那种只回一句或者只做个动作
- 非目标：多人聊天里跟谁说（`[addressee]` 管，不改）；主动开口的额度（`[proactive]` 管，不改）；冷场（`[lull]`，不改）；回复内容的其他风格（去 AI 味 10-05 已做）

## 1. 攒话：身体管节奏

新模块 `brain/pacing.py`（纯计算，不碰设备、不读时钟，`now` 由调用方给）：

```python
class Pacer:
    def heard(self, now: float, lines: list[tuple[str, str]], urgent: bool) -> None  # 一批聊天进来：(说话人, 原文)
    def ready(self, now: float, typing: Collection[str]) -> bool   # 攒着的这批该不该交给大脑
    def pending(self) -> bool                                      # 有没有攒着没放的
    def released(self, now: float) -> None                         # 已经放了：清空这一批
```

**规则**（只管聊天：事件 `chat` 和 `aside`；别的都不经过它）：

- 一批的第一句进来时随机定这批的安静时间 `quiet`：`quiet_min` ~ `quiet_max`（默认 2 ~ 6 秒，均匀分布；随机数由构造时传入的 `random.Random` 给，测试用固定种子）
- 放行条件（满足一条即放）：
  1. 最后一句进来后过了 `quiet` 秒，**并且**这批里说过话的人都不在 `typing` 里（读聊天认出的头顶冒点点的好友）。他还在打字就接着等；打完（从 `typing` 里消失）那一刻起重新算 `quiet`
  2. 这批第一句进来过了 `max_wait`（默认 15 秒）：不管还在不在打字，一定放
  3. `urgent`：这批里有一句马上放（下面列的）
- **马上放**（`urgent = True`，等同现在的 `chat.debounce` 0.8 秒）：卡洛的 `#` 主人命令（事件 `owner_command`，本来就不经过 `Pacer`，这里列出来说明不受影响）；说了难过类的话（`inner/mind.py` 的 `DISTRESS`）
- **问句**：这批里有问句（含「？」「?」「吗」「什么」「怎么」「为啥」「啥」「哪」「几」）时 `quiet` 固定取 `quiet_min`，不随机：问了就答得快一点。打字还在的话照样等
- 读聊天退回 OCR（没有 `typing`）：只按 `quiet` 和 `max_wait`

**接到大脑循环**：

- 身体（`Body._heard` 那一圈）把这批交给 `Pacer.heard`；身体每圈查 `Pacer.ready(now, reader.typing())`，到了就**先冒输入气泡（见下）、再放行**
- 扣住 / 放行：身体把聊天事件 `put` 进队列**之前**先调事件队列的 `hold()`（同一圈、同一线程，大脑线程不会在两步之间醒），放行时调 `release()`；`brain/loop.py` 的 `due()` 原来的条件 `events.urgent() and now - last_put >= debounce` 之外再要求 `events.held() is False`。`hold()` / `release()` 只在有聊天攒着时起作用，没有攒着的聊天时别的紧急事件（好友来了、任务结束、冷场）照旧 0.8 秒叫醒
- 攒聊天期间进来的别的紧急事件跟着这一批一起等（最多等到 `max_wait`），一起交给大脑：好友来了晚十几秒说不打紧，免得大脑醒来只看到半批聊天
- 大脑一轮正在跑时进来的聊天照样攒，这一轮结束后按规则放（原来也是这一轮结束后才醒）
- `pending()` 时 status 写「在攒话：小明说了 3 句，等他说完（还在打字）/ 再等 4 秒」，管理面板和大脑都看得到

**输入气泡跟着挪**（`[reflex] bubble`）：现在被叫到当圈就 `_open_bubble`，攒话时会一直挂着。`[pacing] enabled` 时改成**放行那一刻**才冒（`_on_heard` 里只做小动作反射，开框挪到放行前）；冒不了（技能在跑、面板挡着、闹别扭……原来那些拦法）照旧不冒，不影响放行。`bubble_max` 从放行那一刻算

## 2. 回法：代码把最近的习惯摆到大脑眼前

**`say` 加可选参数 `jab`**（布尔，默认 false）：大脑自己标这句算不算犯贱——损人、故意曲解装傻、甩锅、自恋嘴硬、明褒暗贬都算。两种大脑都加：OpenAI 兼容的 schema 只在 `brain/llm_tools.py` 改，Claude 大脑的 MCP 工具在 `brain/tools.py` 改。手动控制的 `say` 不带，算不贱。

身体在 `say` 真的发出去后记一笔 `(时间, jab)`，只留最近 `jab_window`（6）句；dry-run 也记（status 是真的）。被拦下的（重复、主动开口额度……）不记。

新模块 `brain/manner.py`（纯计算）：

```python
def manner(batch: list[tuple[str, str]], recent: list[bool], mood: str | None, sleepy: bool,
           rng: random.Random, cfg: PacingConfig) -> str | None   # 「回法：…」那一行；没什么好提醒的返回 None
```

**规则**（按顺序拼成一行，用「；」连）：

- **贱的分寸**（三选一，按顺序命中即停）：
  - `recent` 里 True ≥ `jab_limit`（2），或者最后一句是 True →「最近 6 句里贱了 N 句，这轮好好说」
  - 心情低落 / 烦，或者精力困（`inner` 的 `Mind.mood` / `energy` 档）→「没力气贫，懒一点回」
  - 心情开心、`recent` 里 True ≤ 1 →「想贫可以贫一句」
  - 都不是：不写这一项，大脑看上下文定
- **只做动作**：这批**没有问句**、**每句都短**（去掉空白 ≤ `short_len` 6 个字）时，按 `emote_chance`（默认 0.3；困了 ×1.5，最多 0.6）提示「这几句可以只回个动作，不用说话」。这批里有难过类的话不提示
- **攒了好几句**：一批 ≥ 2 句 →「他连着说了 N 句，挑最想接的回一句就行，不用每句都回」（多个人说的写「他们」）
- 只在**被聊天叫醒的那一轮**（这一轮取走了 `chat` / `aside` 事件）加；主人命令那一轮、心跳、背景事件都不加
- 写在唤醒消息里事件列表之后、「状态：」之前：`回法：最近 6 句里贱了 3 句，这轮好好说；他连着说了 3 句，挑最想接的回一句就行`

**status 多一项**「最近说的：6 句里贱了 2 句」（没说过话不写）。

## 3. 提示词（`brain/prompt.py`）

- 「说话」一节加回法（`[pacing] manner` 开着时）：
  - 回法有三种，都是正常的：说一句；**只做个动作不说话**（用 `emote`，不 `say`）；对方连着说了好几句，**挑最想接的那句回**，别每句都回
  - 唤醒消息里的「回法：…」是身体根据你最近的样子给的建议，照着来，除非对方在认真问你事情
  - `say` 的时候用 `jab` 照实标出这句算不算犯贱
- `CHEEKY_RULES`（`[inner] cheeky` 开着时）开头那句「嘴欠、贱兮兮是你的本色（……），几句里来一下就够，别句句都贱」改成：
  「**你平时正常聊天，偶尔犯一下贱才好笑**（像个爱犯贱的损友，不是刻薄）。什么时候可以贱：他先损你、你心情好、气氛正热；连着贱了两句就收一收，正常说几句再说」。下面的几招、「刚认识的照常」、刹车那几条一字不动
- `manner = false`：「说话」一节和 `CHEEKY_RULES` 逐字照旧

## 4. 配置（`config.py`，`[pacing]`）

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 攒话；false = 0.8 秒叫醒、被叫到当圈冒气泡（逐字照旧） |
| `quiet_min` / `quiet_max` | 2.0 / 6.0 | 最后一句后安静多久放行（随机） |
| `max_wait` | 15.0 | 一批最多攒多久 |
| `manner` | true | 回法那一行、`jab` 计数、提示词那几句；false = 不加 |
| `emote_chance` | 0.3 | 提示「只回个动作」的概率 |
| `short_len` | 6 | 多少字以内算短句 |
| `jab_window` / `jab_limit` | 6 / 2 | 最近几句里贱了几句就提醒收着 |

数字都是估的。管理面板设置页加 `pacing.enabled` / `pacing.manner` 两个开关。只在大脑模式生效（`--no-brain` 的普通 Agent 不改）；沙盒照样生效（沙盒读聊天没有 `typing`，只按安静时间）。

## 6. 测试

- `tests/test_pacing.py`：安静时间随机且在范围内（固定种子）；在打字接着等、打完重新算；`max_wait` 到了一定放；难过类马上放；问句取 `quiet_min`；OCR（`typing` 为空）只按时间；`released` 后清空；两批之间互不影响
- `tests/test_manner.py`：贱的三档和顺序；最后一句贱也算；短句 + 无问句才提示动作、概率（固定种子，困了加倍有上限）、有难过类不提示；多句提示、多人用「他们」；没什么好说返回 None
- `brain/loop.py`：假时钟 + 假事件队列，攒着聊天时不醒、放行后醒；没攒聊天时别的紧急事件照旧 0.8 秒醒
- 身体：放行前冒气泡、冒不了照样放；`say(jab=True)` 记账、被拦下的不记；status 两项
- 唤醒消息：只在聊天那一轮加「回法」行、位置在「状态：」前
- 提示词 / 工具 schema：`enabled = false`、`manner = false` 逐字照旧（和现在的输出比，存基准）

## 7. 验证

1. **沙盒**（`sandbox-ctl`）：冒充卡洛 2 秒一句连发 5 句 → 攒成一两轮回、看「回法」行；连着损它 10 句 → 数 `jab` 的比例、有没有只做动作的轮次；冒充说「我今天好难过」→ 马上回、不贱
2. **真机**：用户和团子单聊 10 分钟 → `agent.log` 里「回法」行和实际回复对得上；回复句数 / 用户句数（10-07 是 36/43）目标一半左右；问团子问题时不会等太久

## 8. 已知限制

- `jab` 是大脑自己标的，标不准时计数就不准（只当提醒，不拦话）
- 攒话让回复平均慢 3~10 秒；有人觉得慢可以调 `quiet_*`
- 「对方先损你」代码认不出（得懂语义），只在提示词里交给大脑判断
