# 冷场时的心理活动 — 设计

日期：2026-10-01　状态：**代码已完成，还没用真 Claude 验证**

## 背景

用户在沙盒里观察到：好友在身边、聊了几句后安静下来，团子一直不说话，大脑每次心跳只写一句平静的“不说：刚说完，等卡洛回”“不说：卡洛没回，不连着抛话题”。

用户的要求（原话大意）：一直不回复不接话，正常玩家心里会想 **他是不是忙去了、我是不是说错话了、他是不是心情不好**，这些都可以作为心理活动；现在团子内心太平静了。

查沙盒 `/brain` 时间线（2026-10-01 19:39~19:47，10 轮）得到的原因：

1. **规则套错**：状态里写着“上次主动开口…懒洋洋大王接了话 / 这会儿还能主动说 2 句”（护栏放行），大脑却拿「主动开口」一节“上次主动开口没人接，就收一收，别连着抛话题”套在自己的**接话**没人回上。
2. **心跳消息里没有冷场的信息**：只有“没有新事件（定时醒来）”，不知道冷了多久、最后一句是谁说的；「主动开口」一节又处处在收（偶尔、大多数不用说、收一收）。
3. **心跳越不说隔得越久**：好友在身边 45 → 90 → 180 秒，安静下来后约 3 分钟才醒一次。
4. **接话被算成主动开口**：`body.say` 里 `proactive = … not self.brain_busy()`，只看这一轮是不是被聊天叫醒的；被 `arrive` 叫醒时接的上一句话被记成主动开口，白占额度，后面两轮状态里还冒出“刚主动说过，35 秒后才能再主动开口”。
5. 心情只在反思时变（20 分钟一次，或好友说满 6 句后安静 3 分钟），几分钟的冷场在心里没有任何痕迹。

用户选的范围：**三样都要**（心里想、偶尔流露成一句话 / 动作、影响之后的心情和日记）；**两种情况**：① 好友在身边但不说话了；② 好友聊着聊着走了。
“回得敷衍”（要判断语气）和“说好要来却没来”（和惦记 / 别扭重叠）不做。

用户选的做法：**A：身体发现冷场，大脑自己琢磨**（不额外调模型、不用 Haiku 嘀咕器、不用规则模板）。

## §1 冷场怎么认、怎么推进（`inner/lull.py`，纯计算）

`LullTracker`：身体每圈把 现在（墙钟）、身边的好友、聊天（`body.chat` 的 (墙钟, 说话人, 内容)，团子是“我”）交进来，拿回这一圈要叫醒大脑的冷场事件。不碰设备。

### 情况①：好友在身边，不说话了（一次只有一个，对话级）

- **开始**：最后一句话（任何人，包括团子）过去满 `stages[0]`（60 秒），且这句话之前 `talk_window`（300 秒）内有好友说过话（刚才在聊），且这些说过话的好友里至少一个现在还在身边。
  开始时刻 `t0` = 那最后一句的时间，节点都从 `t0` 算。
- **对象**：`talk_window` 内说过话、现在还在身边的好友；写给大脑时，最后说话的那个好友的名字，几个人都在聊时写“大家”（列出名字）。
- **记下**：最后一句是谁说的、说了什么。分两种处境：团子说完没人接 / 好友说完团子没接（后者是团子自己没接，提示词里分开说）。
- **节点**：`stages` = [60, 180, 360] 秒，每到一个叫醒一次；过了最后一个节点不再专门叫醒，冷场慢慢变成普通“安静”，回到平时的心跳。
- **团子在冷场中又说了话**：不重新计时（不然团子一直说就一直停在第一个节点），只更新“最后一句”，叫醒消息里写“这之间你又说了「…」”。
- **结束**：任何好友开口；或对象里的好友都不在身边了（这时有人走开，走情况②）。

### 情况②：聊着聊着走了（每个好友一个）

- **开始**：身体发现好友 X 走开（`_watch_comings` 里原来发 `leave` 的地方）时，X 在 `leave_spoke`（120 秒）内说过话，或团子在 `leave_said`（60 秒）内说过话而当时 X 在身边。
  原来的背景 `leave` 事件换成**立刻叫醒**的 `lull` 事件：“懒洋洋大王 聊着聊着走开了。走之前最后是你说的「…」”（关系账、`_left_at`、牵手推测照旧）。
- **节点**：走开时一次（就是上面那条）；走开后 `stages[1]`、`stages[2]`（180、360 秒）还没回来各一次（“懒洋洋大王 走开 3 分钟了，还没回来”）。
- **结束**：X 回来（原来的背景 `return` 换成立刻叫醒的 `lull` 事件，带“你刚才在想：…”）；或 X 在聊天里说了话（同下面的“结束时”）。
  X 走开不到 `rejoin` 就回来，照样是“回来了”的 `lull` 事件（他确实走开过，团子可能已经想过）。

### 通用

- 两种冷场同时有（一个人走了、另一个人不说话）：各记各的，同一圈到点的合成一条事件。
- **叫醒**：新事件种类 `lull`，**不在** `BACKGROUND` 里（攒 `chat.debounce` 就叫醒）；不受心跳退档影响（心跳退档本身不改）。
- **快进**（沙盒的模拟时钟）：一次跳过几个节点时只叫醒一次，带最新那个节点。
- 跟踪技能（`quiet_people`）在跑时不判情况②（人进出画面是镜头转的）；情况①照常。
- 黑屏（切场景）期间不推进节点，黑屏结束后接着算（不补发错过的节点，只发当前的）。

## §2 大脑那边：想、记

### 叫醒消息

```
[19:47:15] 事件：
- 冷场  懒洋洋大王 1 分钟没说话了。最后是你说的「才不是啦，我只是反应慢，你要牵好我哦」，他没接。
状态：…… / 冷场：懒洋洋大王 1 分钟没说话（最后是你说的「…」）· 在想：（还没想过） / ……
```

第二个节点起状态里带上之前想的：“在想：他是不是去忙了（1 分钟时）”，大脑接着往下想。

### 提示词（新的一节「冷场的时候」，`[lull] enabled` 时加，放在「主动开口」之后）

- 被“冷场”叫醒时，在最后的文字里写一行 **“心里：……”**：这一刻真实的猜测和感受，贴着最后那句话、交情、心情、精力来想（困了就懒得多想）。
  不用每次都往坏处想：“他应该是去忙了”“是不是我那句太黏人了”“算了我自己看会儿风景”都行。
- 想法跟着冷场往前走：刚开始不在意 → 开始猜 → 失落 / 自己找乐子；别每次重复上一次的话。
- 说不说、说什么照旧自己定；心里想的可以流露（“你还在吗”“是不是我说错话啦”、做个动作），别句句追问。主动开口的护栏照旧。
- 好友说完是你没接的那种冷场：是你自己没接，想的是“要不要接”而不是“他怎么不理我”。
- 冷场结束时聊天后面会附“你刚才在想：…”，可以顺口接（“我还以为你不理我了”），也可以当没这回事。

### 身体怎么记

- 大脑循环每轮结束把最后的文字交给身体（`Brain` 新回调 → `body.call` 到身体线程）；`lull.parse_musing(text)` 取最后一行以“心里：”（或“心里:”）开头的，截 60 字。
- **只在有冷场时记**：挂到当前所有活着的冷场上（带墙钟时间和第几个节点）；没写就当没想、不硬凑；不在冷场时写的“心里：”忽略。
- 不加新工具（多一步工具调用，大脑更慢）。

### 结束时

冷场结束那一刻的叫醒事件后面附一句：聊天事件“（冷场了 4 分钟，你刚才在想：是不是我那句太黏人了）”，情况② 的“回来了”事件同样带。
没想过时只写“（冷场了 4 分钟）”。同一次结束只附一次（附在结束它的第一条聊天上）。

## §3 留下的影响、在哪看得到

### 心情和日记（只在内心层开着、开了反思时）

- 冷场结束时（或下线前最终反思时还没结束），身体把这次冷场写成一行，按冷场开始的时间插进反思材料的聊天（`_reflect_chat`、`_session_chat`，说话人写“（冷场）”）：
  “4 分钟，懒洋洋大王没接你的话。你心里想过：他是不是去忙了 → 是不是我那句太黏人了 → 算了。后来他回来说「刚去倒水」”。
- 冷场到最后一个节点算一次“动静”（`reflector.stirred`），反思到点照常跑；不额外加反思。
- 代码不直接改心情：反思看到这一行自己定（变闷、虚惊一场……），日记可能写到。不新增别扭的触发（反思本来就能给，第 2 期的规矩照管）。

### 看得到的地方

| 地方 | 内容 |
|---|---|
| 大脑的 `status` | “冷场：懒洋洋大王 3 分钟没说话（最后是你说的「…」）· 在想：…”（只在冷场期间） |
| 沙盒聊天记录 | 每想一次插一行旁白“── 心里：是不是我那句太黏人了 ──”（同“── 反思：… ──”） |
| 内心页「现在」 | “在想：…”（冷场期间，实时那一份） |
| 流水账 `mind_log.jsonl` | 每想一次一条 `musing`（谁、第几个节点、原话），只在 live 写；内心页的反思记录里显示 |
| 大脑时间线 | 本来就有每轮最后的文字，不改 |

**不写**：`history.jsonl`、随手记（心理活动不是说过的话，写进去模型会当成自己说过）；关系卡（不加“冷场过几次”）。

## §4 顺带的修复、配置、测试

### 顺带修

1. **接话不算主动**（`body.say`）：除了“这一轮被聊天叫醒”，**`proactive.reply_window` 内有好友说过话、而团子在那之后还没说过**的，这句也算接话。状态里不再冒“刚主动说过”的误导。
2. **规则写清**（`PROACTIVE_RULES`）：“没人接”只看状态里“上次主动开口”那一行；你接了话对方没再说，算冷场，看「冷场的时候」。（`[lull] enabled = false` 时只改这一句里的“没人接”定义，不提冷场。）
3. **心跳**：冷场期间由 §1 的节点叫醒，心跳退档不改。

### 配置 `[lull]`（数字都是估的）

| 键 | 默认 | 意思 |
|---|---|---|
| `enabled` | true | 关掉：不认冷场、`leave` / `return` 照旧是背景事件、提示词和状态逐字照旧（修复 1 照样生效，修复 2 只改那一句） |
| `talk_window` | 300 | 最后一句之前多少秒内有好友说过话，才算“刚才在聊” |
| `stages` | [60, 180, 360] | 冷场多少秒时各叫醒一次（情况② 用后两个） |
| `leave_spoke` | 120 | 好友走开时他多少秒内说过话，算聊着聊着走了 |
| `leave_said` | 60 | 好友走开时团子多少秒内说过话，算聊着聊着走了 |
| `musing_max` | 60 | “心里：”一行最多几个字 |

- 只在大脑模式生效；**不依赖内心层**：内心层关着照样叫醒、写“在想”，只是不进反思和流水账。
- 管理面板设置清单加 `lull.enabled`。沙盒默认开着。

### 测试（`python -m pytest -q`）

- `lull.py`：情况① 开始 / 每个节点 / 结束；对方说完团子没接；团子冷场中又说话不重新计时；几个好友；对象都走了；
  情况② 开始条件（说过话 / 团子刚说过 / 都不满足）、后续节点、回来、说话；两种同时；快进跳过节点只发最新；黑屏不推进；`parse_musing`。
- 身体：节点放 `lull` 事件且不是背景；情况② 换掉 `leave` / `return`；“心里：”记到冷场上、不在冷场时忽略；结束时聊天事件附“你刚才在想”；
  结束后反思材料多一行“（冷场）”；最后节点 `stirred`；`enabled = false` 时提示词和 status 逐字不变。
- 修复 1：被 `arrive` 叫醒、之前有没接的好友聊天时 say 不算主动；没有待接的聊天时照旧算主动。

### 用真 Claude 在沙盒验证（还没做）

1. 冒充卡洛聊几句后不说话：1 / 3 / 6 分钟各醒一次，每次写了“心里：”且想法往前走；聊天记录里有旁白、内心页“现在”有“在想”。
2. 冒充卡洛开口：团子接得住刚才的心思（或自然地当没这回事）。
3. 聊着聊着让卡洛走开，过几分钟再回来：情况② 走一遍。
4. “立刻反思”：心情或日记提到这次冷场；流水账里有 `musing`。
