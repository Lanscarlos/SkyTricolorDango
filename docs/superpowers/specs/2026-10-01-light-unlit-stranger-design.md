# 团子主动点亮没点火的陌生人 + 点火后鞠躬（设计）

日期：2026-10-01。技能路线图 G 期的第一步（`docs/superpowers/plans/2026-09-28-brain-skills-roadmap.md`「G0 部分结果」）。
用户 09-30 晚定的目标："一直晾着陌生人也不好"。2026-10-01 brainstorming 定下：**身体自动点、大脑能用规则关掉**；**点完鞠躬，别人给团子点火后也鞠躬**；
**用 3 号键举蜡烛、靠鞠躬放下**（不点屏幕上的图标）。

## 1. 现象（录像 `tmp/record/candle-20260930-b/c/d/`，10 fps）

- 没点火的黑影（YOLO `player_unlit`）站到团子身边时，他身上出现**深色实心圆 + 白色空心火焰，没有白圈**（下面叫"火焰圆盘"；录像 d 第 15~17 秒，圆心约 (1030, 680)，在胸口；
  之后随人移动，第 20 秒起在头顶附近）。用户 09-30 晚点了它：团子举起蜡烛（点没点上见下一条）
- **点上了 = 黑影显出外观**：录像 c 第 35.5~37 秒，黑影身上一阵闪光后变成有衣服颜色的人 → YOLO 从 `player_unlit` 变成 `player`（用户 10-01 指出：判断点没点上是感知层的事）
- 录像 d 第 20.2 秒起圆盘上方冒出**彩虹爱心**，但那个人到第 38 秒**还是黑的** → 彩虹爱心**不是**点上的信号（含义未知），不用它；
  圆盘也不一定消失 → "圆盘没了"也不能当成功信号。同一个人**不点第二次**
- 要区分的另外两种圆圈（game-ops §6）：
  - **白圈 + 火焰** = 陌生人举蜡烛要给团子点火（`candle`，已经会接）
  - **深色圆 + 蜡烛和两只手** = 没点火的陌生人平时的样子（`stranger.png`，不是请求，录像 d 第 18~25 秒左下角那个人）
- 火焰部分用 `assets/social/candle*.png` 的米白剪影能认（0.84）；YOLO 的 `social_ring` 只认白圈，看不到这个圆盘

### 蜡烛键（用户 2026-10-01 说明）

- 快捷轮盘 **3 号格常驻"举蜡烛"**（`wheel.locked_slots` 默认 `[3, 8]`，程序不会覆盖它）：按数字键 3 举起蜡烛，再按一次放下
- **做鞠躬（任何动作）时角色会默认放下蜡烛**
- 点火圆盘也会举起蜡烛，但**点了之后团子会一直跟着那个陌生人走、直到点上为止**（用户说明）——会被陌生人带着走，危险。
  所以**绝不点火焰圆盘**，一律按 3 举蜡烛（原地举着，不会跟人走）、靠鞠躬放下；顺带也不点屏幕、不切触屏模式、不关聊天面板
- 3 号键是开关：只在**自己刚按 3 举起、之后没做过任何动作**时才按 3 放下，别的时候一律不按 3（不知道状态时按会弄反）

## 2. 做法选择

在感知层给出的**黑影框附近**找火焰圆盘（不重训 YOLO、不整图扫）；圆盘只用来判断"这个黑影站在能点火的距离里"，点火本身靠按 3。
没选的：整图扫深色圆盘（慢、误认多，好处只是不开感知层也能用）；YOLO 加新类别（要标数据重训，等以后有数据再说）；点圆盘（会被带着走，见上，**不做**）。
**要打开感知层才有这个功能**；`[perception] enabled = false` 时什么都不做。

## 3. 发现（`vision/candle.py` 新文件，纯函数，感知层线程里调）

- `find_disk(frame, box, classifier) -> Disk | None`：在黑影框向外扩的一块里（左右各扩 0.5 倍框宽、往上扩 0.6 倍框高、下到框底）找：
  1. 米白剪影和火焰模板匹配，`classifier.classify` 认成 `candle`（`stranger` 等别的图标领先就不算）
  2. 火焰外面一圈（环带，半径约 1~1.6 倍火焰高，具体离线量）**暗**：亮度均值 < `disk_dark`，且**没有亮的描边圆环**（有白圈的是 `candle` 请求，交给原来的逻辑）
  返回圆心、半径、分数
- `PerceptionWatcher.process` 里：对每条 `player_unlit` 轨迹（框高 ≥ `stranger_min_height`，远处的不管），每条轨迹最多每 0.3 s 找一次：
  - 找到 → 记在轨迹的 `data`（第一次 / 最后看到的时间、位置）；中途没找到不超过 1.0 s 不重置（火焰会晃）
  - 已经点亮的人是 `player`，不在这一步里，自然不会出请求
  - 连续看到 ≥ `light_after`（3 s）→ 出请求 `Request(STRANGER, "light", 圆心, now, track=轨迹 id)`，放在 `requests["陌生人·点亮"]`（和举蜡烛的 `requests[STRANGER]` 分开，两件事可能同时有）；**一次只出一个**，挑圆盘看到最久的
  - `lit(track_id, pos) -> bool | None`（身体核实用，全靠 YOLO）：这条轨迹现在是 `player` 且连续 `lit_frames`（3）帧都是 → True；
    还是 `player_unlit` → False；轨迹没了（闪光时 IoU 断掉换了 id）→ 看 `pos` 附近（框中心距离 < 1 倍框宽）这 `light_timeout` 内新出现的轨迹：
    是 `player` 且没挂名字标签（不是路过的好友）→ True，没有 → None（人走了 / 跟丢了）。`Tracker` 的 `cross` 组本来就让 `player` ↔ `player_unlit` 翻转时 id 不变，换 id 只是兜底
  - **已处理过的轨迹不再出请求**：身体点过（不管成没成）调 `env.mark_tried(track_id)`，感知层记在一个集合里，轨迹没了就清掉
- 孤儿圆圈（`social_ring` 上面没名字标签）被认成 `candle`、但外环是暗的、没有亮描边 → 不当成举蜡烛的请求（YOLO 以后可能也会框到圆盘）；归到它下面的黑影轨迹上按上面处理
- `Request` 加一个可选字段 `track: int | None = None`，别的请求不填

## 4. 去点（`brain/body.py` 的 `_watch_light`，只在大脑模式）

按 3 要经过轮盘和动作（`EmotePlayer` 在身体里），所以 `light` 由身体处理，`SocialHandler.handle` 跳过 `light`；规则仍用 `SocialHandler.allowed`。

- 新类型 `light`：`KIND_NAMES["light"] = "点亮陌生人"`；不进 `PASSIVE`；`SocialConfig.accept_strangers` 默认改成 `["candle", "light"]`
- 大脑的 `set_request_policy` 的 kind 多一个 `light`（`REQUEST_KINDS`、工具说明、提示词「互动请求」一节各加一句："light 点亮陌生人：没点火的陌生人站到你身边时身体会自动举蜡烛给他点火，不想点可以关"）；只对陌生人
- 状态机（每圈 `_watch_light(now)`）：
  1. **闲着**：有 `light` 请求、`allowed`、`candle_slot` 格子上有东西 → 过护栏（同反射动作：黑屏、技能在跑、面板挡着、输入框开着、牵着手、别的互动请求挂着都先不做；`clear_view("emote")` 过不了不做）→
     按 `candle_slot`（3）键举蜡烛（`_held("wheel")`，走 `wheel` 按数字键的同一条路），记下 `raised_at`、目标轨迹，`env.mark_tried(track)`
  2. **举着**：`env.lit(track, pos)` 为 True → 成功，进"等鞠躬"；过了 `light_timeout`（8 s）还不是 True（还是黑的 / 人走了）→ 失败，按 3 放下蜡烛（只有 `emotes.last_any` 还早于 `raised_at`，也就是之后没做过动作时才按），
     WARNING 日志"举了蜡烛 8 秒他还是黑的（或者走了），不再点他"
  3. **等鞠躬**：见 §5
- 举着的这段时间身体的反射动作（`_reflex_emote`）先不做（动作会放下蜡烛，点火就断了）；大脑的 `emote` 照做，做了就当蜡烛已经放下（按 `last_any` 判断），之后不再按 3
- 不点屏幕：不借聊天面板、不切触屏模式（数字键和面板的关系按现有动作的做法，见 `clear_view("emote")`）
- dry-run：不按键，日志"[dry-run] 会举蜡烛点亮身边的陌生人"，`mark_tried` 照记（免得每圈都打）
- 普通 Agent（`run --no-brain`）不做（没有身体）

## 5. 点完鞠躬（`brain/body.py`，只在大脑模式）

- 触发：§4 点亮成功（团子举着蜡烛），或 `social.handle` 返回的 `handled` 里有 `candle`（团子接受了别人点火，好友、陌生人都算）
- 等 `bow_delay`（先按 2.5 s，离线从录像 c 量点亮闪光多长后改）：身体记一个"到点鞠躬"的时间，主循环到点再做，**不 sleep 卡住身体**
- 用 `_reflex_emote(after_light, why, now)` 做：只用轮盘上已有的动作、不换轮盘；受 `reflex.min_gap` 管、不占大脑的动作冷却；
  黑屏、技能在跑、有请求挂着、面板挡着、刚做过动作时下一圈再试，到点后 5 s 还做不了就放弃
- **放弃时如果是 §4 举起的蜡烛**、之后没做过动作 → 按 3 放下；`after_light = ""` 时点亮成功也直接按 3 放下
- 牵着手时不鞠躬（防万一）；轮盘上没有这个动作也不鞠躬（点亮的情况照上一条按 3 放下）
- 这个动作不受 `[reflex]` 的额度和 `enabled` 开关管（它是点火的收尾，不是闲着的小动作），但会记进反射的计时（`reflexes.done`）

## 6. 告诉大脑

- `light` 请求**不发** `request` 事件（不是对方发起的）。处理过的轨迹感知层不再出请求，所以圆盘还在也不会一直挂在 `_requests` 里，挡住鞠躬、反射和输入气泡
- 成功：背景事件 `accepted`"你举起蜡烛给身边一个没点火的陌生人点了火（他亮起来了）"；鞠躬做了再放 `reflex`"点完火你鞠了个躬"
- status 里举着时写"正在举蜡烛给陌生人点火"；点完 `social.remember` 秒内写"N 秒前你给一个陌生人点了火"

## 7. 配置（`[social]` 新增）

| 键 | 默认 | 说明 |
|---|---|---|
| `accept_strangers` | `["candle", "light"]` | 加上 `light` |
| `candle_slot` | 3 | 轮盘上"举蜡烛"在第几格（按这个数字键） |
| `light_after` | 3.0 | 圆盘连续看到多久才举蜡烛（别点路过的） |
| `light_timeout` | 8.0 | 举着蜡烛最多等多久看他亮起来（举蜡烛点火要一会儿，真机量） |
| `lit_frames` | 3 | YOLO 连续几帧认成 `player` 才算点亮（`[perception]` 里，感知层用） |
| `after_light` | `"鞠躬"` | 点亮别人 / 被点火之后做的动作，空 = 不做 |
| `bow_delay` | 2.5 | 看到他亮起来 / 接受点火后多久再鞠躬（等闪光动画） |
| `disk_dark` | 离线量 | 圆盘外环多暗算暗 |

所有数字都**没在真机上验证**，`disk_dark` / `bow_delay` 白天用录像量，`light_timeout` 晚上量。

## 8. 测试

- 单元测试（`python -m pytest -q`）：
  - `candle.py`：合成画面（黑色人影 + 深色实心圆 + 贴上 `candle.png` 的火焰）认得出；白圈 + 火焰不算；圆盘里换成 `stranger.png` 不算
  - 感知层：同一条黑影轨迹圆盘不到 `light_after` 不出请求、到了出一个；中间断 0.5 s 不重置、断 2 s 重置；`mark_tried` 之后不再出；
    `lit()`：同一条轨迹翻成 `player` 满 `lit_frames` 帧 → True、不满 → False；轨迹没了、原地冒出没名字的 `player` → True；原地没人 → None；冒出来的是挂着好友名字的 → 不算
  - 身体（假设备 + 假 env）：有 `light` 请求 → 按一次 3；`lit` 为真 → 过 `bow_delay` 鞠躬、不再按 3；超时 → 按 3 放下、不鞠躬；
    中途大脑做了动作 → 超时也不按 3；鞠躬一直做不成 → 放弃时按 3；规则关掉 `light` / dry-run / 牵着手 / 3 号格空着 → 不按；不点屏幕；不发 `request` 事件
  - 接受 `candle` 之后过 `bow_delay` 鞠躬，不按 3
- 离线评估（`tmp/` 下的脚本，不进 git）：录像 b / c / d 用 v7 跑感知层 + `find_disk`，人工看一遍标注图：
  圆盘认出率、误认（尤其把 `stranger` 圆盘、白圈火焰认成圆盘）；录像 c 第 33~41 秒那个黑影：YOLO 什么时候翻成 `player`、闪光时轨迹 id 断没断、`lit()` 什么时候为真 →
  定 `disk_dark` / `bow_delay`、核对 `lit()` 的兜底，结论写进 game-ops §6

## 9. 真机验证（晚上）

1. `run --view` dry-run：找两三个没点火的黑影站到团子身边，日志里有"[dry-run] 会举蜡烛点亮身边的陌生人"，路过的不算；`stranger` 图标的人不算
2. live：看团子按 3 举起蜡烛 → 多久黑影亮起来、日志说成功（定 `light_timeout`）→ 过 2~3 秒鞠躬、蜡烛放下；网页上看那个人的框从紫（黑影）变绿
3. 让一个陌生人举蜡烛给团子点火：接受后鞠躬
4. 大脑 `set_request_policy(stranger, light, false)` 后再来黑影：不举蜡烛
5. 结果写进 game-ops §6 的圆圈图标表、3 号键举蜡烛写进 game-ops §4 快捷轮盘

## 10. 待确认（晚上真机）

- 按 3 举蜡烛站在旁边，是不是就会给黑影点上、要多久（定 `light_timeout`）；如果点不上，这个功能先关着（`accept_strangers` 去掉 `light`）再想办法，**不退回点圆盘**
