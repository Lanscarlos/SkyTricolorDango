# 团子主动点亮没点火的陌生人 + 点火后鞠躬（设计）

日期：2026-10-01。技能路线图 G 期的第一步（`docs/superpowers/plans/2026-09-28-brain-skills-roadmap.md`「G0 部分结果」）。
用户 09-30 晚定的目标："一直晾着陌生人也不好"。2026-10-01 brainstorming 定下：**身体自动点、大脑能用规则关掉**；**点完鞠躬，别人给团子点火后也鞠躬**。

## 1. 现象（录像 `tmp/record/candle-20260930-b/c/d/`，10 fps）

- 没点火的黑影（YOLO `player_unlit`）站到团子身边时，他身上出现**深色实心圆 + 白色火焰，没有白圈**（录像 d 第 15~17 秒，圆心约 (1030, 680)，在胸口；
  之后随人移动，第 20 秒起在头顶附近）。点它 = 团子给他点火
- 点上后圆盘上方冒出**彩虹爱心**（录像 d 第 20.2 秒起），**圆盘不消失、人还是黑的**（至少到第 25 秒）→ "圆盘没了"不能当成功信号，
  同一个人**绝不点第二下**（再点会怎样没验证过）
- 要区分的另外两种圆圈（game-ops §6）：
  - **白圈 + 火焰** = 陌生人举蜡烛要给团子点火（`candle`，已经会接）
  - **深色圆 + 蜡烛和两只手** = 没点火的陌生人平时的样子（`stranger.png`，不是请求，录像 d 第 18~25 秒左下角那个人）
- 火焰部分用 `assets/social/candle*.png` 的米白剪影能认（0.84）；YOLO 的 `social_ring` 只认白圈，看不到这个圆盘

### 蜡烛键（用户 2026-10-01 说明）

- 快捷轮盘 **3 号格常驻"举蜡烛"**（`wheel.locked_slots` 默认 `[3, 8]`，程序不会覆盖它）：按数字键 3 举起蜡烛，再按一次放下
- **做鞠躬时角色会默认放下蜡烛** → 点完火鞠躬顺带把蜡烛收起来
- 3 号键是开关：不知道现在举没举着就按，会弄反。所以本设计**不主动按 3**，只靠鞠躬收蜡烛；
  点圆盘后团子会不会自己举起蜡烛、点完是不是一直举着，见 §10 待确认

## 2. 做法选择

在感知层给出的**黑影框附近**找"深色圆盘 + 火焰"（不重训 YOLO、不整图扫）。
没选的：整图扫深色圆盘（慢、误认多，好处只是不开感知层也能用）；YOLO 加新类别（要标数据重训，等以后有数据再说）。
**要打开感知层才有这个功能**；`[perception] enabled = false` 时什么都不做。

## 3. 发现（`vision/candle.py` 新文件，纯函数，感知层线程里调）

- `find_disk(frame, box, classifier) -> Disk | None`：在黑影框向外扩的一块里（左右各扩 0.5 倍框宽、往上扩 0.6 倍框高、下到框底）找：
  1. 米白剪影和火焰模板匹配，`classifier.classify` 认成 `candle`（`stranger` 等别的图标领先就不算）
  2. 火焰外面一圈（环带，半径约 1~1.6 倍火焰高，具体离线量）**暗**：亮度均值 < `disk_dark`，且**没有亮的描边圆环**（有白圈的是 `candle` 请求，交给原来的逻辑）
  返回圆心、半径、分数
- `heart_above(frame, disk) -> bool`：圆盘上方一块（约 1.5 个圆盘直径高）里高饱和、色相分布够散的像素占比 ≥ `heart_min`（彩虹爱心）
- `PerceptionWatcher.process` 里：对每条 `player_unlit` 轨迹（框高 ≥ `stranger_min_height`，远处的不管），每条轨迹最多每 0.3 s 找一次：
  - 找到 → 记在轨迹的 `data`（最后看到的时间、第一次看到的时间、位置）；中途没找到不超过 1.0 s 不重置（火焰会晃）
  - 圆盘上方已经有彩虹爱心 → 这条轨迹记为"已点过"，不再出请求
  - 连续看到 ≥ `light_after`（3 s）→ 出请求 `Request(STRANGER, "light", 圆心, now, track=轨迹 id)`，放在 `requests["陌生人·点亮"]`（和举蜡烛的 `requests[STRANGER]` 分开，两件事可能同时有）；**一次只出一个**，挑圆盘看到最久的
  - **已处理过的轨迹不再出请求**：社交那边点过（不管成没成）会调 `env.mark_lit(track_id)`，感知层记在一个集合里，轨迹没了就清掉
- 孤儿圆圈（`social_ring` 上面没名字标签）被认成 `candle`、但外环是暗的、没有亮描边 → 按 `light` 处理（YOLO 以后可能也会框到圆盘，别把它当成举蜡烛的请求）
- `Request` 加一个可选字段 `track: int | None = None`，别的请求不填

## 4. 去点（`game/social.py`）

- 新类型 `light`：`KIND_NAMES["light"] = "点亮陌生人"`；不进 `PASSIVE`（是要处理的）；`SocialConfig.accept_strangers` 默认改成 `["candle", "light"]`
- 大脑的 `set_request_policy` 的 kind 多一个 `light`（`REQUEST_KINDS`、工具说明、提示词「互动请求」一节各加一句："light 点亮陌生人：没点火的陌生人站到你身边时身体会自动给他点火，不想点可以关"）；只对陌生人
- `SocialHandler.accept` 对 `light` 走同一套：先截图确认圆盘还在（用 `find_disk`，找不到返回 None → 过 `RETRY` 秒再看）→ 借面板（`close=False`）→ 键盘模式先点一下唤醒 → **只点一下** →
  `_wait_lit`：每 `check_delay` 截一张，`light_timeout`（5 s）内圆盘上方出现彩虹爱心 = 成功，否则失败。**不补点**
- 点过（成功或失败）都 `env.mark_lit(track)`；冷却按轨迹记，不按"陌生人"这个名字（不同陌生人不互相挡）
- 失败：WARNING 日志"点了陌生人身上的火焰，5 秒内没看到彩虹爱心，不再点他"，不发事件
- 其余护栏和现在接请求一样：输入框开着不点、`clear_view("social")` 过不了不点、adb 出错退避、dry-run 只打印"[dry-run] 将会点亮陌生人"

## 5. 点完鞠躬（`brain/body.py`，只在大脑模式）

- 触发：`social.handle` 返回的 `handled` 里有 `light`（团子点亮了别人）或 `candle`（团子接受了别人点火，好友、陌生人都算）
- 等 `bow_delay`（先按 2.5 s，离线从录像量爱心动画多长后改）：身体记一个"到点鞠躬"的时间，主循环到点再做，**不 sleep 卡住身体**
- 用 `_reflex_emote(after_light, why, now)` 做：只用轮盘上已有的动作、不换轮盘；受 `reflex.min_gap` 管、不占大脑的动作冷却；
  黑屏、技能在跑、有请求挂着、面板挡着、刚做过动作时下一圈再试，点完 `bow_delay + 5 s` 还做不了就放弃（不再排队）
- 牵着手时不鞠躬（接点火不会牵手；这是防万一）；`[social] after_light = ""` 关掉；轮盘上没有这个动作也不做（`_reflex_emote` 之前查 `_wheel()`）
- 这个动作不受 `[reflex]` 的额度和 `enabled` 开关管（它是点火的收尾，不是闲着的小动作），但会记进反射的计时（`reflexes.done`）
- 普通 Agent（`run --no-brain`）只点火、不鞠躬

## 6. 告诉大脑

- `light` 请求**不发** `request` 事件（不是对方发起的）。处理过的轨迹感知层不再出请求，所以圆盘还在也不会一直挂在 `_requests` 里，挡住鞠躬、反射和输入气泡
- 成功：背景事件 `accepted`"身体给身边一个没点火的陌生人点了火（他头上冒了彩虹爱心）"；鞠躬做了再放 `reflex`"点完火你鞠了个躬"
- `SocialHandler.describe` 照旧（"N 秒前你接受了 陌生人 的点亮陌生人"改成"N 秒前你给一个陌生人点了火"）

## 7. 配置（`[social]` 新增）

| 键 | 默认 | 说明 |
|---|---|---|
| `accept_strangers` | `["candle", "light"]` | 加上 `light` |
| `light_after` | 3.0 | 圆盘连续看到多久才点（别点路过的） |
| `light_timeout` | 5.0 | 点完等多久看彩虹爱心 |
| `after_light` | `"鞠躬"` | 点亮别人 / 被点火之后做的动作，空 = 不做 |
| `bow_delay` | 2.5 | 点完多久再鞠躬（等爱心动画） |
| `disk_dark` / `heart_min` | 离线量 | 圆盘外环多暗算暗、彩虹像素占比多少算爱心 |

所有数字都**没在真机上验证**，`disk_dark` / `heart_min` / `bow_delay` 白天用录像量。

## 8. 测试

- 单元测试（`python -m pytest -q`）：
  - `candle.py`：合成画面（黑色人影 + 深色实心圆 + 贴上 `candle.png` 的火焰）认得出；白圈 + 火焰不算；圆盘里换成 `stranger.png` 不算；圆盘上方画一块彩虹色 → `heart_above` 为真
  - 感知层：同一条黑影轨迹圆盘不到 `light_after` 不出请求、到了出一个；中间断 0.5 s 不重置、断 2 s 重置；`mark_lit` 之后不再出；有彩虹爱心的不出
  - 社交：假设备上 `light` 只点一下（键盘模式两下：唤醒 + 真点）；等到爱心 → True；超时 → False 且不补点；两种都 `mark_lit`；dry-run 不点；规则关掉 `light` 不点
  - 身体：`handled` 里有 `light` / `candle` → 过 `bow_delay` 做 `after_light`；没到时间不做；`after_light = ""` / 轮盘上没有 / 牵着手时不做；`light` 请求不发 `request` 事件
- 离线评估（`tmp/` 下的脚本，不进 git）：录像 b / c / d 每帧跑 `find_disk` + `heart_above`（黑影框用 v7 模型现出），人工看一遍标注图：
  圆盘认出率、误认（尤其把 `stranger` 圆盘、白圈火焰认成圆盘）、爱心从出现到稳定多久 → 定 `disk_dark` / `heart_min` / `bow_delay`，结论写进 game-ops §6

## 9. 真机验证（晚上）

1. `run --view` dry-run：找两三个没点火的黑影站到团子身边，日志里有"[dry-run] 将会点亮陌生人"，路过的不算；`stranger` 图标的人不算
2. live：点一个，看团子是不是只点了一下、彩虹爱心出来、日志说成功、过 2~3 秒鞠躬
3. 让一个陌生人举蜡烛给团子点火：接受后鞠躬
4. 大脑 `set_request_policy(stranger, light, false)` 后再来黑影：不点
5. 结果（包括再点一下会发生什么，如果不小心看到了）写进 game-ops §6 的圆圈图标表；3 号键举蜡烛写进 game-ops §4 快捷轮盘

## 10. 待确认

- 点圆盘时团子会不会自己举起蜡烛、点完是不是一直举着（决定鞠躬做不成时要不要补一步放下蜡烛）；
  圆盘是不是要团子先举着蜡烛（按 3）才出现（如果是，"主动点"就要先按 3 再等圆盘）
