# YOLO 只框人，点没点火交给外形头（视觉重构 A）

日期：2026-11-04。状态：设计已和用户逐节确认，待写计划。

## 0. 背景和整体路线

11-02 晚的真机上陌生人被编了 55 个号（实际约 6 人），团子转视角时被判成陌生人；11-02 / 11-04 的离线实验（`tmp/reid-spike/`）说明长相本身分不太开：
现成模型里最好的 SigLIP-base / so400m AUC 只有 0.75 左右，自己训的认人头更差。问题出在结构上：谁是谁有好几条路径各判各的
（`_mark_dango` 和 self 连续性、认装扮三档、接回、身份板、在不在场、按 Q），每次真机出错就在某一条上打补丁。

视觉模块往这个方向重构：**YOLO 只负责框出东西在哪；DINOv2 外形头判"是哪种人"；身份交给一个统一的身份层**
（名字标签 > 团子位置 > 位置连续 > 长相）。拆成四个子项目，各自 spec → 计划 → 实现：

| | 子项目 | 依赖 |
|---|---|---|
| **A** | **YOLO 只框定**（本文）：`player` / `player_unlit` / `spirit` 合成一类"人"，点没点火 / 先祖交给外形头 | — |
| B | 团子靠位置定：镜头支点 + 身体自己的按键，替代 YOLO 的 `self` 类，做完后 `self` 也并进"人" | — |
| C | 统一身份层：无障碍名字接进认人，认装扮三档、`_mark_dango`、接回并进来 | B |
| D | 陌生人编号：按位置接回、晚发编号、允许合并 | C |

A 的好处：标 YOLO 数据时人只标"人"，不用再分点没点火 / 先祖（这件事外形页确认）；同一个人出 `player` + `player_unlit` 两个框（`merge_people` 那一串）自然消失。
外形头的数据已经够：`datasets/attrs/form` 点过火 4041、黑影 1650、不是人 244、先祖 41、共享空间 11、变身 2。

**A 里保留 `self` 类**（用户选的）：认团子的那一串（`_mark_dango`、身份板、点亮找团子周围、换角度、光圈）这一期不动，留给 B。

## 1. 模型怎么认、点没点火从哪来

### 1.1 单类模式

- 合并训练出来的模型，类别号不变：0 号叫 `person`，4 号、9 号叫 `unused_4` / `unused_9`（没有样本），其余同 `datasets/sky/data.yaml`。
- 感知层加载模型时看类别名：0 号是 `person` → **单类模式**；否则（v10 等）逐字照旧。不加配置开关。
- 单类模式下 YOLO 的 0 号框在内部仍当 `player`（轨迹 `cls` 照旧），下游按类别名判断的代码不用改；`unused_*` 万一出框直接丢掉。
- status 和管理面板「真机团子」页写明"感知：单类模式"。

### 1.2 点没点火（`PersonAttrs.is_unlit` / `unlit_score`）

- **单类模式 + 外形头开着**：YOLO 那一侧没有信息，`unlit_score` 只看外形头（`yolo_w` 不生效），滞回（0.4 / 0.6）和 `flip_votes` 照旧。
- **单类模式 + 外形头关着 / 自己关掉了**：按 `candle.black()` 判。每条轨迹每 `[attrs] every` 秒量一次（排除团子框，同点亮陌生人的量法），
  最近 `votes` 次取中位数，≥ 新配置项 `[attrs] dark_unlit`（先估 0.5，同图鉴 `dark_max` 的量）算黑影，滞回和 `flip_votes` 同上；量不准（`None`）不投票。
  status 写"点没点火：按亮度估（外形头没开）"。`[attrs] enabled = false` 时也走这条（`PersonAttrs` 不加载模型、只做亮度这一半）。
- **旧模型**：逐字照旧。

### 1.3 跟着变的地方

- `merge_people`：单类模式下没有两类框，自然不触发，不改。
- 难例 `unlit_vs_player`：单类模式下改成数 `is_unlit` 结果翻转的次数（`Track.flips` 的来源换掉）。
- 点亮陌生人（`lighting.py` 的"下面的人 YOLO 认成 `player_unlit`"）、`_people_boxes` 里"是不是黑影"那一位：改读 `is_unlit`。
- 低分框复核（`open_low`）照旧，单类模式下只对 `player` 一类开。
- **先祖**：单类模式下 YOLO 不再出 `spirit` 框，只靠外形头投票（`_other_form`）；圆圈归属（`ring_spirits`）只用外形头那一路。
  外形头关着时先祖当普通的人（"先祖不算陌生人"这条丢了，接受）。

## 2. 训练数据和工具

### 2.1 合并视图（新模块 `vision/merged.py`，纯文件操作）

- `build(dataset, out) -> Path`：把 `datasets/sky` 的 `images/{train,val}` 硬链接到 `out/images/…`（失败就复制），`labels/` 逐行改类别号：`4`、`9` 改成 `0`，其余照抄；
  增强图（`_blur` / `_dark`）是普通文件，跟着一起处理。写新的 `out/data.yaml`（`path` 指 `out`，names 按 1.1）。返回 `data.yaml` 路径。
- `datasets/sky` 本身一个字节不动（细分标注还给外形头回放当答案）。

### 2.2 训练和对比

- `[retrain]` 加 `merge`（默认 `true`）：`perception retrain` 先在 `tmp/retrain/<时间>/merged/` 建合并视图再训；`false` 照旧用原数据集。
- 回放对比、ultralytics val 也用合并视图：旧模型的 `player` / `player_unlit` / `spirit` 都算成 `person`，新旧在同一套答案上比。
- 模型名照旧 `sky-yolo-v<N>.pt`；报告写明"单类模式"。管理面板"换上 / 回退"不用改。

### 2.3 标注工具

- 收件箱整理（`inbox process`）：单类模式下 YOLO 说是人、外形头最高的人形类把握 ≥ `[inbox] agree` → 一致、自动确认，写回 `datasets/sky` 用外形头的类别（`FORM_CLS`：点过火 / 共享空间 / 变身 → 0、黑影 → 4、先祖 → 9），新帧照样带细分信息；拿不准的照旧交外形页。
- 整帧页、Claude 辅助标注（`assist` / `objlabel`）：类别列表不动；提示词和人工标注规则改成"点没点火拿不准就标 `player`"。
- 外形头回放评估（`attrs-eval` / `attrs_train` 的整帧回放）：答案只取标了 `player_unlit` / `spirit` 的框和外形页确认过的框；只标 `player`、没确认过的框不计分（以前当点过火）。

**不动**：`self` 类、物品和气泡类别、外形头训练（本来就从 `datasets/attrs` 来）。

## 3. 验收

### 3.1 离线门槛（合并视图的验证集，写进重训报告）

1. **找人不变差**：新模型 `person` 的召回、精确率 ≥ **同一份数据、同设置按多类训的对照**三类合起来的值，答案要不偏向任何一个模型。
   （11-04 改：原来写的是 ≥ v10，但验证集 10-04 是拿 v10 补全的，偏向 v10，见 `docs/progress/2026-09-28-yolo-training.md` 11-04 晚一节）
2. **点没点火判得准**：整帧回放（答案按 2.3），单类模式下外形头单独判的准确率 ≥ 现在 v10 + 外形头一起投票。
3. **备用判法**：只用 `black()` 中位数判，在同一批框上报准确率、给出建议的 `dark_unlit`。只记录，不设门槛。

### 3.2 真机验证（晚上做）

1. 管理面板"换上"新模型，status 有"感知：单类模式"。
2. 有黑影陌生人时画面标成黑影、算陌生人；点亮陌生人能举蜡烛、判点亮。
3. 好友鞠躬、背光站着不被判成黑影（10-03 双框问题的老样本）。
4. 设置页关掉外形头：按亮度估照样能跑，status 写明原因。
5. 回退到 v10，一切照旧。

### 3.3 测试

- 合并视图：类别映射、硬链接 / 复制、增强图、`data.yaml`。
- 单类模式识别：按类别名判断；旧模型不受影响。
- `is_unlit`：外形头开 / 关 / 中途自己关掉三种；亮度投票的滞回和 `None`。
- 难例翻转计数、点亮陌生人读 `is_unlit`、收件箱单类模式的自动确认。
- 旧模型逐字照旧：现有测试全部照样通过。

## 4. 风险

- 外形头单独判点没点火，没有 YOLO 那一票兜底：外形头在新场景（光照、地图）上认错时没人纠正。门槛 2 在验证集上兜一层，真机第 3 步再看。
- 亮度备用判法：黑斗篷的好友会被判黑影。只在外形头用不了时生效，而且好友有名字标签、不会因此被判陌生人。
- 单类模型的 `person` 分数分布和 v10 不同，`conf` / `low_conf` 等阈值可能要重对；重训报告里列分数分布。
