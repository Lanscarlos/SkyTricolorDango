# 身份答案标注页（管理面板「标注 → 认人」）

日期：2026-10-27（10-26 晚开始讨论）。上游：身份板 `2026-10-22-identity-board-design.md`，进度 `docs/progress/2026-10-22-identity.md`。

## 0. 为什么做

身份板上真机之前，要先在拥挤录像上过 `identity-eval` 的三条线，这需要一份标准答案。
10-26 晚录了 `tmp/record/20261026-224826/`（300 秒、6.5 fps），`perception identity-truth` 生成的草稿有 140 条轨迹、3060 个框，
其中 8 条轨迹挂过两个名字（约 18% 的框，标签跳到邻居或追踪器换了人）——正是最该考的。
对着 `sheet.jpg` 手改 `truth-draft.toml` 工作量太大，而且一条轨迹只能写一个名字，换了人的轨迹标不对。

目标：在管理面板「标注」页里按键标完这份答案，覆盖率到 90% 左右就能跑评估。成功 = 用户在一个晚上内标完这段录像，`--apply` 写出的 `truth.jsonl` 能直接给 `identity-eval` 用。

已定（用户选的）：
- 换了人的轨迹**能在某一帧切开**，前后分开标。
- `truth-draft.toml` 仍是**唯一**的答案文件，页面和命令行读写同一份。
- 生成草稿、`--apply`、`identity-eval` 留在命令行，页面不做。

## 1. 数据格式

### 1.1 草稿

单个名字的写法照旧：

```toml
t147 = "玛卡巴卡"  # 出现 44.3~70.3 s，103 帧
```

新增分段写法：一个数组，每项 `[开始秒数, 名字]`，按开始时间从小到大：

```toml
t528 = [[0, "玛卡巴卡"], [150.3, "懒洋洋大王"]]  # 出现 140.2~160.8 s，96 帧
```

- 第一段的开始时间必须 ≤ 这条轨迹的第一帧（页面写 0）；段与段之间不留空，后一段开始即前一段结束。
- 名字只能是好友名（friends.md 的 `## 标题`）/ 团子 / 陌生人 / 不要 / ?。
- 页面重写草稿时保留每行原来的注释（出现时间、帧数）和文件开头的说明行，行顺序按轨迹编号。

### 1.2 落到每一帧（`apply_draft`）

每一帧的时间取 `logs.json` 里这条轨迹的 `times`（和 `frames` 一一对应；缺 `times` 时从帧文件名 `NNNN_SSS.SSs.jpg` 解析）。
帧落在「开始时间 ≤ 帧时间」的最后一段；名字是「不要」或「?」的段不写进 `truth.jsonl`。单个名字等价于 `[[0, 名字]]`。

校验照旧「先全部验完再写」，新增几条报错（都带行号）：分段不是 `[数字, 字符串]`、开始时间不递增、第一段晚于第一帧。

## 2. 后端：`console/identity_truth.py`

`IdentityTruth(root=Path("tmp/identity-truth"), friends=callable)`，`server.py` 挂在 `/api/identity/*`（和 `/api/gesture/*` 等同一套 Host 校验、`post_guard`）：

| 接口 | 做什么 |
|---|---|
| `GET /api/identity/runs` | `root` 下有 `truth-draft.toml` + `logs.json` 的子目录 |
| `GET /api/identity/state?run=` | 轨迹列表：编号、帧数、出现时间、每帧的时间 / 帧名 / 框 / 挂的名字、初判（`draft_identities` 现算）、当前标注（分段）、是否挂过两个名字；好友名单；覆盖率；草稿修改时间 `mtime` |
| `GET /api/identity/crop?run=&track=&frame=` | 从录像（`logs.json` 的 `source`）读那一帧、按框裁图（四周留一点余量），太小放大到固定高度，JPEG |
| `GET /api/identity/frame?run=&frame=` | 整帧 JPEG（缩到页面用的宽度） |
| `POST /api/identity/label` | `{run, track, segments, mtime}`：改一条轨迹的分段 |
| `POST /api/identity/undo` | `{run, mtime}`：退回上一版 |

- **看过哪些**：草稿里初判本来就写着名字，采纳初判时文件不变、分不出看没看过，所以页面标过的轨迹编号另记在同目录 `reviewed.json`（`label` 时加进去，撤销时按旧状态还原）。
  草稿里和初判不一样的行（命令行 / 编辑器改过的）也算看过。`apply_draft` 不读它，只给覆盖率和「没标的」筛选用。
- **写盘**：先校验（名字、分段规则同 §1），再把当前草稿存成 `truth-draft.toml.bak`，写临时文件再替换。校验不过或写失败 → 返回错误，草稿不动。
- **撤销**：`.bak` 只存一版；连按撤销靠前端的操作栈：前端记下每次改之前的分段，撤销就把旧分段再 `label` 一次。`/undo` 只在前端栈丢了（刷新过页面）时用，退回 `.bak` 那一版。
- **并发**：请求带上读到的 `mtime`，和文件对不上返回 409「草稿在别处改过，刷新一下」，不硬盖（两个页面同时开、或者用户在编辑器里改了）。
- **好友名单**：当前配置的 `memory_dir` 下的 friends.md（本机 `private/memory`），每次 `state` 现读。读不到就只给团子 / 陌生人 / 不要 / ?，`state` 里带一句提示。
- **路径**：`run` 只认 `root` 下真实存在的子目录名（不带 `/`、`..`）；`frame` 必须是这条轨迹 `logs.json` 里出现过的帧名；录像目录不在了返回明确的错误。
- 草稿 TOML 坏了：`state` 返回错误和行号，页面显示出来，不覆盖。
- 团子在跑也能用：只读 `tmp/`，不碰设备。

## 3. 页面：「标注」页第五个标签页「认人」

`console.html` 的 `#lb-tabs` 加 `data-tab="identity"`，新文件 `static/identity.js`（分段的纯函数放在能被 node require 的部分），样式进 `console.css`（颜色只用 `var(--…)`）。

**顶栏**：选录像（`runs`）；进度「已标 2510 / 3060 框（82%）」（= 看过的轨迹里不在「?」段上的框，看过的定义见 §2），到 90% 变绿并提示去命令行跑 `perception identity-truth <录像> --apply` 和 `perception identity-eval <录像>`。

**左栏：轨迹列表**
- 按框数从多到少排；1~2 帧的碎轨迹自然排在最后，可以不标。
- 每行：`t147 · 103 帧 · 44.3~70.3 s · 初判 玛卡巴卡 → 现在：玛卡巴卡 | 懒洋洋大王`；挂过两个名字的打醒目标记。
- 筛选：全部 / 没标的 / 挂过两个名字 / 「?」。

**中间：选中的轨迹**
- **名字时间线**：一条横带，每帧一格，按挂的名字上色、没挂是灰的；点一格跳到那一帧的裁图。用来找标签在哪一帧跳到了别人身上。
- **裁图条**：沿时间均匀挑约 12 张裁图，每张下面写时间和这一帧挂的名字；「展开」显示全部帧。
- **分段色带**：裁图条下方按当前分段上色、写名字。
- **点一张裁图**（或用方向键选中）→ 右边显示整帧：这个框加粗，别的框淡着画。

**按键**（只在这个标签页显示时绑，输入框有焦点时不吃键）
- `1`~`9`：好友（页面列出编号对应谁）；`D` 团子、`S` 陌生人、`X` 不要、`0` 改回「?」——作用到选中裁图所在的那一段。
- 回车：采纳初判（整条轨迹一段）。
- `/`：在选中的裁图前面切一刀；`Backspace`：删掉离选中裁图最近的切点。相邻两段同名自动合并。
- `←` / `→`：在裁图之间移动；`J` / `K`：下一条 / 上一条轨迹；`Z`：撤销。
- 标完一条（没有「?」段）自动跳到下一条没标的。

写盘失败或 409：这一下不算，提示条说原因，页面上的分段退回去，撤销照常能用。

## 4. 测试

- `apply_draft`：单个名字、分段、切点正好落在某一帧、第一段从 0 开始、「不要 / ?」段被跳过、各种格式错误带行号且不写文件。
- 草稿读写往返：分段和单名混写、注释和说明行保留、按编号排序。
- `IdentityTruth`：`state` 的覆盖率（采纳初判算看过、手改过的行算看过）和「挂过两个名字」、`label` 校验失败草稿不动、`.bak`、`mtime` 不对返回 409、friends.md 读不到、坏 TOML、非法 `run` / `frame`、录像目录不在。
- 前端纯函数（node）：切开、删切点、同名合并、按段改名、覆盖率。
- 页面接口走 `server.py` 的现有测试写法（Host、`X-Skydango`、JSON）。

## 5. 不在这一期

页面里生成草稿 / 跑 `--apply` / 跑评估；多段录像的汇总；陌生人分 A / B 编号（答案里只有「陌生人」一种，和 `identity-eval` 现在的格式一致）；改 `identity-truth` 生成草稿的方法。

## 6. 验证

1. 在个人电脑上开管理面板，选 `20261026-224826`，标几条长轨迹和一条挂过两个名字的（切开、前后分开标），刷新页面还在，`Z` 能退回去。
2. 编辑器里同时改一行草稿，页面再标一下应提示刷新、不覆盖。
3. 标到 90%，命令行 `--apply` 成功写出 `truth.jsonl`，抽查切开那条轨迹前后的框名字对。
4. `identity-eval` 能读这份答案跑完。
