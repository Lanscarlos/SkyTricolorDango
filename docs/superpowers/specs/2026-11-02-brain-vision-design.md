# 大脑直接看图（`[brain.vision]`）设计

日期：2026-11-02　状态：设计已和用户逐节确认，待写计划

## 0. 起因和目标

团子的感知层（YOLO + OCR + 第二层 + 认装扮 + 身份板……）认错人、认不清交互图标时，写进 status 的文字口气和确凿的事实一样。
OpenAI 兼容的大脑（默认 `deepseek/deepseek-flash`）从来没亲眼看过画面：唤醒消息里只有文字，`look(image=true)` 等工具拿到的原图也先交给眼睛写成文字（代看）。
结果是大脑照着错的描述流畅地说话，自己发现不了。

`deepseek-flash`（DeepSeek-V4.1-Flash-1017）官方支持图像理解，内置供应商表里已经勾了「能看图」，眼睛那条路一直在给它发图。
**目标**：大脑能直接看画面，用截图核对感知层的说法，对不上时以截图为准，并把「核对」写下来（顺带攒感知层错误率的样本）。

**不做**：替代感知层认人（远处标签淡掉的小人，大脑看图也未必认得出）；Claude 大脑的自动附图；沙盒（没有画面）；让眼睛少看。

## 1. 探针（2026-11-02，一次性脚本，不进仓库）

同一张真机截图（`runs/20261101-214620-live-brain/hard/215749_low_conf.jpg`：团子 + 懒洋洋大王 + 聊天面板），真的工具定义，系统提示词约 3600 token：

| | 图的 prompt token | 一轮用时 | 发现框标错 |
|---|---|---|---|
| 1280×720 带编号框 | ≈ 580 | 7~9 秒 | 3/3 |
| 960×540 带编号框 | ≈ 310 | 8~9 秒 | 2/2 |
| 640×360 | ≈ 190 | — | 没测 |
| 不给图 | 0 | 13~14 秒 | 0/2 |

- 「标错」= 状态里把懒洋洋大王写成「陌生人A（没看到名字）」。有图的 5 次都在「核对」里指出了；不给图时它连调 `look` / `look_at` / `look_person` / `look_around` 想看，6 步用完也没确认。
- tool 消息后面紧接一条带 `image_url` 的 user 消息，接口照收，模型照常调 `say`；图可以命中前缀缓存。
- 真机大脑每次请求约 6.3 万输入 token（`runs/20261101-214620-live-brain/brain.jsonl`，98% 命中缓存），一张 960×540 只多约 0.5%。
- 局限：这张图名字标签亮着、只有两个人，难度低；系统提示词短，真机上下文 6 万多，要复测。

## 2. 什么时候给图

### 2.1 工具返回的图直接给大脑

`sees()`（`cli._run_brain`）从「只有 Claude Code 大脑、模型勾了能看图」改成「大脑现在用的模型勾了能看图」（OpenAI 兼容的也算），且 `[brain.vision] enabled`。
能看图时 `look(image=true)` / `look_at` / `look_person` / `check_friend` / `panel_read(image=true)` 不再走 `Eyes.proxy`：

- OpenAI 的 `tool` 消息只收文字：工具结果写成「截图在下一条消息里。」+ 原来的文字块（位置说明等），这次调用所有 tool 消息之后紧接**一条** user 消息，内容是这些图（同一步调了几个看图的工具就放几张，按调用顺序，每张前一行「（look 的截图）」之类）。
- `question` 参数保留（大脑看不了图时还要用），能看图时忽略。

### 2.2 唤醒消息挑时机自动附一张（`auto`）

纯函数 `should_attach(events, unsure, last_at, now, cfg)`，满足任一条且离上次**自动**附图 ≥ `min_gap`（20 秒）、画面不黑：

- 这批取走的事件里有 `chat`（addressee 判成 跟你说 / 说给大家 / 拿不准的才是 chat）；
- `arrive`、`approach`；
- `notice`（眼睛的新鲜事）、`lull`（冷场叫醒）；
- 感知层拿不准：`env.overlay` 里有「像谁 / 可能是谁」的人，或认不出的图标。

心跳、纯背景兜底叫醒的轮次（只有 `BACKGROUND` 事件）不附。工具返回的图不受 `min_gap` 管，也不刷新它。

## 3. 编号图

新文件 `brain/vision.py`（纯计算）：

- **取图和框**：`Brain.message` 经 `body.call` 在身体线程里取身体最新一帧 + `env.overlay(now)`（和管理面板画面同一份）。感知层结果超过 1 秒没更新（`people()` 已经是空的那种情况）只给图、不画框。感知层没开（`EnvWatcher`）只给图。
- **画什么**：人（好友 / 像谁 / 可能是谁 / 陌生人 / 黑影 / 团子）、认出的东西（座位、篝火……）、图标；名字标签、气泡不画（游戏里本来看得见，画了挡住）。
- **怎么画**：框 + 框左上角外的实心圆里写数字（cv2 写不了中文；探针证明数字就够）；颜色按种类（好友绿、拿不准黄、陌生人白、团子灰、东西 / 图标青），颜色写成常量；从左往右编号。缩到 `size`（默认 960×540），JPEG 质量沿用 `brain.jpeg_quality`。
- **图例**（跟在图前面的文字块，代替这张图原来的 `scene_note` 坐标说明）：
  ```
  图上的编号（身体认的，可能错）：
  ① 懒洋洋大王（好友，看到名字）
  ② 像番茄炒蛋盖饭（没看到名字）
  ③ 陌生人A
  ④ 你自己
  ⑤ 图标：牵手（在①头顶）
  ```
  没框：「图上没画框（身体这会儿没认出东西）」。
- `look(image=true)` 在能看图时也用这套画法（编号图只有一种）；代看时（看不了图）照旧给眼睛干净的图 + `scene_note`，逐字不变。
- **status 的「画面里」一行不改**（管理面板、注意力、日志都在用）；大脑靠图例把编号和名字对上。

## 4. 大脑循环（`brain/toolloop.py`）

- `send(text, image=None)`：`image` 是 `(图例文字, 图片块)`；有就把唤醒消息组成 `[文字, 图例, 图]` 的内容块（`to_openai_content`）。`BrainSession.send` 不变（Claude 大脑不收自动图，`Brain` 只在会话是 `ToolLoopBrain` 且能看图时取图）。
- **历史不留图**：这一轮存进 `_past` 时，唤醒消息里的图换成一行「（这时附了一张截图）」（图例保留，照旧截到 `HISTORY_TEXT`）；工具后面那条带图的 user 消息换成「（看了截图）」。最后一轮本来就因截短对不上缓存，前面的历史照样命中。
- 压缩：起压缩时沿用这一轮原样的消息（带图无妨，`tool_choice = "none"`）。
- **接口拒收图**：带图的请求报 400 且错误里提到 image / vision（或模型不支持多模态的错误码）→ 这次运行关掉看图（`vision_off = 原因`）、这一轮去掉图重发一次、之后走代看；WARNING 一行；status「模型：」一行写「看不了图（原因）」。别的错照旧 `ModelError`。
- **切到备用大脑**：按备用模型勾没勾能看图；`sees()` 每次现算。

## 5. 提示词

`BLIND_NOTE` 拆成两版：

- 看不了图：现在的 `BLIND_NOTE` 逐字不变。
- 看得了图（`SIGHTED_NOTE`）：「你有时会收到当前画面的截图，图上画了身体认出的框和编号，图例写着它认的是谁。状态和图例是身体认的，可能错：跟截图对不上时以截图为准（名字以头顶亮着的名字标签为准），在最后的文字里写一行「核对：…」说哪里对不上；认不出的别硬认，可以问。」+ 原来后四条。

ToolLoopBrain 建好时按 `sees()` 选；中途切到看不了图（拒收、换备用）时，下一轮起唤醒消息开头加一句「（现在看不了图了，看图的工具会请眼睛代看）」，系统提示词不改（免得缓存全丢）。

## 6. 成本、记录、看得到的地方

- 用量照旧记在大脑名下。`brain.jsonl` 每轮多 `images`：`[{"src": "auto" | "<工具名>", "w": 960, "h": 540}]`，没附就不写这个键。
- **「核对」行**：每轮最后的文字里以「核对：」开头的行，INFO 日志一行 `核对：…`，`brain.jsonl` 多 `check` 字段。
- **大脑控制台**（`brain/trace.py` + `console/static/brainlog.js`）：附了图的那一轮轮头标「附图·自动」或「附图·look」，点开看缩略图（trace 只在内存里留最近 20 张，JPEG 缩到 480 宽）。「核对」行高亮。
- 先不设每小时上限；跑一晚看 `images` 和用量再定。

## 7. 配置（`[brain.vision]`，`config.VisionConfig`，挂在 `BrainConfig.vision`）

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 关掉 = 逐字照旧（代看、不自动附图、`BLIND_NOTE`） |
| `auto` | `true` | 唤醒消息自动附图；关掉只剩工具返回的图直接给 |
| `min_gap` | `20.0` | 两张自动附图之间至少隔多少秒 |
| `size` | `[960, 540]` | 编号图的尺寸（宽, 高） |

管理面板设置页给 `brain.vision.enabled` / `brain.vision.auto`。

## 8. 不变的地方

- `enabled = false`：`ToolLoopBrain` 的请求、历史、提示词、代看逐字照旧，用 `tests/data/toolloop_baseline.json` 比。
- Claude 大脑：工具返回的图本来就直接看，不动；不自动附图。
- 沙盒（`text_only`）：不取图、不附图、提示词用看不了图那版。
- 眼睛：照旧定时看、挑新鲜事、写场景描述；只是能看图时不再代看。

## 9. 测试（`python -m pytest -q`）

- `brain/vision.py`：合成画面 + 假 overlay：框数、编号从左往右、颜色按种类、图例文字；overlay 太旧 / 没有感知层只给图；名字标签和气泡不画。
- `should_attach`：每种触发、`min_gap`、黑屏、只有背景事件、工具图不刷新 `last_at`。
- `ToolLoopBrain`：带图唤醒消息的请求结构；工具返回图时 tool 消息 + 一条带图 user 消息（多个看图工具合一条）；历史里图换成占位；400 拒收 → 去图重发、之后代看；`enabled = false` 对基准逐字一致。
- `sees()`：OpenAI 兼容 + 勾了能看图 → True；没勾 / 关掉 / 沙盒 → False。
- 「核对」行解析进 `brain.jsonl` 和日志。

## 10. 验收（晚上真机，按顺序）

1. 真机 dry-run 半小时：大脑控制台有附图的轮次、缩略图和编号对得上、出现「核对」行；
2. 造错：好友站远一点、名字标签淡掉（感知层多半写「陌生人」或「像他」），看大脑是照着说、含糊带过，还是去问 / 去喊；
3. 跑一晚 live：从 `brain.jsonl` 数 `images`，对照模型用量算每小时多花多少；
4. 把这一晚所有「核对」行拉出来人工过一遍：感知层真错了 / 大脑看错了 / 说不清，当作第一份感知层错误率样本，写进进度文档。
