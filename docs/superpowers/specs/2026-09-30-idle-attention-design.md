# 空闲注意力：团子闲着时东张西望（设计）

日期：2026-09-30　状态：设计已和用户逐节确认，待实施计划

## 目标

团子没事做的时候，镜头也在有意义地动：偶尔随意看看，有动静就转过去看，看腻了就看别的。
**主要是给用户看的**（看模拟器 / 可视化网页时有"活着"的感觉，像 Neuro-sama）；游戏里别的玩家看不到团子的镜头。

成功的样子：用户旁观半小时，镜头每次动都说得出理由（"它在看刚说话的小明""它在看朝它走过来的人"），
不抽搐、不来回甩、不一直往一个方向转；不耽误聊天，不和 track、look_person 换角度这些抢镜头。

### 用户定下的原则

- **身体做反射，大脑定心思**：秒级的"往哪看、看多久"全由身体按规则做，不花额度；大脑只偶尔设一个"心思"（§3）。
- **不设"原来的朝向"、不回位**：团子每一刻只考虑"现在最想看什么"。看完别的东西不用转回去 —— 那边的好友还在说话，
  自然还是最有意思的，会再转回去。镜头停在哪都行；大脑想复位自己调 `camera_reset`。
- 让团子转过去看的动静：**有人说话**（头顶气泡）、**有人朝团子走过来**、**有人对团子做事**（互动请求、挥手鞠躬）。
  **有人进出画面不算**（太频繁，一惊一乍）。
- 只在面板 **auto 模式**、聊天面板关着的空闲时间做；always 模式下完全不动。
- 只左右转（`Camera.nudge`），不上下看、不缩放、不走动。

## 1. 什么时候动、什么时候让路

注意力是身体主循环里的一个环节（**不是技能**，见"为什么不做成技能"），每圈在技能 tick 和大脑命令之后跑一次。
同时满足下面这些才按键：

- `[panel] mode = "auto"`，聊天面板此刻关着（`reader.panel_closed_since is not None`），而且马上不会开：
  `PanelManager` 处于 idle、没借出、没有排队的 `_pending`、离下一次定时看一眼还有至少 `track.settle + 1` 秒。
  为此 `PanelManager` 加一个公开方法 `quiet(now) -> bool`（不再从外面读私有字段）
- 没有技能在跑（`skills.active is None`）
- 大脑没在用身体：命令队列空；没有攒着的 `chat` / `owner_command` 事件；`brain_busy()` 为假（= 大脑没在回聊天：取走了聊天的那一轮还没结束）。
  大脑在别的轮次（主动开口、背景事件）里思考时照常东张西望 —— 它要用身体时命令排在注意力前面
- 没黑屏、没牵手（`holding`）、没有别的面板开着（`panels.state.others()` 为空）
- 注意力没被关（`[attention] enabled`、心思不是"别动"）
- 不是 dry-run —— dry-run 照样算"想看什么"（进 status），只是不按键

**让路**：条件不满足时就停在原地，不回位、不收尾。每次只按一下小键（0.02～0.1 s，`hw_key_hold` 一条命令按完即松），
不存在"转到一半"，谁要镜头随时直接拿走。track、look_person 换角度、`camera` 工具都在前面执行，天然优先。

**按键不借面板**：只有面板本来就关着才按（上面的条件），不需要 `borrow`。

**自己转镜头的副作用**：
- 转镜头时人框会横移、大小略变，可能被判成"有人走近"：注意力按键后 `track.settle` 秒内，身体丢掉这段时间里冒出的 `approach`
  （互动请求、气泡照常）
- 自己转的不算"画面大变"：按键后清 `_ref_thumb`（同 camera 工具）；`_forget_self()` 不用调（只左右转，团子框大小不变）

### 为什么不做成技能

技能层（`brain/skills.py`）和"空闲本能"四处冲突：技能结束发 `task_done` / `task_failed` 会叫醒大脑；
`needs_camera` 技能整段借着面板（auto 模式看一眼、看气泡都得等）；`quiet_people` 会丢掉 `approach` / `gesture`（正是要响应的动静）；
同时只能一个技能（占着位大脑就开不了 track）。技能是大脑交代的**任务**，注意力是身体闲着时的**本能**，分开放谁也不用为对方开特例。

## 2. 想看什么、看多久（兴趣模型）

### 候选目标

每圈从感知层收集**画面里**值得看的东西（画面外的认不出来）：

| 目标 | 来源 | 基础兴趣（默认） |
|---|---|---|
| 好友在说话（头顶气泡） | 感知层新接口 `talkers(now)` | `talk_friend = 1.0` |
| 有人对团子做事（互动请求 / 挥手鞠躬） | `env.requests` 的 `pos`；`gesture` 按名字 `target_x` | `act_on_me = 0.9` |
| 有人朝团子走过来 | `approach` 附带位置（感知层顺手记下 cx，陌生人也有） | `approach = 0.7` |
| 陌生人在说话 | `talkers(now)` | `talk_stranger = 0.4` |
| 画面里站着的好友 | `people()` | `friend_present = 0.2` |

同一个人可能同时是几种目标（好友站着 + 在说话）：取最高的那种。目标用"感知层轨迹 id"认同一个人，没有轨迹的（互动请求只有名字和位置）用名字。

感知层补的接口：
- `talkers(now) -> list[Talker]`：`(track_id, 名字或 None, 是好友, 框中心 x, 最近一次看到气泡的时间, 这次气泡开始的时间)`，
  数据来自已有的 `_typing` / `owner.data["typing_at"]`。**这次气泡开始的时间**：同一个人的气泡消失超过 `bubble_gap`（1 s）后再出现，算一个新的气泡
- `approach` 记录 `(who, cx, 时间)`；`pop_approaches()` 的返回值不变（身体事件照旧），另加 `recent_approaches(now)` 给注意力用

### 看腻

每个目标有一个"看腻程度" `bored ∈ [0, 1]`：它在画面中间带（见下）里时按 `bore_rate`（每秒）涨，不在时按 `recover_rate` 消。
**实际兴趣 = 基础兴趣 × (1 − bored)**。

- 好友说话：**新的气泡**（上面的定义）出现时 `bored` 清零 —— 一直在聊就一直看着他
- 互动请求、走近：看几秒就腻，注意力自然转走
- 不写"看 3 秒再回来"这种死规则，行为由分数涌现

### 转过去

- 当前目标 = 实际兴趣最高、且超过 `min_interest`（0.15）的那个
- 目标中心在画面中间 `center_band`（40%）以内就不动（玩家不会把人精确摆正中）；不在就像 track 一样小步比例控制：
  按键秒数 = `gain × 偏差`（半屏宽算 1），夹到 `[track] nudge_min ~ nudge_max`；每按一下至少隔 `track.settle` 秒再看下一步
- 转不动（同方向连按 `track.stall_nudges` 次偏差没缩小 `track.stall_px`）：给这个目标加 `stuck_bored`（0.5），注意力自然换走

### 防抖

- 换目标：新目标的实际兴趣要比当前目标高出 `switch_margin`（0.2）才换；刚换过目标 `switch_hold`（2 s）内不再换
- 两个人同时说话时不会左右甩：当前那个在中间带里会慢慢看腻，腻到另一个高出门槛才换

### 闲着随意看

没有任何目标超过 `min_interest` 时：每隔随机 `wander_min ~ wander_max`（8～20 s）往随机一边看一眼 ——
连按 `wander_presses`（2～4）下小键、每下之间隔 `track.settle`，像拖视角；看完停在那，**不回来**。
往同一边连着看不超过 `wander_same_side`（2）次，免得一直往一个方向转圈。
有目标出现就立刻打断随意看。

## 3. 大脑定"心思"

新大脑工具 `attention(mind, focus=None)`，写法照 `set_request_policy`：状态存在身体里（本次运行有效，改了才变），status 里显示。

| mind | 身体怎么做 |
|---|---|
| `随意`（默认） | §2 的样子 |
| `好奇` | 随意看更勤（间隔 4～10 s）；陌生人说话算 0.7 |
| `专心` | 不随意看；只对 ≥ `act_on_me` 的目标转（好友说话、对团子做事） |
| `别动` | 完全不动镜头 |

`focus`（一个名字，可选）：这个人的基础兴趣提到 `focus_interest`（1.0），看腻速度减半。它和 `track` 不同：
track 是一直把人摆中间的任务；focus 只是"更想看他"，别处有大动静照样转走。`focus=""` 清掉。
名字匹配同 `target_x`（先一模一样、再容忍 OCR 错一两个字）。

- 提示词加一小段：身体闲着会自己东张西望；心思只在想改变习惯时设，不用每轮设；主人说"别乱转""看我"之类由大脑理解后调 `attention`
- 算"做了事"的工具（进 `ACTIONS`，同 `set_request_policy`）；手动控制栏不加（YAGNI）

## 4. 代码结构、可见性、测试

### 代码结构（决策和按键分开，同 peek）

| 位置 | 内容 |
|---|---|
| `brain/attention.py`（新） | 纯计算：候选目标 → 看腻 / 实际兴趣 / 防抖 → 这一圈做什么（不动 / `Turn(方向, 秒)` / 随意看的下一下）；心思、focus 在这里生效；用假时钟完整可测 |
| `Body` | 每圈（技能、命令之后）：判断闲不闲（§1）→ 从感知层收集候选 → 交给 attention → 闲着且不是 dry-run 就按一下；按键后 settle 内丢 `approach`、清 `_ref_thumb` |
| `vision/perception.py` | `talkers()`、`recent_approaches()`（§2） |
| `chat/panel.py` | `PanelManager.quiet(now)`（§1） |
| `brain/tools.py` `prompt.py` | `attention` 工具、说明、提示词一段 |
| `config.py` `config.example.toml` | `[attention]` 节（下表） |

`[attention]` 默认值（都是估的，真机调）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 只在 auto 模式起作用，所以眼下（默认 always）行为不变 |
| `talk_friend` / `act_on_me` / `approach` / `talk_stranger` / `friend_present` | 1.0 / 0.9 / 0.7 / 0.4 / 0.2 | 基础兴趣 |
| `focus_interest` | 1.0 | |
| `min_interest` | 0.15 | 低于它不算目标 |
| `bore_rate` / `recover_rate` | 0.2 / 0.05 | 每秒 |
| `stuck_bored` | 0.5 | 转不动时加的看腻 |
| `bubble_gap` | 1.0 | 气泡消失多久再出现算新的 |
| `center_band` | 0.4 | 画面中间多宽算"已经在看" |
| `gain` | 0.3 | 按键秒数 = gain × 偏差 |
| `switch_margin` / `switch_hold` | 0.2 / 2.0 | 防抖 |
| `wander_min` / `wander_max` | 8 / 20 | 秒；好奇时减半 |
| `wander_presses` | [2, 4] | |
| `wander_same_side` | 2 | |

按键长短、settle、转不动的判断沿用 `[track]`。

### 可见性

- status 加一行：`在看：小明（在说话）` / `在看：陌生人（朝你走过来）` / `闲着随意看` / `没在看什么`；心思不是随意、或有 focus 时写 `心思：专心，关注小明`
- 可视化网页状态栏（`Body._show` 的 `info`）加 `注意力` 一项，网页和管理面板不用改
- DEBUG 日志：每次换目标（新旧目标和各自实际兴趣）、每次按键（方向、秒数、偏差）；真机调参靠它

### 测试（离线，TDD）

- `attention.py`：好友说话压过陌生人说话；同一人看腻后转走、冒新气泡后再转回；防抖（两人同时说话不来回甩、`switch_hold`）；
  进中间带不动；转不动加看腻；随意看的间隔、按键次数、同边上限、有目标立刻打断；四种心思；focus 提兴趣、看腻减半
- `Body`：§1 每个"不闲"条件下不按键；dry-run 只算不按；按键后 settle 内的 `approach` 被丢、之后照常；status 的"在看"行；心思工具的校验和 status
- `PanelManager.quiet`：idle / peek / bubble / chatting / 借出 / 有 pending / 快到定时看一眼
- `PerceptionWatcher.talkers` / `recent_approaches`：气泡挂到人、新气泡的判定、陌生人走近带位置

### 真机验收（等 auto 模式验收、默认改 auto 之后）

用户开着网页旁观 15～30 分钟：
1. 镜头每次动都说得出理由；没有来回甩、没有晕、没有一直往一个方向转
2. 好友说话时会看过去；陌生人说话偶尔瞥一眼
3. 不耽误聊天：面板该开时及时开，开着时注意力不动
4. 按 DEBUG 日志调兴趣分、看腻速度、随意看的间隔

## 不在这次范围内

上下看、缩放、走动；画面外的动静（听到声音转身）；按 Q 认团子；手动控制栏里的心思按钮。
