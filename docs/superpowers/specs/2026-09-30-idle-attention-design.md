# 空闲注意力：团子闲着时东张西望（设计）

日期：2026-09-30　状态：设计已和用户逐节确认，待实施计划

## 目标

团子没事做的时候，镜头也在有意义地动：偶尔随意看看，有动静就转过去看，看腻了就看别的。
**主要是给用户看的**（看模拟器 / 可视化网页时有"活着"的感觉，像 Neuro-sama）；游戏里别的玩家看不到团子的镜头。

成功的样子：用户旁观半小时，镜头每次动都说得出理由（"它在看刚说话的小明""它在看朝它走过来的人"），
不抽搐、不来回甩、不一直往一个方向转；不耽误聊天，不和 track、look_person 换角度、身体反射抢镜头 / 抢时机。

它补的正是身体反射 spec（`2026-09-30-body-reflex-design.md`）"不做"里的"转镜头看说话的人"：
那边不做是因为 always 模式下要关面板几秒；这里只在 auto 模式、面板关着时做。

### 用户定下的原则

- **身体做反射，大脑定注意力模式**：秒级的"往哪看、看多久"全由身体按规则做，不花额度；大脑只偶尔设一个模式（§3）。
- **不设"原来的朝向"、不回位**：团子每一刻只考虑"现在最想看什么"。看完别的东西不用转回去 —— 那边的好友还在说话，
  自然还是最有意思的，会再转回去。镜头停在哪都行；大脑想复位自己调 `camera_reset`。
- 让团子转过去看的动静：**有人说话**（头顶气泡）、**有人朝团子走过来**、**有人对团子做事**（挥手鞠躬）。
  **有人进出画面不算**（太频繁，一惊一乍）。
- **先看一眼再开面板**：auto 模式下好友冒气泡 / 有人走近会叫开聊天面板（面板开着方向键不管用）。
  注意力先转过去看（最多 `look_first` 2 秒），再让面板开 —— 像玩家看到有人说话先把视角转过去、再按 C 看聊天。
  面板关着时消息照样进聊天记录（2026-09-29 真机确认），只是晚两秒读到。
- 只在面板 **auto 模式**、聊天面板关着时做；always 模式下完全不动。
- 只左右转（`Camera.nudge`），不上下看、不缩放、不走动。

## 1. 什么时候动、什么时候让路

注意力是身体主循环里的一个环节（**不是技能**，见"为什么不做成技能"），放在 `Body.step()` 的 `_watch_idle`（反射的闲着小动作）之后。
同时满足下面这些才按键：

- `self.panel.auto` 为真（它本身要求 `vision.mode == "log"`；沙盒强制 always，天然不跑），聊天面板此刻关着（`reader.panel_closed_since is not None`），
  而且面板"安静"：`PanelManager.quiet(now)` 为真，或者处在"先看一眼"的窗口里（下面）
- 输入框没开：`self._bubble_at is None`、`not self.sender.opened`、`not device.ime_shown()`（反射替大脑冒的输入框开着时方向键会打进框里；注意力只让路，不关框）
- 没有技能在跑（`skills.active is None`）
- 没有互动请求挂着（`env.requests` 空）：身体接受请求要点头顶圆圈，镜头一转圆圈位置就变了（同反射的条件）
- 大脑没在用身体：命令队列空；没有攒着的 `chat` / `owner_command` 事件；`brain_busy()` 为假（= 大脑没在回聊天：取走了聊天的那一轮还没结束）。
  大脑在别的轮次（主动开口、背景事件）里思考时照常东张西望 —— 它要用身体时命令排在注意力前面
- 没黑屏、没牵手（`holding`）、没有别的面板开着（`panels` 为 None 或 `panels.state.others()` 为空）
- 离上一个动作（大脑或反射做的，`emotes` 记的最近一次）超过 `reflex.min_gap`：别在动作动画里甩镜头
- `camera` 不是 None、感知层有 `people`（沙盒里都没有：判空后什么都不做）
- `[attention] enabled`、模式不是"别动"
- 不是 dry-run —— dry-run 照样算"想看什么"（进 status），只是不按键

`PanelManager.quiet(now)`（新公开方法，和 `describe()` 的"N 秒后看一眼"共用算法）：
auto、state 为 idle、没借出、没有 `_pending`、离下一次定时看一眼（`_last_read + idle_peek`）还有至少 `track.settle + 1` 秒。

### 先看一眼再开面板

好友冒气泡（`bubble_seen` 把 `_pending` 设成 "bubble"）或有人走近（`trigger("approach")`）时，面板本来下一圈就会开。
如果注意力认为这个动静值得看（§2 的目标、实际兴趣最高）、而其他条件都满足：

- 调 `PanelManager.hold_off(until)`（新方法）让面板推迟处理 `_pending`，`until = now + look_first`（2 s）；
  推迟期间 `_tick_idle` 不开面板，其它状态（chatting、peek、bubble）不受影响，`_pending` 保留
- 注意力照 §2 转过去；**目标进了中间带或到了 `until`**，就 `hold_off(None)` 放手，面板下一圈照常打开
- 同一个 `_pending` 只推迟一次；推迟中如果读到新消息 / 大脑要说话 / 大脑调 `chat_log`，面板照常立刻进 chatting（这些路径本来就不看 `_pending`）

### 让路

条件不满足时就停在原地，不回位、不收尾。每次只按一下小键（0.02～0.1 s，`hw_key_hold` 一条命令按完即松），
不存在"转到一半"，谁要镜头随时直接拿走。track、look_person 换角度、`camera` 工具都在前面的 `_run_commands` 里执行，天然优先。

### 按键不打扰别人

- **不借面板**：只有面板本来就关着才按
- **不走 `clear_view`、不调 `reflexes.stir()`**：注意力转镜头不算"有动静"。否则每 8～20 秒转一次会把反射"闲着的小动作"（180～420 s 起算）的计时一直往后推，
  小动作永远做不成；`clear_view` 还会关掉替大脑开的输入框
- **不套 `env.held()`**：转的时候要感知层一直看着（同 track）
- 自己转镜头时人框会横移、大小略变，可能被判成"有人走近"：注意力按键后 `track.settle` 秒内，`_watch_comings` 丢掉这段时间里冒出的 `approach`，
  **丢的位置在 `panel.trigger("approach")` 之前**（不然自己转镜头会把面板叫开）；互动请求、气泡照常
- 自己转的不算"画面大变"：按键后清 `_ref_thumb`（同 camera 工具）；`_forget_self()` 不用调（只左右转，团子框大小不变）

### 为什么不做成技能

技能层（`brain/skills.py`）和"空闲本能"四处冲突：技能结束发 `task_done` / `task_failed` 会叫醒大脑；
`needs_camera` 技能整段借着面板（auto 模式看一眼、看气泡都得等）；`quiet_people` 会丢掉 `approach` / `gesture`（正是要响应的动静）；
同时只能一个技能（占着位大脑就开不了 track）。技能是大脑交代的**任务**，注意力是身体闲着时的**本能**，分开放谁也不用为对方开特例。

## 2. 想看什么、看多久（兴趣模型）

### 候选目标

每圈从感知层收集**画面里**值得看的东西（画面外的认不出来）：

| 目标 | 来源 | 基础兴趣（默认） |
|---|---|---|
| 好友在说话（头顶气泡） | 感知层新接口 `talkers(now)` | `talk_friend = 1.0` |
| 有人对团子做事（挥手鞠躬） | 身体在 `_watch_comings` 里 `pop_gestures()` 时另记一份 `(who, 动作, 时间)`（回礼反射照旧消耗原队列），位置按名字 `target_x` | `act_on_me = 0.9` |
| 有人朝团子走过来 | 感知层新接口 `recent_approaches(now)`（顺手记下 cx，陌生人也有） | `approach = 0.7` |
| 陌生人在说话 | `talkers(now)` | `talk_stranger = 0.4` |
| 画面里站着的好友 | `people()` | `friend_present = 0.2` |

互动请求不在这里：请求挂着时注意力整个不动（§1）。挥手鞠躬还没有识别模型（`[gesture]` 默认关），接口先接上。

同一个人可能同时是几种目标（好友站着 + 在说话）：取最高的那种。目标用"感知层轨迹 id"认同一个人，没有轨迹 id 的（挥手鞠躬只有名字）用名字。

感知层补的接口（`hasattr` 判断后再用：`EnvWatcher`、沙盒的 env 没有）：
- `talkers(now) -> list[Talker]`：`(track_id, 名字或 None, 是好友, 框中心 x, 最近一次看到气泡的时间, 这次气泡开始的时间)`，
  数据来自已有的 `_typing` / `owner.data["typing_at"]`。**这次气泡开始的时间**：同一个人的气泡消失超过 `bubble_gap`（1 s）后再出现，算一个新的气泡
- `recent_approaches(now) -> list[(who, cx, 时间)]`：`_watch_approach` 记下时多存 cx；`pop_approaches()` 的返回值不变（身体事件照旧）

### 看腻

每个目标有一个"看腻程度" `bored ∈ [0, 1]`：它在画面中间带（见下）里时按 `bore_rate`（每秒）涨，不在时按 `recover_rate` 消。
**实际兴趣 = 基础兴趣 × (1 − bored)**。

- 好友说话：**新的气泡**（上面的定义）出现时 `bored` 清零 —— 一直在聊就一直看着他
- 走近、挥手鞠躬：看几秒就腻，注意力自然转走
- 不写"看 3 秒再回来"这种死规则，行为由分数涌现
- 每圈的时间差夹到 `max_step`（1 s）：沙盒的模拟时钟 `skip` 会一下跳几小时，看腻不能因此一步到顶

### 转过去

- 当前目标 = 实际兴趣最高、且超过 `min_interest`（0.15）的那个
- 目标中心在画面中间 `center_band`（40%）以内就不动（玩家不会把人精确摆正中）；不在就像 track 一样小步比例控制：
  按键秒数 = `gain × 偏差`（半屏宽算 1），夹到 `[track] nudge_min ~ nudge_max`；每按一下至少隔 `track.settle` 秒再看下一步
- 转不动（同方向连按 `track.stall_nudges` 次偏差没缩小 `track.stall_px`）：给这个目标加 `stuck_bored`（0.5），注意力自然换走

### 防抖

- 换目标：新目标的实际兴趣要比当前目标高出 `switch_margin`（0.2）才换；刚换过目标 `switch_hold`（2 s）内不再换
- 两个人同时说话时不会左右甩：当前那个在中间带里会慢慢看腻，腻到另一个高出门槛才换

### 闲着随意看

没有任何目标超过 `min_interest` 时：每隔随机 `wander_min ~ wander_max`（8～20 s）× 倍数（下面）往随机一边看一眼 ——
连按 `wander_presses`（2～4）下小键、每下之间隔 `track.settle`，像拖视角；看完停在那，**不回来**。
往同一边连着看不超过 `wander_same_side`（2）次，免得一直往一个方向转圈。有目标出现就立刻打断随意看。

**心情精力的倍数**：内心层 `inner/effects.py` 的 `Effects` 加一个字段 `wander`（随意看的间隔倍数，> 1 看得少），
照已有的做法写成常量表、不开放配置：

| 档位 | 开心 | 平常 | 低落 | 烦 | 精神 / 还行 | 有点累 | 困 |
|---|---|---|---|---|---|---|---|
| `wander` | 0.8 | 1.0 | 1.5 | 1.2 | 1.0 | 1.3 | 2.0 |

心情和精力的倍数相乘，再乘模式的倍数（§3）。**不复用 `idle`**：反射里困了小动作更勤（×0.6，打哈欠之类），东张西望则是困了看得少，方向相反。
心情不会自动改注意力模式 —— 那是大脑的事（它在 status 的"心里"里看得到心情）。

## 3. 大脑定注意力模式

新大脑工具 `attention(mode, focus=None)`，写法照 `set_request_policy`：状态存在身体里（本次运行有效，改了才变），status 里显示。
（不叫"心思"：内心层已经有 `Body.mind` 和 status 的"心里"，免得混。）

| mode | 身体怎么做 |
|---|---|
| `随意`（默认） | §2 的样子 |
| `好奇` | 随意看的间隔 ×0.5；陌生人说话算 0.7 |
| `专心` | 不随意看；只对 ≥ `act_on_me` 的目标转（好友说话、对团子做事、focus 的人） |
| `别动` | 完全不动镜头（也不推迟面板） |

`focus`（一个名字，可选）：这个人的基础兴趣提到 `focus_interest`（1.0），看腻速度减半。它和 `track` 不同：
track 是一直把人摆中间的任务；focus 只是"更想看他"，别处有大动静照样转走。`focus=""` 清掉。
名字匹配同 `target_x`（先一模一样、再容忍 OCR 错一两个字）。

- 提示词加一小段：身体闲着会自己东张西望；模式只在想改变习惯时设，不用每轮设；主人说"别乱转""看我"之类由大脑理解后调 `attention`
- **不进 `ACTIONS`**：它不在游戏里做事，不该让心跳退档归零（`ACTIONS` 是"算做了事"、心跳退档用的）
- 沙盒里放行（只改状态，无害）；手动控制栏不加（YAGNI）

## 4. 代码结构、可见性、测试

### 代码结构（决策和按键分开，同 peek）

| 位置 | 内容 |
|---|---|
| `brain/attention.py`（新） | 纯计算：候选目标 → 看腻 / 实际兴趣 / 防抖 → 这一圈做什么（不动 / `Turn(方向, 秒)` / 随意看的下一下 / 要不要推迟面板）；模式、focus、倍数在这里生效；时钟和随机数注入，完整可测 |
| `Body` | `_watch_idle` 之后：判断闲不闲（§1）→ 收集候选 → 交给 attention → 按一下、推迟 / 放手面板；按键后 settle 内在 `_watch_comings` 里丢 `approach`（在 `panel.trigger` 之前）、清 `_ref_thumb`；`pop_gestures` 时另记一份；随机数存一份（`Body` 现在没存 `rng`，照 `Reflexes` 注入） |
| `vision/perception.py` | `talkers()`、`recent_approaches()`（§2） |
| `chat/panel.py` | `PanelManager.quiet(now)`、`hold_off(until)`（§1） |
| `inner/effects.py` | `Effects.wander` 和常量表（§2） |
| `brain/tools.py` `prompt.py` | `attention` 工具、说明、提示词一段 |
| `config.py` `config.example.toml` | `[attention]` 节（下表） |

`[attention]` 默认值（都是估的，真机调）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 只在 auto 模式起作用，所以眼下（默认 always）行为不变 |
| `talk_friend` / `act_on_me` / `approach` / `talk_stranger` / `friend_present` | 1.0 / 0.9 / 0.7 / 0.4 / 0.2 | 基础兴趣 |
| `focus_interest` | 1.0 | |
| `min_interest` | 0.15 | 低于它不算目标 |
| `bore_rate` / `recover_rate` | 0.2 / 0.05 | 每秒 |
| `stuck_bored` | 0.5 | 转不动时加的看腻 |
| `bubble_gap` | 1.0 | 气泡消失多久再出现算新的 |
| `center_band` | 0.4 | 画面中间多宽算"已经在看" |
| `gain` | 0.3 | 按键秒数 = gain × 偏差 |
| `switch_margin` / `switch_hold` | 0.2 / 2.0 | 防抖 |
| `look_first` | 2.0 | 冒气泡 / 有人走近时，先看这么久再让面板开 |
| `wander_min` / `wander_max` | 8 / 20 | 秒；再乘倍数 |
| `wander_presses` | [2, 4] | |
| `wander_same_side` | 2 | |
| `max_step` | 1.0 | 每圈时间差上限（模拟时钟跳时间） |

按键长短、settle、转不动的判断沿用 `[track]`；"离上个动作多久"沿用 `[reflex] min_gap`。

### 可见性

- status 加一行，放在"刚才下意识"之后、"心里"之前：`在看：小明（在说话）` / `在看：陌生人（朝你走过来）` / `闲着随意看` / `没在看什么`；
  模式不是随意、或有 focus 时写成 `注意力：专心，关注小明；在看：…`
- 可视化网页状态栏（`Body._show` 的 `info`）加 `注意力` 一项（已有"反射""心情""精力"），网页和管理面板不用改
- DEBUG 日志：每次换目标（新旧目标和各自实际兴趣）、每次按键（方向、秒数、偏差）、每次推迟 / 放手面板；真机调参靠它

### 测试（离线，TDD）

- `attention.py`：好友说话压过陌生人说话；同一人看腻后转走、冒新气泡后再转回；防抖（两人同时说话不来回甩、`switch_hold`）；
  进中间带不动；转不动加看腻；随意看的间隔、按键次数、同边上限、有目标立刻打断、倍数生效；四种模式；focus 提兴趣、看腻减半；
  时间一下跳几小时不出错；要不要推迟面板的判断
- `Body`：§1 每个"不闲"条件下不按键（含输入框开着、请求挂着、刚做过动作、沙盒里没有镜头 / 感知层）；dry-run 只算不按；
  按键后 settle 内的 `approach` 被丢、也没叫开面板，之后照常；先看一眼：推迟面板、转过去或到时间后放手、面板下一圈打开；
  转镜头不重置反射的闲着计时；status 的"在看"行；`attention` 工具的校验和 status；不算"做了事"
- `PanelManager.quiet` / `hold_off`：idle / peek / bubble / chatting / 借出 / 有 pending / 快到定时看一眼；推迟期间不开、放手后开、推迟不挡 chatting
- `PerceptionWatcher.talkers` / `recent_approaches`：气泡挂到人、新气泡的判定、陌生人走近带位置
- `Effects.wander`：各档位倍数

### 真机验收（等 auto 模式验收、默认改 auto 之后）

用户开着网页旁观 15～30 分钟：
1. 镜头每次动都说得出理由；没有来回甩、没有晕、没有一直往一个方向转
2. 好友说话时先转过去、再开面板读；陌生人说话偶尔瞥一眼
3. 不耽误聊天：面板最多晚 2 秒开，开着时注意力不动；反射的小动作照常做
4. 按 DEBUG 日志调兴趣分、看腻速度、随意看的间隔

## 不在这次范围内

上下看、缩放、走动；画面外的动静（听到声音转身）；按 Q 认团子；手动控制栏里的注意力按钮；把互动请求当目标。
