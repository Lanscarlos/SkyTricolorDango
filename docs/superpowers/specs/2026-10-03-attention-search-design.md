# 东张西望改成"有意识地找"（设计）

日期：2026-10-03　状态：设计已和用户逐节确认，待实施计划

## 起因

空闲注意力（`2026-09-30-idle-attention-design.md`）10-02 晚真机能动，但用户评价"太机械，没有主观的想法"：
20 分钟按了约 175 下，闲着时每 10~17 秒"随意看"——到点往随机一边连按 2~4 下，说不出在看什么；大脑一次都没调 `attention`。
（当时它常盯着的"陌生人"多半是团子自己，① 认人已在 10-03 修掉。）

用户要的是**有意识地**东张西望：说得出"在找附近有没有人""在找刚走开的小明"，找到就停下看，找不到换个方向或者放弃，看完有结果。

### 用户定下的原则

- **两层**：常见的"找"由身体按规则做（不花额度）；找完把有意义的结果交给大脑（背景事件 / status），大脑可以接话，
  也可以给身体下"找某某"的目标。**大脑不为了东张西望单独被叫醒**。
- **没有动机就不转**：删掉纯随机的"随意看"，不保留"发呆换个朝向"。
- 被动注意（有人说话 / 走近 / 对团子做动作就转过去看）**保留**，它本来就有目的。
- 这一期身体会三种找：**找刚走开的好友**、**环顾看周围有没有人**、**大脑下的目标**。
  "看那边亮的 / 新的是什么"要物品模型，这一期不做。
- 环顾：一个人待着时约 **60 秒**一次；**每次只看一片**，不转满一圈；往**最久没看过的方向**看，不随机。
- 镜头照旧**不回位**。

成功的样子：用户旁观时，镜头每次动都说得出理由，status / 网页上写着"在找：小明（他刚从左边走了）""往右后方看看，那边很久没看了"；
一个人站着时大约每分钟往没看过的方向看一片；好友走出画面后团子往他走的方向找；大脑 `find` 能找画面外的好友并报告结果。

## 1. 怎么找（`brain/search.py`，纯计算）

新模块，不碰设备：给一个找的计划，每圈喂感知结果，输出"这一圈按什么 / 找到了 / 可能是 / 放弃了"。
注意力（闲着的找）和技能 `find`（大脑的目标）共用它。

### 基本动作：分段转

镜头绕着团子转，近处的人在画面上移得慢、背景转得快（game-ops「转视角实测（D0）」）；按住 0.5 秒约转 90°。
"找"的基本动作是**分段转**：往一边连按 `seg_presses` 下（每下 `[track] nudge_max` 0.1 秒，身体线程不能按太久），
每下之间等 `[track] settle`；一段转完停 `dwell`（1.5 秒）让画面稳住、YOLO 出框、名字标签读出来，再判断要不要接着转。

角度靠按键次数估：`press_deg`（每下 0.1 秒约转几度，**估 18°**，按 `[spin] seconds_per_turn = 2.0` 线性折算，短按不一定线性）。
一段 = `seg_presses`（3）× `press_deg` ≈ 54°，按 60° 一段记账。**`press_deg` 没在真机标定**，先用 `camera spin` 标 `seconds_per_turn` 再改。

### 粗略朝向和"最久没看过"

`Heading`：累计按键次数 × `press_deg` 得到相对朝向（0~360°，相对上次清零时），分 6 个方位（每个 60°），
记每个方位"上次在画面里是什么时候"（画面水平视野按 `[spin] hfov` 90°，每圈把视野覆盖的方位刷新成现在）。

- 只拿它挑方向，不求准；**清零**：走路（`move`）、黑屏、别人转过镜头（track、`camera`、`camera_reset`、`look_around`、look_person 换角度——
  就是现在 `Attention.external_move` 被调的那些时候）。清零后所有方位都当"很久没看"，只有当前视野那个算刚看过。
- 挑方向：找"最久没看过"的方位，按离当前朝向近的那一侧转过去（一样近时和上次环顾的方向相反）。

### 三种计划

1. **找走开的好友**（`lost`，输入：名字、失踪记录里他最后的框和速度 `Lost`、是不是从画面边上出去的）
   - 在画面中间淡掉的（最后的框不贴边，画面里还有没挂名字的人）：多半只是走远、标签淡了 → **先按 Q**（`Body.call_out`），不转；
     喊完等呼喊窗口结果：认回来了就成功，否则当作"不在画面里"接下一步
   - 从画面边上出去的（或者 Q 之后还没有）：往他出去的那一边（没有就按速度方向）转，**最多 2 段**；
     还没看到就按一次 Q（Q 让画面外好友的名字贴在屏幕边上，`call_result` 里有"在画面外（左边）"）；有贴边标签就往那边再转最多 2 段
   - 都没有 → 放弃
   - Q 受 `[call]` 的额度管（`min_gap`、`auto_quota`、认回来的好友 5 分钟内不再为他自动喊）；额度不够就跳过 Q 那一步，只转；`[call] auto = false` 时也只转
2. **环顾**（`scan`，输入：方位记忆）
   - 往"最久没看过"的方位转，转 `scan_segments`（2~3 段，随机取一个，约 120°~180°），每段停 `dwell`
   - 看到人就停：好友交给被动注意（站着的好友）去看；陌生人停下看 `scan_look`（3 秒）后结束，记"那边有 1 个陌生人"
   - 转完都没有 → 记"附近没人"
3. **大脑下的目标**（`find`，输入：名字、可能有的失踪记录）
   - 画面里已经有他 → 直接成功
   - 有他的失踪记录（`keep` 内）→ 按计划 1 走
   - 否则先按 Q（这里是大脑的命令，Q 的间隔同大脑调 `call` 的规矩）：有贴边标签就往那边转；没有就**转满一圈**（6 段，每段停 `dwell`）
   - 一圈没找到 / 超时（默认 30 秒）→ 失败

### 什么算找到

- **找到**：这一帧他的名字标签挂在某个人身上（感知层 `people()` 里 `name == 他`、`sure = True`）
- **可能是他**：追踪器按位置接回的（`maybe_by = "relink"`）、认装扮"像他"的（`maybe`）→ 也停下，结果写"可能是"
- 找到 / 可能是之后：闲着的找交还被动注意（他就是站着的好友目标）；`find` 结束

## 2. 闲着的找怎么接进注意力

### 优先级和打断

被动注意（有人说话 / 走近 / 对团子做动作）> 找走开的好友 > 环顾 > 不动。

- 高的出现时打断低的：被打断的找**暂停**；被动目标看完（没有被动目标了）后，暂停没超过 `resume_within`（10 秒）就接着找，超过就作废
- 找走开的好友超过 `[call] auto_after_leave`（30 秒）还没开始 / 没找完就作废；他自己回来了（`return`）也作废
- "站着的好友"（`friend_present`）不打断找：找的时候画面里本来就可能站着别的好友

### 什么时候发起

- **找走开的好友**：好友走开（`_left_at` 里新的一条，判断同现在的 `_watch_call`：`auto_after_leave` 内、还没回来、这次走开没为他找过）。
  一次只找一个人；同时走开几个，按最近走开的那个找，其余作废
- **环顾**：画面里一个人都没有（`people()` 去掉团子）持续 `scan_after`（20 秒），且离上次环顾结束超过 `scan_every`（**60 秒**，乘精力倍数 `Effects.wander`、乘模式倍数）

### 能不能按键

沿用现在的 `_attention_blocked`（聊天面板开着、输入框开着、在做技能、有互动请求、在聊天、黑屏、牵手、举着蜡烛、别的面板开着、刚做完动作、dry-run……）。
被挡住的那一圈不按，找的进度停在原地（暂停计时照算 `resume_within`）。**dry-run 照样算**，status 写"想往左边找小明（dry-run，没按）"。

### 删掉"随意看"

删 `Attention._wander`、`WANDER_MODE`、`Thought.wandering`、`[attention] wander_min` / `wander_max` / `wander_presses` / `wander_same_side`。
`config.py` 遇到未知键会 `raise ValueError("未知配置项")`，删掉的四项如果写在旧的 `config.toml` / `console.toml` 里会让启动失败：
加一张"已废弃的键"表（`attention.wander_min` 等四项），加载时跳过并记一条 WARNING（"已废弃，可以删掉"），别的未知键照旧报错。
管理面板的设置清单里去掉这四项。`Effects.wander` 改成乘环顾间隔（含义同方向：> 1 看得少），注释跟着改。

### 模式（大脑 `attention` 工具）

| 模式 | 被动注意 | 找走开的好友 | 环顾 |
|---|---|---|---|
| 随意（默认） | 全部 | 做 | 间隔 ×1 |
| 好奇 | 全部，陌生人说话更想看（同现在） | 做 | 间隔 ×0.5 |
| 专心 | 只看好友说话、冲团子来的、关注的人（同现在） | 做 | 不做 |
| 别动 | 不转 | 不做 | 不做 |

`focus`（更想看谁）保留，含义不变。

### 和自动喊（`[call] auto`）合并

注意力在跑、`[attention] search` 开着时，"好友刚走开、画面里有没挂名字的人 → 喊一声"变成计划 1 的第一步，`_watch_call` **不再单独判断**（免得同一件事两边都做）；
注意力不在跑（always 模式、沙盒、`search = false`、`enabled = false`）时 `_watch_call` 照旧。额度、事件（`call` 背景事件、认回来的好友 `return`）照旧。

### 结果事件（背景事件 `search`，不单独叫醒大脑）

只有有意义的结果才发，其余只写 status：

| 情况 | 发什么 |
|---|---|
| 找走开的好友：找到了 | 不另发，走现有的 `return` |
| 找走开的好友：可能是他 | "你往左边找了找刚走开的小明，那边有个人可能是他（没看到名字）" |
| 找走开的好友：没找到 | "你往左边找了找刚走开的小明，没看到他" |
| 环顾：上次是"附近没人"、这次看到了人 | "你往右后方看了看：有 2 个陌生人" |
| 环顾：看到了好友 | "你往右后方看了看：看到了小明"（他本来就不在身边时才发，在身边的走 `arrive` / `return`） |
| 环顾：还是没人 / 和上次一样 | 只写 status |

`search` 加进 `brain/events.py` 的 `BACKGROUND`；同一种结果攒着时只留最新一条（同陌生人事件）。

## 3. 大脑这边

### 新工具 `find(名字, 秒=30)`（技能，`brain/find.py`）

和 `track` 并列放在技能层（`skills.py`）：

- 要打开感知层、有镜头；dry-run 时拒绝（手动控制照做，同 track）；秒数夹到 5~60
- 名字按 OCR 容错匹配 friends.md（同 `look_person`）；不在好友名单里直接拒绝
- 开始时借面板（技能层本来就借）；按计划 3 走；`tick` 里每圈最多按一下，不 sleep
- 结束：
  - `task_done`："找到了小明（右边·远）"或"可能是小明（没看到名字，右边·中）"
  - `task_failed`："转了一圈没找到小明，喊了一声也没看到他的名字"；黑屏 / 超时 / 出错照技能层的规矩
- 镜头不复位（同注意力）；找到后停下，要一直跟着由大脑接着调 `track`
- 算"做了事"（进 `ACTIONS`）；`find` 在跑时注意力不动（`skills.active` 已经挡住）
- 注册条件：感知层开着、有镜头（同 track），和 `[attention] search` 无关

### `attention` 工具

说明文字改成上面四种模式："随意（默认：看说话 / 走近的人，找刚走开的好友，一个人时看看周围）/ 好奇（周围看得更勤）/ 专心（只看跟你说话、冲你来的人，不看周围）/ 别动"。

### 提示词和 status

- 「视角」一节加一句：想知道谁在不在附近、好友走开了想看看他去哪了，用 `find`；身体闲着时自己会看看周围、找刚走开的好友，有结果会作为事件告诉你
- status 的注意力那一行：
  - "在找：小明（他刚从左边走了，往左转了 1 段）"
  - "在看看周围：往右后方（那边很久没看了）"
  - "刚才看了看：附近没人（40 秒前）"
  - 被动注意照旧"在看：小明（在说话）"
- 网页 / 管理面板显示同一行（现在就是取 `describe()`）

### `look_around` 不动

它是大脑要"转一圈汇报方位"的工具，不针对某个人；`find` 针对某个人、找到就停。

## 4. 开关、出错、代码结构、测试

### 配置（`[attention]` 新增，数字都是估的）

| 键 | 默认 | 含义 |
|---|---|---|
| `search` | true | 闲着的找（找走开的好友 + 环顾）；关掉只剩被动注意 |
| `press_deg` | 18.0 | 每下 `nudge_max` 约转几度（待 `camera spin` 标定） |
| `seg_presses` | 3 | 一段按几下 |
| `dwell` | 1.5 | 一段转完停几秒 |
| `scan_after` | 20.0 | 画面里没人多久才环顾 |
| `scan_every` | 60.0 | 两次环顾至少隔几秒（乘精力、模式倍数） |
| `scan_segments` | [2, 3] | 环顾一次转几段 |
| `scan_look` | 3.0 | 环顾看到陌生人停下看几秒 |
| `lost_segments` | 2 | 找走开的好友往一边最多转几段（Q 之后再给同样多） |
| `resume_within` | 10.0 | 被打断的找多久内能接着找 |

`find` 的超时默认 30 秒（工具参数）。管理面板加 `attention.search` 开关。

### 出错

- 转镜头出错 / 黑屏 / 感知层暂停（`env.held`）超过 `resume_within` → 闲着的找作废、记 DEBUG；`find` 算失败，原因写进 `task_failed`
- 方位记忆清零的时机见 §1；清零不影响正在进行的找（只是挑方向的依据重置）

### 代码结构

- `brain/search.py`（新）：`Heading`（方位记忆）、`SearchPlan`（三种计划的步骤）、`Search`（每圈 `step(obs, now) -> SearchStep`：按键 / 喊一声 / 找到 / 可能是 / 放弃），纯计算
- `brain/attention.py`：删随意看；`think()` 多收"找的观察"（画面里的人、失踪记录、呼喊结果），在被动目标为空时推进 `Search`；`describe()` 加"在找"那几行
- `brain/find.py`（新）：技能 `Find`，包 `Search`
- `brain/body.py`：`_watch_attention` 把 `Search` 的"喊一声"交给 `call_out`（等窗口结果同 `_collect_auto_call`）；发起找走开的好友 / 环顾；`_watch_call` 在注意力接管时跳过；发 `search` 事件
- `brain/tools.py` / `mcp_server.py`：注册 `find`、改 `attention` 说明；`brain/events.py`：`search` 进 `BACKGROUND`
- `config.py`：`AttentionConfig` 增删字段；提示词（「视角」一节）

### 测试（离线，TDD）

- `search.py`：三种计划的步骤（中间淡掉先 Q、边上出去先转、Q 后贴边再转、放弃）；找到 / 可能是；方位记忆（刷新、清零、挑最久没看的、两边一样近换方向）；环顾段数
- `attention.py`：优先级（被动打断找、看完接着找、超过 `resume_within` 作废）；四种模式；没有动机就不按键（以前的随意看测试删掉或改写）
- body 接线（假设备 + 假感知层）：好友从左边出去 → 往左转；中间淡掉 → 先 Q；`_watch_call` 不重复喊；环顾间隔和"画面里没人"条件；事件只在表里该发的时候发；dry-run 只算不按
- `find` 技能：画面里已有、Q 后贴边找到、转一圈没找到、超时、可能是、dry-run 拒绝、不认识的名字拒绝

### 真机验证（晚上）

1. `camera spin` 标定 `[spin] seconds_per_turn`，换算 `press_deg`
2. 一个人站着：约 1 分钟往没看过的方向看一片，status 写着往哪看、为什么；转了几次后周围都看到过
3. 好友从画面左边走出去：团子往左找；中间走远标签淡掉：先喊一声
4. 大脑（或手动控制）`find` 一个不在画面里的好友：成功 / 失败的文字对不对
5. 旁观 20 分钟：按键次数和 10-02 晚（175 下）比，每次动都说得出理由

## 不在这次范围内

- 看物品 / 地点（"那边亮的是什么"）：等物品模型
- 大脑偶尔自己挑看什么、带理由（"他换了新斗篷多看两眼"）
- 心情精力影响看法的细节（这一期只沿用 `Effects.wander` 乘环顾间隔）
- 走过去找（`move`）：只转镜头
- 上下看、缩放
