# 看场合主动开口 — 设计

日期：2026-09-29　状态：**设计已和用户确认**，待写实施计划

远期目标（用户）：把团子做成像 Neuro-sama 那样"有存在感"的**游戏里的伙伴**（不做主播）—— 性格鲜明，会对眼前的事起反应、自己找话，记得每个人。
这份设计是其中第一个子项目：**视觉给聊天用 —— 看到了就有话说**。物品定位、地形识别要等 `move` 工具（`2026-09-27-brain-move-design.md`），另开设计；
认地图（三期 §2）代码已有，待图库和真机验收。

## 现状

- 身体有事件叫醒大脑：`arrive` / `leave` / `stranger` / `scene_change`……（`brain/body.py`）；没事件时按心跳 45 / 90 / 180 秒醒（`[brain] heartbeat`）
- 眼睛（Haiku）在有人来 / 走 / 画面大变后（隔 ≥ `auto_look_min` 20 秒）或 `auto_look_max` 180 秒没看时自动看，写一份四项描述缓存起来，大脑醒来时附上（`brain/eyes.py`）
- **缺口 1**：每次描述都是从头写，没人比较"这次和上次有什么不同"，天黑了 / 好友换了斗篷 / 有人坐下弹琴都不会变成事件
- **缺口 2**：提示词写着"没人理你的时候别自言自语"（`brain/prompt.py`），就算看到了也会憋着

## 需求（已和用户确认）

1. 路线：先给聊天用（这份），之后再让团子动起来
2. 定位：游戏里的伙伴，暂不考虑主播方向
3. **看场合**：好友在身边、大家在聊时活跃一些（接梗、对眼前的事吐槽）；好友都安静时偶尔找个话头；只有陌生人或没人时基本不说
4. **主观判断**：说不说、说什么由大脑自己判断，不是写死的规则；说的话带自己的看法和喜好，前后一致。代码只给材料 + 守底线
5. 方案 B：**眼睛做初筛**（对比上次，挑出新鲜事候选），**大脑做决定**，**身体守护栏**
6. 喜好初版由 Claude 按现有人设补几条，用户再改（附录 A）

## 总览

```
眼睛（Haiku，自动看）──“新鲜事”──┐
认地图（places，换了地方）───────┼─→ 身体：notice 事件（没熟人 / 额度用完就不发）─→ 大脑醒来
                                  │
身体每次拼 status ──→ occasion.py：场合（热闹 / 安静 / 没熟人）+ 事实 + 还能主动说几句
                                  │
大脑（提示词：看场合、带看法、可以用动作、可以不说）──say──→ 身体护栏（只管主动开口）──→ 游戏
```

## §1 视觉侧：眼睛挑新鲜事（`brain/eyes.py`）

1. **描述加第五项"新鲜事"**：眼睛看图时附上**上一份描述**和它是多久前看的，请求末尾加：
   > 新鲜事：和上次比，有没有值得跟朋友提一句的变化？最多两条，一条一句；没有或拿不准就写"无"。

   附例子：
   - 值得：天黑了 / 下雨了、到了新地方；好友换了斗篷 / 发型；好友在做有意思的事（弹琴、坐下、睡着冒 Z、放烟花、跳舞）；出现显眼的东西（篝火、先祖、冥龙、彩虹）
   - 不值得：镜头角度变了、人挪了几步、陌生人来来去去（身体已经有事件）

   同一次 Haiku 调用，不多花一次。没有上一份（刚启动）或上一份超过 `prev_max_age`（600 秒）时，请求里不加这一项（不和太旧的比），
   这次也就不会发 `notice`。解析：取"新鲜事："之后的内容，是"无"/ 空 / 解析不到都当没有。大脑看到的描述里照样带这一项。
2. **变成事件**：只有**眼睛自动看**（`tick`）得到的新鲜事才让身体放 `notice` 事件，文字"眼睛注意到：天黑了；小明坐下弹琴了"。
   大脑自己调 `look` / `look_around` 不发（它已经看到了）。
   去重：距上一个 `notice` 不到 `notice_min`（60 秒）不发；和上一条内容几乎一样（归一化后相同）不发。
3. **换地图**：身体每圈看 `env.place`（三期认地图；EnvWatcher 读地名也是这个字段），从一个非空值变成另一个非空值时发 `notice`："看起来到了雨林"。
   从空变成有、从有变成空都不发（刚启动、认不出不算"换了地方"）。和眼睛的 `notice` 共用 `notice_min` 去重
4. **好友在身边时看得勤一点**：好友在身边时 `auto_look_max` 换成 `auto_look_busy`（60 秒），否则仍是 180 秒。
   代价：好友在身边时每小时最多约 40 次额外的 Haiku 调用，可调
5. `notice` 的过滤（没熟人 / 额度用完不发）见 §4

`notice` 不在 `AUTO_LOOK_KINDS` 里（它本来就是看出来的，不再触发看）。

## §2 场合信息（新文件 `brain/occasion.py`）

纯计算、不碰设备，输入身体已有的数据，输出给大脑看的一行 + 给护栏用的结构化结果。身体每次拼 `status` 时调它，大脑每次醒来都看得到。

**输入**
- 身边的好友 `env.nearby(now)`、陌生人数 `env.strangers(now)`（没有这个方法当 0）
- 最近的聊天 `body.chat`（时间、说话人、内容；团子自己是"我"）；说话人按 friends.md 的名字模糊匹配（和 env 认名字同一个匹配函数）分出好友
- 团子说过的话：`body.said` 之外新记一份 `(时间, 内容, 主动?)`。**主动** = 说话时 `brain_busy()` 为假（这一轮不是被聊天 / 主人命令叫醒的；
  被 `notice`、心跳、别的事件叫醒后开口都算）。手动控制（`live=True`）说的不记进来（不是团子的判断）

**档位**
- **热闹**：好友在身边，且最近 `busy_window`（180 秒）里别人（不含"我"）说了 ≥ `busy_lines`（4）句
- **安静**：好友在身边，但没到热闹
- **没熟人**：身边没有好友（只有陌生人或没人）

**事实**
- 上次主动开口：多久前、说了什么、**有没有人接** —— 主动那句之后 `reply_window`（90 秒）内有好友说话就算有人接（话里带团子的名字时标"叫了你"）；
  窗口还没过完写"还在等"；过完了没人说话写"没人接"
- 最近 `quota_window`（600 秒）里主动说了几句、几句有人接
- 这会儿还能主动说几句（§4 的额度减去已用；冷场暂停 / 没熟人时是 0，并写原因）

**大脑看到的样子**（`status` 里多一段，放在"刚说过"后面）

> 场合：热闹（身边 小明、阿花；最近 3 分钟别人说了 7 句）/ 上次主动开口 4 分钟前「这图好黑」，小明接了话 / 最近 10 分钟主动说了 2 句，1 句有人接 / 这会儿还能主动说 1 句

**别的地方**
- 可视化网页和管理面板的状态卡片加"场合"（档位 + 还能主动说几句），调参时看得到
- 心跳不动：好友在身边 45 秒、闲着逐档退到 90 / 180 秒；"安静时偶尔找个话头"就靠它

## §3 性格和提示词（`brain/prompt.py`、`cli.py`、`chat/memory.py`）

**1. 提示词**：删掉"没人理你的时候别自言自语"，在"说话"后面加一节"## 主动开口"，大意：

- 看状态里的"场合"：
  - 热闹：可以接梗、插一句吐槽、对眼前的事发表看法；别人聊得正起劲时别硬转话题
  - 安静：偶尔抛个话头就够 —— 眼前的新鲜事、好友的近况（记忆里有的）、以前聊过的事（先 `recall` 确认）
  - 没熟人：不主动开口
- 要有自己的看法，不要播报："天黑了" ✗ → "一到晚上这图就阴森森的" ✓；"小明在弹琴" ✗ → "小明这首弹得还挺像样" ✓。喜好照人设，前后一致
- "眼睛注意到"的新鲜事不是任务：大多数不用说，只挑自己真有想法的
- 分寸：上次主动没人接就收一收，过一阵再说，别连着抛话题；一次只主动说一句；不用问句开场硬找话
- 不开口也可以用动作：好友弹琴可以鼓掌、被夸可以害羞 —— 光遇本来就靠动作交流，动作不占聊天
- 想了但决定不说：在心里写一句"不说：原因"（不会发出去，调参时在时间线上看得到它为什么忍住）
- 被护栏拒了（§4）就照它说的等，别换个说法再试

"## 你在做什么"里对 `notice` 事件加一句说明（身体会把眼睛注意到的新鲜事告诉你）。

`[proactive] enabled = false` 时用原来的规则文本（保留旧那句、不加新一节），行为和现在一样。

**2. 喜好和看法**
- 人设（用户写）：`memory init` 的 `PROFILE_TEMPLATE` 加一节"## 喜好和看法"，内容用附录 A 的初版（用户的 `profile.md` 在 `memory/`，不进 git，由用户自己复制过去再改）
- 团子自己形成的看法（自动）：随手记的 `MEMO_SYSTEM` 已经会记"我新说出口的关于自己的设定"，明确加上"**喜好和评价**（比如"我说雨林太湿，不喜欢待"）"，
  整理进 notes.md 后下次还是这个态度

**3. 旧的 history 先不清**：`history.jsonl` 里都是接话的回合，只是没主动、不和新规则矛盾，清了反而丢掉接得上话的上下文。
真机跑下来明显太保守，再照 CLAUDE.md 的老办法挪进 `memory/archive/`。

## §4 护栏（`brain/body.py`）

只管**主动**开口（§2 的定义）；接话、主人手动控制（`live=True`）不受影响；现有的 `reply.min_interval` / `max_per_minute`、每轮最多 2 句对所有发言照旧。
在 `body.say` 里、`clean_reply` 和现有限速之后检查：

1. **没熟人不主动**：场合是"没熟人" → 拒绝："身边没有好友，不主动开口"
2. **额度**：最近 `quota_window`（600 秒）里主动说的句数，按说话这一刻的档位：热闹 ≤ `quota_busy`（4），安静 ≤ `quota_quiet`（2）；超了拒绝，写明最早什么时候恢复
3. **间隔**：两句主动的话之间 ≥ `min_gap`（60 秒）；拒绝时写还要等几秒
4. **冷场收手**：连续 `cold_after`（3）句主动都没人接（按 §2 的判定，还在等的不算）→ 暂停主动，直到有好友说话（任何一句）为止；拒绝时说明原因

拒绝都用 `ToolError`，措辞写给大脑看、说清原因和要等多久。dry-run 说的话也记进"说过的话"，额度和冷场照算（不真发也能看出它会多主动）。

**省额度**：场合是"没熟人"、或这会儿还能主动说 0 句时，§1 的 `notice` 不发（为了做个动作叫醒一轮 Sonnet 不划算）。

## 配置（新 `[proactive]`，`config.py` 的 `ProactiveConfig`）

| 键 | 默认 | 作用 |
|---|---|---|
| `enabled` | `true` | 总开关；`false` = 完全照旧（旧提示词、不发 `notice`、眼睛不写新鲜事、不加护栏、status 不加场合） |
| `notice_min` | 60 | 两个 `notice` 至少隔几秒 |
| `prev_max_age` | 600 | 上一份描述超过几秒就不拿来比 |
| `auto_look_busy` | 60 | 好友在身边时眼睛最久几秒看一次 |
| `busy_window` / `busy_lines` | 180 / 4 | 热闹：这么多秒里别人说了至少这么多句 |
| `reply_window` | 90 | 主动那句之后多少秒内有好友说话算有人接 |
| `quota_window` | 600 | 主动额度的时间窗口 |
| `quota_busy` / `quota_quiet` | 4 / 2 | 热闹 / 安静时窗口内最多主动说几句 |
| `min_gap` | 60 | 两句主动的话之间至少隔几秒 |
| `cold_after` | 3 | 连续几句主动没人接就暂停主动 |

`config.example.toml` 加这一节（带注释）；管理面板设置清单（`console/settings.py`）加 `enabled`、`quota_busy`、`quota_quiet`、`min_gap`、`auto_look_busy`。

**所有数字都是估的，没在真机验证**，真机跑时靠 `run --view` 的大脑时间线和 `brain.jsonl` 调。

## 测试（`python -m pytest -q`，不需要模拟器）

- 眼睛：新鲜事"无" / 空 / 解析不到 → 不发；有内容 → 一个 `notice`；`notice_min` 内第二条不发；内容相同不发；大脑调 `look` 不发；
  上一份超过 `prev_max_age` 不带、刚启动不带；好友在身边时 `auto_look_busy` 生效
- 换地图：非空 → 另一个非空才发；空 ↔ 有不发
- 场合：三档分对；"有人接" / "还在等" / "没人接"；10 分钟统计；主动 / 接话的区分（`brain_busy`）；手动控制不算
- 护栏：四条各拦一次；接话、手动控制不受限；额度随时间恢复；好友说话后冷场解除；dry-run 也计数；没熟人 / 额度 0 时 `notice` 不发
- 总开关 `false`：规则文本是旧的、不发 `notice`、status 没有场合、主动说话不拦
- 模板：`PROFILE_TEMPLATE` 带"喜好和看法"；`MEMO_SYSTEM` 带"喜好和评价"

## 真机验证（单元测试过了不等于游戏里能用）

1. `run --view`（dry-run）和好友待 20 分钟以上：时间线里 `notice` 的频率、新鲜事是不是编的、大脑说 / 不说的理由（"不说：…"）
2. 热闹 / 安静 / 一个人三种场合各看一阵：一个人时一句都不主动；安静时不刷屏
3. 喜好前后一致：同一个话题隔一阵再提，态度一样
4. `--live` 小范围试（只有熟人在的时候），看好友的反应，再调数字

## 不做（这一期）

- 让团子为了"有话说"主动转镜头 / 环视（`look_around` 仍然由大脑按需调）

## 附录 A：喜好和看法（初版，用户改）

```markdown
## 喜好和看法
- 地图：最喜欢云野，能坐着看云海；霞谷的滑道很爽；雨林湿漉漉的，不爱久待；暮土有冥龙，嘴上说不怕，其实会躲
- 装扮：樱花发型天下第一；喜欢浅色、粉色系的可爱斗篷，看到好看的会忍不住夸、问在哪换的

- 说话的态度：夸人是真心的，不敷衍；吐槽点到为止，不损人
```
