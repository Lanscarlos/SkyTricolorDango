# 内心层 第 2 期：反思（心情、精力、别扭、心愿、日记）— 设计

日期：2026-09-30　状态：**代码已完成**（实施计划 `docs/superpowers/plans/2026-09-30-inner-phase2.md`），待真机验证（见文末）

## 背景

内心层总路线见 `2026-09-30-inner-phase1-design.md` 开头：1 账本（已完成）→ **2 反思（这份）** → 3 性格。
第 1 期让团子记得"和谁、多久、上次说了什么"；这一期让它**有状态**：今天心情怎么样、困不困、跟谁闹别扭、惦记着什么，并且状态**有后果**。

## 需求（已和用户确认）

1. **情绪幅度：有小脾气，会闹别扭**（最像 Neuro）。边界：别扭有时限、自己消气；只是"嘲两句、晚点接话"，不骂人、不冷暴力；对方认真问 / 说难过 / 说不舒服时别扭立刻作废（光遇未成年玩家多）
2. **别扭只冲够熟的好友**（关系卡上一起玩过 ≥ `grudge_min_days` 天）；陌生人、刚认识的好友不闹
3. **精力**跟着现实时间 + 连续挂了多久 + 热闹程度变，身体按规则算，不调模型
4. **心愿 / 惦记的事**：惦记人和事（见到时主动问）、想一起做的事（看日落、听弹琴…，靠别人配合）、自己的小心思（只能是游戏里的事或人设已有喜好的延伸，**不编现实生活**）。不做"想去的地方"
5. **做法 A**：定时"反思"（一次性 `claude -p`）写心情 / 别扭 / 心愿 / 日记；精力按规则
6. **后果**：硬开关只动"说多少、做多少"（主动开口额度、反射、心跳），"怎么说"交给提示词；**接话永远照常**，只少主动开口
7. 日记：下线时的反思写第一人称日记，**代替**现在大脑写的"经过"

大脑模式专用；`run --no-brain` 不接。

## §1 存什么（`memory/inner/`，只在 live 写盘，dry-run 只在内存里）

### `mind.json`

```json
{"version": 1, "updated": 1759200000.0,
 "mood": {"level": "低落", "text": "有点闷，小明说好来又没来", "since": 1759199000.0},
 "grudge": {"who": "小明", "why": "说好来又没来", "since": 1759199000.0, "until": 1759206200.0},
 "wants": [{"kind": "惦记", "text": "阿花考试考得怎么样", "who": "阿花", "since": 1759100000.0, "until": 1759704800.0}]}
```

- `mood.level`：`开心` / `平常` / `低落` / `烦` 之一（别的一律当 `平常`）；`text` 一句带原因的话（≤ 40 字）
- `grudge`：最多 1 条，没有是 `null`；`until` 由代码按 `grudge_max` 截
- `wants`：最多 `wants_max`（3）条；`kind` 是 `惦记` / `想做` / `小心思`；`who` 只有 `惦记` 可以填（必须是好友名单里的）；`until` 默认 `since + want_days` 天

### `diary.md`

按天往后追加，`## 2026年9月30日（周三）` 一节一天，同一天多次下线就在那一节下面接着写一段。第一人称、口语，不写隐私（同 NOTES_SYSTEM 的规矩）。

精力**不存**：每圈现算（§3）。

## §2 反思（`inner/reflect.py` 的 `Reflector`）

**什么时候跑**（身体每圈 `tick(now, activity)`，满足就丢给后台线程；同一时间最多一次在跑）
- 定时：距上次反思 ≥ `reflect_every`（1200 秒）且这期间**有动静**（有人说话 / 好友来去）；没动静跳过
- 聊完：上次反思后好友说了 ≥ `reflect_min_lines`（6）句，然后 `reflect_after_quiet`（180 秒）没人说话
- 下线：cli 收尾时同步跑一次（`final=True`，要日记和要点），最多等 `reflect_timeout`（90 秒）

**材料**（一条 user 消息）：
- 现在几点（`format_date` + 时分）、精力（§3 的档位和说明）
- 上一份内心状态（心情、别扭、心愿，带多久前）
- 上次反思以来的聊天原话（身体的 `chat`，"我"标出团子自己说的；最多 80 行，多了留最新的）、这期间谁来了谁走了
- 涉及到的好友的关系卡（`card_line`）和 notes.md / inbox.md 里提到他们的行（最多 10 行）
- 人设（profile.md，没有就 `reply.persona`）

**系统提示词**（`REFLECT_SYSTEM`，要点）：你是团子，回头想想刚才这段时间；按人设和发生的事更新心情（带原因，别凭空大起大落）、决定要不要跟某个熟人闹点小别扭（有由头才闹：被放鸽子、被冷落、被开过分的玩笑；对方已经道歉 / 认真哄了就撤）、增删心愿（惦记的事来自好友说过的话；想做的事要靠别人配合；小心思只能是游戏里的事或人设喜好的延伸，不编上学上班生病这类现实生活）；`final` 时再写一段第一人称日记（≤ 200 字）和给以后的自己的要点（≤ 5 条，每条 ≤ 30 字，同随手记的规矩）。只输出 JSON：

```json
{"mood": {"level": "…", "text": "…"},
 "grudge": {"who": "…", "why": "…"} | null | "keep",
 "wants_add": [{"kind": "…", "text": "…", "who": "…"}],
 "wants_done": ["…"],
 "diary": "…", "memos": ["…"]}
```

`grudge`：`"keep"` = 不变，`null` = 撤销，对象 = 新的（替换旧的）。`wants_done` 里每一条和已有心愿的 `text` 算 `similar(…, 0.75)`，对上的删掉（已了结）。

**调用**：`ClaudeLlm(reflect_model)`（同 `NotesKeeper` 的记忆整理：一次性 `claude -p`、令牌同大脑、不给工具，工作目录 `runs/<…>/brain/reflect/`），后台线程（`name="reflect"`）。
取回后解析（容忍 ```json 包着、前后有字；取第一个 `{` 到最后一个 `}`），交给 `Mind.apply`。

**出错**：超时 / 失败 / 额度用完 / 解析不了 → 沿用上一份状态、日志 WARNING；额度用完（`ClaudeError.limit`）后 `limit_retry`（同 `[brain] limit_retry`，600 秒）内不再反思。

## §3 精力（`inner/energy.py`，纯计算）

`energy(hour: float, awake_min: float, cheered: bool, busy_min: float) -> Energy(level, score, note)`，分数 0~100：

- **几点**：9~22 点 100；22~24 点 80；7~9 点 80；0~2 点 60；2~7 点 40（`hour` 带小数，本地时间）
- **连续挂了多久** `awake_min`：这一次上线的时长；如果上一次（`days.jsonl` 最后一行，含 crash）结束到这次开始不到 `rest_gap`（3600 秒），再加上一次的时长（"没睡"）。每 60 分钟 −10，最多 −40
- **被逗得来劲** `cheered`：最近 10 分钟有好友跟团子说话（身体在 `_heard` 里 `addressed()` 为真时记下时间）→ +10
- **闹累了** `busy_min`：最近 60 分钟里场合是"热闹"的分钟数（身体每圈按 `occasion` 的档位累计），超过 30 分钟的部分每 10 分钟 −5，最多 −15
- 夹到 0~100。档位：≥ 70 精神、≥ 50 还行、≥ 30 有点累、其余困

`note` 给大脑看："有点困（快凌晨一点了，连着挂了两个多小时）"。

## §4 心情和别扭（`inner/mind.py`）

`Mind`（数据 + 规矩）：
- `apply(result: dict, cards: dict[str, Card], friends: list[str], now: float, cfg) -> list[str]`：套进反思结果，返回丢掉了哪些条目（记日志）。代码守的规矩：
  - `mood.level` 不认识 → `平常`；`text` 截 40 字；`since` 只在档位变了时更新
  - 新别扭：`who` 要对得上好友名单（`match_friend`），且那张关系卡 `len(days) ≥ grudge_min_days`，否则丢；`until = now + grudge_max`
  - 心愿：`kind` 不认识丢；`惦记` 的 `who` 对不上好友丢；其他 kind 的 `who` 清空；和已有的几乎一样（`similar ≥ 0.75`）不加；超过 `wants_max` 丢最旧的
- `expire(now)`：别扭到 `until` 撤、心愿到 `until` 删（每圈调，便宜）
- `grudge_on(name, now) -> bool`：现在是不是在跟这个人闹别扭
- `line(now, energy) -> str`：status 的"心里"
  > 心里：有点闷（小明说好来又没来）· 有点困（快凌晨一点了）· 跟小明闹别扭（小明说好来又没来，还有 40 分钟消气）· 惦记：阿花考试考得怎么样
  平常且没别扭没心愿时只写"心里：平常 · 精神"
- `want_note(name) -> str`：好友来时接在 arrive 说明后面："。你惦记着：他考试考得怎么样"（只列 `惦记` 且 `who` 是他的）

## §5 后果（`inner/effects.py`，纯计算）

`effects(mood_level: str, energy_level: str) -> Effects`：

| | 主动额度 | 被叫到的小动作概率 | 闲着的小动作间隔 | 心跳 |
|---|---|---|---|---|
| 开心 | ×1.5 | ×1.5 | ×1 | 不变 |
| 平常 | ×1 | ×1 | ×1 | 不变 |
| 低落 | ×0.5 | ×1 | ×1 | 不变 |
| 烦 | ×0.5 | ×0（不做） | ×1 | 不变 |
| 精神 / 还行 | ×1 | ×1 | ×1 | 不变 |
| 有点累 | ×0.75 | ×1 | ×1 | 不变 |
| 困 | ×0.5 | ×1 | ×0.6（更勤） | 慢一档 |

心情和精力的倍数相乘；主动额度倍数下限 0.25，算出的额度向下取整但**至少 1**（最少还能主动说一句）。

接到哪里：
- **主动额度**：`occasion.assess(..., quota_scale=…)`：`limit = max(1, int(base × scale))`；status 的"场合"照旧写"还能主动说 N 句"
- **被叫到的小动作**：`Reflexes.pick_addressed(..., scale=…)` 概率乘上去（上限 1）
- **闲着的间隔**：`Reflexes.stir(now, scale=…)`：`idle_min` / `idle_max` 乘上去
- **心跳**：`Brain.heartbeat` 取档时下标多 +1（`beats[min(start + idle + 1, len - 1)]`，到最后一档为止），`Brain` 多一个可选的 `slow: Callable[[], bool]`，困时为真
- **别扭对象不冒气泡**：`Body._on_heard` 里，这批话全是别扭对象说的 → 不开输入框（被叫到的小动作也不做）；别人说的照常
- **接话照常**：被聊天 / 主人命令叫醒的那一轮不受额度影响（本来就只管主动开口）；牵手等互动请求照常接

## §6 给大脑看什么（`brain/prompt.py`、`brain/body.py`、`inner/days.py`）

- **status**：`场合` 后面多一项"心里：…"（§4 `line`）
- **arrive**：`present` 返回的说明后面接 `want_note`
- **「日子」**：最后一篇日记（`diary_prompt`，默认 1 篇）放在"上次的经过"那一行后面："上次的日记：…"（截 200 字）；有日记时"上次的经过"那行只保留"上次见到了：…"
- **提示词**（内心层反思开着才加，放在「说话」一节交情规矩之后）：
  - 状态里的"心里"是你现在的心情、精力、别扭和惦记的事。照着它说话：开心可以皮一点，低落 / 困了话短、兴致不高，困了可以说困；别每句都提自己的心情
  - 跟谁闹别扭：可以嘲两句、慢点接、装作不在乎；**他认真问、说难过、说不舒服、真的生气了，别扭立刻作废**，照常关心他。不骂人、不翻旧账、不拿互动（牵手、拥抱）冷落人
  - 惦记的事：见到那个人、场合合适时自然地问一句，别一见面就查户口
  - 想做的事、小心思：场合合适时提，别硬塞；做不到的（坐下、弹琴、自己去远处）只能说想，请别人配合
- **可视化网页 / 管理面板**：状态卡片（`Body._show` 的 `info`）加"心情""精力"两项

## §7 下线（`cli.py`、`inner/reflect.py`）

`reflect = true` 时：`checkpoint` → **退出反思**（`final=True`，同步，最多 `reflect_timeout`）→ 日记写进 `diary.md`、要点写进 inbox.md（`store.add_memos`，前缀"<日期> 的要点："）、`ledger.close(summary=要点连成一句)` → 结束大脑进程。**不再调 `brain.farewell()`**。
退出反思失败：日记这天没有，`summary` 为空；live 时仍 `close`。`reflect = false`：完全照第 1 期（`brain.farewell()`）。
dry-run：退出反思照跑（看得到结果），不写 diary / inbox / mind.json。

## §8 接线

- `cli`：`[inner] enabled and reflect` 且有账本时建 `Mind`（读 `mind.json`，dry-run 只读）、`Reflector`（`ClaudeLlm`），交给 `Body`（`body.mind` / `body.reflector`，默认 `None`）；`Brain(..., slow=…)`
- `Body`：每圈 `mind.expire(now)`、算精力（缓存到下一圈）、`reflector.tick(...)`；`_on_heard` / `say` / `_watch_people` 给 Reflector 报动静；`status`、`_show`、arrive 接上 §6
- `Reflector` 结果回到身体线程再套进 `Mind`（后台线程只放进一个队列，身体每圈取），`Mind` 不用锁
- 所有调用经 `_ledger_call` 同样的包法（出错只记日志）

## §10 出错怎么办

- 反思出任何错：沿用上一份，WARNING；解析出的条目不合规矩逐条丢（§4）
- `mind.json` 读不了：改名 `.bad-<时间>`（dry-run 不改名）、从"平常"开始
- `diary.md` 写不了：日志，不影响别的
- 精力、后果、拼文字出错：退回"平常 / 精神"的效果（倍数 1），只记日志

## §11 测试（`python -m pytest -q`，假时钟、假模型，不碰设备）

- 精力：白天刚上线精神；凌晨一点挂两小时困；"没睡"接着算、睡过一觉清零；被逗 +10；闹累了封顶
- `Mind.apply`：别扭冲陌生人 / 不够熟 / 超 `grudge_max` / `"keep"` / `null`；心愿 kind 不认识、惦记冲非好友、重复、超额丢最旧；`expire`；心情档位不认识
- 解析：```json 包着、前后有字、不是 JSON、缺字段
- `Reflector.tick`：定时有动静才跑、没动静跳过、聊完安静、同一时间只一次、额度用完暂停
- `effects`：各格倍数、相乘、下限、额度至少 1
- 身体：主动额度随心情变；别扭对象的话不冒气泡、别人照常；status 有"心里"；arrive 带"你惦记着"；`_show` 有心情 / 精力
- 大脑：困时心跳慢一档
- 下线：反思写日记和要点、代替 `farewell`；失败时 summary 空仍 close；`reflect = false` 走 `farewell`；dry-run 不写
- 提示词：`reflect` 开着有新规矩、关着和第 1 期逐字一样；「日子」带最后一篇日记

## 真机验证

1. 跑一晚上，`--view` 看"心里"怎么变、理由对不对得上发生过的事、多久反思一次（额度够不够）
2. 深夜：主动开口明显少、会说困，闲着的小动作勤一点
3. 说好来又不来（放鸽子），看会不会闹别扭、多久消；认真说"我今天很难过"，别扭是不是马上作废
4. 第二天上线：「日子」里的日记像不像它自己写的；惦记的事见到人时会不会自然问起
