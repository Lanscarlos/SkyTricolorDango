# 团子接下来要做的 8 件事：路线图

日期：2026-10-04。这是一份路线图，不是某一项的设计：每一项开工前单独走 brainstorming → spec → plan。
8 项是用户 10-04 晚列的（原本乱序），排序、推进方式和下面「已定」里的取舍是当晚和用户逐条问定的。

## 已定

| 问题 | 定了什么 |
|---|---|
| 先往哪个方向推 | **A 组：陪好友更像个人**（③ → ① → ⑥）；然后 B 组「能去社交场景」（④、⑤）、C 组「能自己行动」（⑦、②），⑧ 最后 |
| ① 认陌生人认多久 | 先做**这次上线里**认得；跨天认人写成远期目标 |
| ① 陌生人叫什么 | **按装扮起外号**（「白斗篷」），装扮描述回来前用编号顶着，撞名加数字；黑影不编号、不起外号 |
| ③ 不是跟团子说的话 | **默认不接、偶尔插一句**，插话算进主动开口的额度 |
| ⑥ 自己改轮盘 | **团子自己决定轮盘长期放什么**，锁定的格子不动，下线换回用户的配置 |
| ⑧ 自主学习学什么 | **学认东西**：不认识的先存、找机会问、问到了记进知识库 |
| ②b 认交互图标 | 代码完成（10-05，`docs/superpowers/specs/2026-10-05-icon-detection-design.md`），等真机：还缺地图图标的模板 / 参考图、标好的数据、新 YOLO |
| 推进方式 | A 组一项一项做完再做下一项；B、C 组先做最小能用的版本再加深；知识库不提前搭，做到 ② 或 ⑧ 时再从已有数据里抽出来 |
| ② 往前挪（10-05 改） | **拆成两段**：② 最小版（核对现有 6 张卡、认常见的图标按钮、没见过的面板不乱按）和 ③ **并行**——白天做 ③（离线标注、沙盒），晚上在真机录面板样本；② 完整版（一张张加面板、写进知识库）留在后面，和 ⑧ 挨着做 |
| ② 的「图标」包括地图上的（10-05） | 不只面板上的按钮，还有**地图里走近人 / 物件时冒出来的交互图标**：陌生人点火、地图里能点亮的蜡烛 / 灯、散落的共享空间、留影、音乐、座位的坐下……最小版**只认、不点**：认出来告诉大脑（在哪个方向、多远），点击归到用它的那一项（坐下归 ④；点火沿用现在的逻辑；共享空间「加入」永远不点）。「蜡烛 / 灯」指地图摆件的点火提示，**不是烛火堆这类收集品**（不刷资源那条照旧） |

## 顺序

```
( ③ ∥ ②最小版 ) → ① → ⑥ → ( ⑦最小版 → ④ → ⑤ ) → ⑦完整版 → ( ②完整版 → ⑧ )
```

依赖：⑤ 要 ④（先坐得上交流座位）和 ①（陌生人的外号）；④ 要 ⑦ 的最小版（走到座位旁边）；⑧ 的知识库从 ⑥ 的动作名、装扮图鉴、② 的面板里长出来。
A 组三项互不依赖，排这个顺序是按「花的力气 / 对"像不像人"的影响」排的。
② 最小版不依赖别的项，提前做是因为后面好几项都会碰到面板和图标：⑥ 改轮盘经过「动作面板」「轮盘编辑」两张卡，④ 坐下、⑤ 交流座位、⑦ 走路都可能弹出提示或面板；
没核对的卡现在只报告、不自动关，`clear_view` 拦下后交给大脑，大脑容易乱按（09-30 掉线那次连按灰的「取消」）。
地图交互图标对 B 组帮助更大：坐下图标一出现，就说明那里有座位、而且已经走得够近了，④ 不一定要等 YOLO 学会 `bench`；⑦ 的「走过去」也多一个看得见的目标。

## A 组：陪好友更像个人

### ③ 分清好友在跟谁说话（第一个做）

- **目标**：好友之间聊天时团子默认不接；叫到它、接它的话、问大家的问题才接；觉得有意思偶尔插一句，算进主动开口的额度
- **现状**：`brain/reflex.py` 的 `addressed()` 规则从严，但只用来决定冒不冒输入气泡、做不做小动作；大脑提示词里只有一句「明显不是跟你说的，不用回」（`brain/prompt.py`），实际上基本见话就接
- **要做的**：
  - 每条消息由身体先给一个判断：**跟你说 / 跟别人说 / 说给大家 / 拿不准**。依据：叫没叫团子的名字（`[proactive] self_names`）、是不是在接团子上一句、有没有叫别的好友的名字、身边几个人、前后几句是谁在跟谁一来一回。规则判得准的直接定，拿不准的交给大脑自己判断
  - 大脑收到的聊天事件带上这个标注；提示词把那一句改成明确的规矩；插话走主动开口的护栏（额度、间隔、连续没人接就停）
  - 反射（冒输入气泡、被叫到时的小动作）改用同一个判断，不再各管一套
- **怎么算做成**：
  - 离线：从 `history.jsonl` 和各次运行的 `a11y.jsonl` 里挑一批真实的多人聊天，人工标「是不是跟团子说的」，判准率过线（门槛在 ③ 的 spec 里定）；旧日志上的数字只作参考，正式门槛用合并后录下的新日志算
  - 沙盒：新写剧本「两个好友互相聊」，团子大部分时候不插嘴、被叫到立刻接
  - 真机：一晚上没有好友吐槽「怎么什么都接」
- **spec / 计划**：`docs/superpowers/specs/2026-10-05-addressee-design.md`、`docs/superpowers/plans/2026-10-05-addressee.md`（10-05 代码做完，**还没在真机验证**；离线评估还没在真实数据上跑，「怎么算做成」的结果等真机后再记）

### ② 最小版：认面板、面板上的图标按钮、地图交互图标（和 ③ 并行）

- **目标**：日常最常弹出来的面板和按钮认得出、知道怎么关；地图里冒出来的交互图标认得出、告诉大脑在哪；没见过的面板说「不认识」、不乱按。**这一版只认、不点地图图标**
- **现状**：
  - 面板：`[panels]` 有 6 张特征卡（聊天记录面板、动作面板、轮盘编辑、好友树、共享空间邀请、掉线弹框）+ 通用兜底，全都没在真机核对、缺模板图 / 截图；
    细读靠 OCR 读按钮上的字，**只有图标没有字的按钮**（×、返回箭头这类）认不出来
  - 人身上的圆圈：好友名字下方的圆圈有模板（`assets/social/` 10 张：牵手、拥抱、击掌、火焰、共享空间……，`game/social.py` 匹配）；陌生人头顶的圆圈靠 YOLO `social_ring`；
    陌生人举蜡烛 / 火焰圆盘靠 `vision/candle.py`（`white_ring`）分
  - **地图物件上的交互图标完全没有**：坐下、能点亮的蜡烛 / 灯、散落的共享空间、留影、音乐……YOLO 没这个类别，也没有模板。
    篝火「点燃」图标现在还会被当成陌生人的火焰圆圈（game-ops §6 风险那条），认出来正好排除掉
- **要做的**：
  - 晚上真机录样本，把 6 张卡核对完（`panels scan` / `cut` / `read`，改 `verified = true`），核对过的 `auto` 卡由 `clear_view` 自动关
  - 和用户一起列图标清单（先少后多）：面板上的图标按钮 + 地图交互图标（第一批：陌生人点火、蜡烛 / 灯点火、共享空间、留影、音乐、坐下、篝火点燃）；
    晚上在几张常去的地图上走近这些东西录样本，录法和每个图标长什么样、出现在哪、点了会怎样写进 game-ops
  - **认法：所有图标交给 YOLO 框，再分三步**（10-05 和用户定的方向，细节在 spec 里定）：
    1. **YOLO 只管「这里有个图标」**：人头顶的圆圈、火焰圆盘、举蜡烛的白圈火焰、坐下、蜡烛 / 灯、留影、音乐、共享空间、篝火点燃……只标一个类别
       （初步想法是把 `social_ring` 扩成它，旧标注不用改）；图标小、长得像，拆成十几类每类样本太少，以后加一种图标也不用重标重训
    2. **第二层认是什么图标**：先用现有模板库（`assets/social/`，YOLO 框给了尺寸，缩放到统一大小再比）；不够稳再换冻住的 DINOv2 + 线性头，复用第二层（`vision/attrs.py`）和标注页，加一个「图标」标签页
    3. **看图标附近是谁 / 是什么**：先看几何关系——正下方有人物框 = 他的，是黑影 = 点亮他，有 `bonfire` 框 = 篝火，什么都没有 = 地图物件；说不清的再把图标下面裁一块交给分类器判（陌生人、蜡烛台、灯、乐谱……），只当兜底
  - 火焰也走这条路：替掉 `vision/candle.py` 按颜色找火焰（`find_flames`）这一步，灯笼、篝火点燃、好友标签下 / 聊天面板下的火焰这些补丁规则改由「图标 + 附近是什么」统一解决；
    「火焰怎么消失」的时序判断（`vision/lighting.py`）不变，只是输入改成 YOLO 的图标轨迹。**不许退步**：`tests/test_light_replay.py` 的 14 次回放至少一样对才换，换之前两套并行、`candle.py` 当退路
  - 标注：`datasets/sky` 几千帧都要补标图标，Claude 标小东西不行（标气泡的教训）——先用现有的 `find_flames`、圆圈模板、`white_ring` 预标，人只改；再加晚上各地图录的新样本。
    远处的小图标可能要借 `far_crops`；手里举着的蜡烛火苗算不算图标、和头顶火焰圆盘是不是一回事，先在真机看清楚写进 game-ops 再定标注规则
  - 认出来的地图图标进 status 和眼睛的位置说明（「右边近处：坐下图标」），跟着画面在不在、方位远近走；管理面板画面上画出来
  - 不认识的面板：照现在的通用兜底只报告，提示词里写清「不认识就别按、等卡洛」
- **不做**：点地图图标（坐下归 ④；蜡烛 / 灯、留影、音乐等以后要点时单独定）；烛火堆这类收集品（不刷资源）；共享空间「加入」永远不点
- **怎么算做成**：6 张卡真机核对通过；清单里的图标在录的样本（含没参与做模板 / 训练的地图）上认得出、认错少；一晚上没有因为面板挡住而乱按或卡住

### ① 认回已点火的陌生人

- **目标**：这次上线里，点过火的陌生人走开再回来（没换装），团子认得是同一个人，用装扮外号叫他；黑影不编号
- **现状**：认装扮（`[appearance]`）已经给陌生人编号「陌生人A / B」、走开又回来发 `stranger_back`；但门槛还是 10-03 spike 估的，10-04 晚第一次上真机出现的 6 次「陌生人X 又回来了」对不对还没核对
- **要做的**：
  - 先补欠账：`perception appearance-eval <录像> --gallery` 重标 `match` / `unsure` / `dango_match`；核对 10-04 晚 `stranger_back` 的 6 次
  - 外号：从 Haiku 的装扮描述里取几个字当外号，描述回来前用编号；同一次上线里不重名（撞了加数字）；status、事件、`look_person` 都认外号
  - 认不稳再加强认人特征（看前一步核对的结果定，不预先做）
- **怎么算做成**：录像回放里，陌生人走开再回来认对的比例过线；两个不同的陌生人被当成同一个人的次数接近 0（认成同一个人比认不出更糟）
- **远期**：跨天认人。现在底库只认这次上线，是因为不同地图、白天晚上光照差太多，颜色和 DINOv2 都不稳；要换更强的认人模型、自己攒训练数据

### ⑥ 认常见动作、自己排轮盘

- **目标**：认得出别人对团子做的常见动作；团子按自己的习惯决定轮盘放什么；做动作照旧
- **现状**：轮盘读 / 改 / 做都有（`game/wheel.py`、`game/emotes.py`，`swap_slots` 临时换、退出恢复）；动作识别 10-02 标了 264 段、试训 3 类没达标——只有一两段录像，换场景就认不出；欢呼 / 害羞还没录
- **要做的**：
  - 先和用户一起定「常见动作」清单（例如 8 个），名字用管理面板「标注 → 动作名」起的名字
  - 补数据：每类动作在多个地图、白天晚上、远近各录几段，够了再训（`perception clips` → 标注页 → `gesture-train`）
  - 轮盘：团子按最近常用、心情、场合排轮盘；锁定格（3、8）不动；下线换回用户的配置（沿用现在的恢复逻辑）；换轮盘有冷却，不在别人面前频繁换
- **怎么算做成**：在没参与训练的录像（新场景）上每类都认得出、过线；轮盘真机上改了又恢复，退出后逐格核对和原来一样

## B 组：能去社交场景

### ⑦ 最小版：走到看得见的目标旁边

- **要做的**：标定 `move` 一步走多远、`Camera.nudge` 一下转多少度（`[spin]` 的数字也还没标定）；做「走过去」技能：把目标转到画面中间 → 往前走几步 → 看目标框有没有变大、有没有偏 → 修正；走不动（框不变大、画面不动）就停下报告「被挡住了」
- **怎么算做成**：真机上在空地对着看得见的座位 / 好友，十次里大部分能走到旁边；走不到时能自己停下，不会一直撞墙

### ④ 认座位、会坐下

- **现状**：`bench` 类和 `objects()` 代码写好了（`2026-09-29-object-recognition-design.md`），v8 / v9 座位试训没上线，没有可用的模型
- **要做的**：先看 ② 最小版的坐下图标够不够用（走近了才冒出来，远处还是要认座位）；物品模式给数据集补标 `bench`，训出认得座位的模型；先在真机上手动确认坐下怎么操作（走近后出什么提示、按什么键 / 点哪里、怎么站起来），写进 game-ops；再做「去坐下」技能 = 走过去 + 坐下 + 确认坐上了
- **怎么算做成**：常去的几张地图里座位认得出；真机上「去那个座位坐下」能做成，坐下和站起来都能确认

### ⑤ 坐在交流座位上和陌生人聊天

- **要做的**：先在真机确认交流座位的机制（陌生人的话从哪里出来、无障碍节点读不读得到）；陌生人说话进聊天事件，标出是陌生人、用 ① 的外号；单独写一套对陌生人说话的规矩
- **底线**（陌生人里很可能有未成年人）：不问也不说个人信息、不约线下、不加联系方式、不声称是真人（认真问就承认）、话短、对方不想聊就停；聊得不舒服团子可以自己站起来走。现在「陌生人只能接点火 / 点亮」那条限制要放开到这个场景里，其余照旧
- **怎么算做成**：沙盒剧本里陌生人的试探（问年龄、要 QQ、问是不是真人）都守住；真机上能和陌生人来回聊几句、能自己结束

## C 组：能自己行动

### ⑦ 完整版：认地形、自己走路

- **方向**：先不追求「看一眼就知道哪能走」，边走边记：走不动的方向、走通的路记下来；以后再考虑训练认地面 / 悬崖 / 水的模型
- **怎么算做成**：在一张熟悉的地图里能从 A 走到 B，中途撞墙能绕开，不会掉下悬崖（掉了能发现）

### ② 完整版：认全按钮、面板，会操作

- **前提**：② 最小版（见 A 组）已经做完
- **要做的**：按常用程度一张张加面板（商店、星盘、设置、季节……）；每个面板 / 按钮写进知识库：长什么样、叫什么、按了会怎样、能不能自己按（花钱、删好友、退出、共享空间「加入」永远不按，和现在的 `never` 一致）。和 ⑧ 挨着做，知识库这时一起抽出来
- **怎么算做成**：日常会碰到的面板都认得出、知道怎么关

## ⑧ 自主学习：学认东西（最后做）

- **要做的**：
  - 这时把知识库抽出来：⑥ 的动作名、装扮图鉴（`catalog/`）、② 的面板都放进去，条目 = 长什么样、叫什么、怎么操作、谁教的
  - 团子遇到不认识的东西（名字、装扮、按钮、地图、动作）先存进「不认识的清单」（`unknown_names/`、图鉴 inbox 是现成的苗头）
  - 找合适的时机（闲着、和熟人聊天时）问卡洛或好友「这个叫什么」，问到了写进知识库，下次认得；问过的不反复问，问的频率有限额。和图鉴路线的第 3 期「游戏里主动问」合并
- **不做**：自己去点没见过的按钮试结果（风险太大）；从聊天里学好友的习惯（内心层已经在做）；从失败里自动调参 / 重训
- **怎么算做成**：一晚上团子问了几个问题，答案进了知识库，之后再碰到能叫出名字；不会追着人问到烦
