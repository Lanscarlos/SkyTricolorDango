# 外形页网格过目（训练集人物框核对第一步）

日期：2026-11-05。状态：设计已和用户逐节确认，待写计划。

## 0. 背景

要先人工核对 YOLO 训练集的人物框再训（`docs/progress/2026-09-28-yolo-training.md` 11-04 晚一节）。11-05 做了外形页按轨迹整组判
（`docs/superpowers/specs/2026-11-05-form-track-labeling-design.md`），但真实数据上只省约 40% 按键：训练集是稀疏抽帧，同一个人很少连着几帧出现，
1304 张导入未确认的裁图只串成 758 组；收件箱的裁图全是单张。

核对时大部分框是对的，要找的是少数错的，所以改成**网格过目**：一页摆很多张，默认是对的，只点错的，整页确认。

核对分两步（用户选的）：**第一步只核"是不是人"**（这一期，给 YOLO 单类训练用）；**第二步核外形类别**（点亮 / 黑影 / 先祖，用现有外形页的「导入未确认」，不改）。
两步的记录要分开，第一步不能把外形类别也记成"确认过"。

## 1. 记录：`scope: "person"`

- **点出"不是人"**：照旧挪进 `form/not_person`，正常的一条标注（写回时删框）。
- **点出"不要"**：照旧挪进 `_discard`。
- **默认是人（没点的）**：
  - 在 `form/<类别>/` 里的（原有标注导入的）：不挪，记 `{"t", "crop", "from": 类别, "to": 类别, "scope": "person", "batch"}`；
  - 在 `_unlabeled` 里的（`crops-audit` 找到的漏标）：挪到外形头猜的人形类别（`_scores.json` 里 lit / unlit / spirit 概率最高的；没有分数 = lit），记 `{…, "from": "_unlabeled", "to": 类别, "scope": "person", "batch"}`。
- `scope: "person"` 的记录：
  - **不算**外形确认：`attrs_data.hand_labels` 跳过它（这些裁图在第二步里还是"导入未确认"；`attrs-train` 默认只用确认过的，所以第一步的结果不进外形头训练）。
  - 新函数 `attrs_data.person_checked(root) -> set[str]`：撤销之后还算数的 `scope: "person"` 记录、而且裁图现在还在那条记录的 `to` 里 = 核过是人。
  - 撤销照旧（人在页面上标的，进撤销栈），`live_records` 的配对规则不变。
- 整页确认一次 = 一个 `batch`（同 11-05 的整组撤销，Z 撤整页）。

## 2. 写回 `datasets/sky`（`perception crops --writeback`）

- 照旧处理外形确认过的（改点没点火、补漏标、删不是人）。
- 另外读 `person_checked`：**只用来补框**——`crops-audit` 找到的漏标（`_crops.jsonl` 里 `known = False`）核过是人的，按它所在的类别目录（`WRITEBACK_ID`）补一个框；原有标注（`known = True`）核过是人的，标注不变。
- "不是人"删框、"不要"不动，同以前。

## 3. 分数：`_scores.json`

- `perception crops-audit` 过外形头时，对**训练集所有人物标注框和这次找到的漏标**都算外形概率（以前只算三个模型都框到的），
  写进 `datasets/attrs/_scores.json`（裁图名 → {类别: 概率}），覆盖写，旧文件先备份成 `_scores-<时间>.json`；外形头没加载就不写。
- 「是人的概率」= lit + unlit + spirit + shared + morph 之和（缺的类按 0）。

## 4. 页面

- 外形页顶上加模式切换 **「单张 / 网格」**（存 `localStorage` 键 `skydango.form.mode`，读写包 try/catch，默认单张）；网格模式下左边列表和右边按钮收起，中间整块是网格。
- **显示哪些**：沿用当前筛选，**去掉已核过是人的**；按「是人的概率」从低到高排（最可疑在前），没有分数的排最后；一页 **36 张**（6 × 6）。
- **每一格**：裁图缩略图；角上小字写现在的类别（点亮 / 黑影 / 先祖 / 待确认……）和是人的概率（没分数不写）。
  - 单击：切换"不是人"（红色 ×），再点取消；Shift + 单击：切换"不要"（灰色）；双击：右侧弹出上下文整帧（`api/form/context`），点别处收起。
- **整页**：底部「这一页确认（Enter）」→ 一次 `api/form/check`，成功后加载下一页；**Z** 撤销上一页（回到那一页，标记恢复成确认前的样子）；
  顶上进度「核过是人 N / 这个筛选共 M」。跳过的裁图 `toast` 一句。
- 页面不引外部资源、不用原生弹窗，颜色用 `console.css` 的变量。

## 5. 后端接口

- `api/form/state` 多给：`scores`（`_scores.json` 里现在还存在的裁图 → 概率；坏文件 = `{}`）、`person`（`person_checked` 的名单）。
- 新 `POST api/form/check` `{"person": [...], "not_person": [...], "discard": [...]}`：一个 `batch`，持锁逐张按 §1 做；同一张出现在两份名单里 = 400；
  不存在 / 不在原处 / 已核过的跳过并报出来，其余照做。返回 `{"ok": True, "batch", "items": [...], "skipped": [{"crop", "text"}]}`；一张都没做成 = 409。
- `api/form/undo`：整页撤销沿用 `batch` 那一套；`scope: "person"` 的原地记录撤销 = 记一条撤销、不挪；从 `_unlabeled` 挪出来的挪回去。

## 6. 测试和验收

- `person_checked` / `hand_labels`：scope 记录不算外形确认、撤销后不算核过、被挪走后不算核过。
- `api/form/check`：三份名单各自的去处和记账、一个 `batch`、重复名字 400、跳过、整页撤销恢复原样。
- 写回：漏标核过是人 → 补框；原有标注核过是人 → 不变；不是人 → 删框。
- `crops-audit`：`_scores.json` 覆盖所有训练集标注框和漏标、旧文件备份。
- 前端纯逻辑（node）：分页、排序（没分数排最后）、去掉核过的、点击 / Shift 点击切换、整页提交的三份名单。
- **验收（人工）**：「重点核对」+ 训练集「导入未确认」在网格里过一遍，记时间；目标 1300 张左右 40 分钟内（每页 36 张平均 2 分钟以内）。

**不在这一期**：第二步细核外形类别（现有外形页）、交互图标和物品的核对。
