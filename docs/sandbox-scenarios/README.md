# 沙盒示例剧本

管理面板「沙盒」页的剧本回放用（格式见 `docs/superpowers/specs/2026-09-30-brain-sandbox-design.md` §6）。

| 剧本 | 看什么 |
|---|---|
| `放鸽子.toml` | 说好来又不来：会不会闹别扭；认真说难过后别扭当场撤掉；下线写日记、睡一晚再上线 |
| `深夜犯困.toml` | 越聊越晚：精力掉到困、主动开口变少，被叫到照样接话 |
| `第二天上线.toml` | 下线写日记、睡一晚上线：「日子」带日记，见到老朋友接上昨天的话 |
| `两个好友互相聊.toml` | 两个好友互相叫名字聊：团子大部分不接、插话不超主动开口额度（聊天记录标「跟别人说」）；叫到团子立刻接（标「跟你说」）。两个好友名都要在 friends.md 里，最好各加一行 `- 叫法：…` |

## 怎么用

1. 人名是占位的 `小明` / `阿花`：换成你 `memory/friends.md` 里的好友名（`## 标题`），不然团子不认识他们
   （别扭、老梗只冲一起玩过 3 天以上的好友，放鸽子要用老朋友才看得出别扭）
2. 复制到 `sandbox/scenarios/`（不进 git，剧本里是好友真昵称）
3. 管理面板「沙盒」页 → 剧本下拉里选它 → 回放；报告在 `sandbox/reports/<剧本>-<时间>.md`

`expect` 只写进报告给人看，这一版不自动检查。回放真的会调 Claude（大脑、反思、记忆整理），和真机一样花额度。
