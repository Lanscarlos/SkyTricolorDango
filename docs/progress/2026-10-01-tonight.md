## 0. 开始前

- `git pull`（本地 main 要是最新的）；`config.toml` 里 `[perception] enabled = true`、`model = "models/sky-yolo-v7.pt"`（已经是）
- 游戏里关掉聊天记录面板（C）；MuMu 窗口别最小化
- 全程开着 `--view`：大脑时间线能看到每轮收到了什么、为什么说 / 不说

## 1. 录素材（好友在的时候先做，要他配合）

照 `docs/progress/2026-09-28-yolo-training.md`「2026-10-01 晚：录物品和动作素材」一节：

- [ ] 动作（第一版认 4 个）：**挥手、鞠躬、欢呼、害羞**各 2~3 段（`--fps 8`，一段一种动作，目录名 `gesture-wave-1` / `gesture-bow-1` / `gesture-cheer-1` / `gesture-shy-1`），
      反例 `none` 2~3 段（站着、走、坐下、做发抖 / 张臂踢腿等别的动作）
- [ ] 乐器：请好友弹，2 段
- [ ] 座位、篝火：各 2~3 个地方（可以自己跑图时录，不用好友）
- [ ] 先祖：2 张图（别拍壁画）
- [ ] 好友挂机冒 Z 时录 1 分钟

## 2. 认装扮：只看不动（5 分钟）

`config.toml` 加 `[appearance] enabled = true`，然后 `python -m skydango view`（不发任何输入）：

- [ ] 好友走到远处 / 背后、名字标签消失后，框上是浅绿虚线"像小明?"，不是橙色"陌生人"
- [ ] 点过火的陌生人走开再回来，还是同一个"陌生人X"
- [ ] 鼠标悬停虚线框（还没描述时没字，正常）

## 3. dry-run 跟好友待 20 分钟以上（不真发消息）

```bash
python -m skydango run --dry-run --view --duration 1800
```

在网页的大脑时间线里看：

- [ ] **主动开口**：`notice`（眼睛注意到的新鲜事）多久一条、是不是编的；说 / 不说的理由；只有陌生人时一句都不主动
- [ ] **身体反射**：有人跟团子说话时状态里"输入框：开着（身体替你开的）"什么时候出现、什么时候关
- [ ] **东张西望**（要 `[panel] mode = "auto"`，默认就是）：面板关着、闲着时镜头会不会自己往说话的人 / 走过来的人那边转；转得频不频、晃不晃
- [ ] **内心层**：arrive 那条带不带交情（"第 N 次见、上次…前"）；"心里"一栏的心情、精力和理由对不对得上
- [ ] **认装扮**：状态里有没有"你自己：…"、好友名字后面的装扮；描述是不是在瞎编季节名
- [ ] **点亮陌生人**（另一个会话做的，见 `docs/superpowers/specs/2026-10-01-light-unlit-stranger-design.md` §9）：黑影站到身边时日志里有"[dry-run] 会举蜡烛…"

## 4. live 小范围试（只有熟人在的时候）

```bash
python -m skydango run --live --view
```

- [ ] 身体反射：气泡冒了又消？团子回话是不是从这个框发出去的；框开着时来牵手请求能不能接上
- [ ] 主动开口：好友对团子主动说的话什么反应；有没有刷屏
- [ ] 性格：故意夸它不喜欢的东西，看会不会唱反调；说一句"难过"，看会不会马上收着
- [ ] 认装扮：好友换一套装扮再来（换装判断改过之后再试，见下）
- [ ] 点亮陌生人：按 3 举蜡烛 → 黑影亮起来 → 鞠躬
